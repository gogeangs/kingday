# 콘텐츠 기획 세션 안내서

작성일: 2026-10-21 · 대상: 새 「콘텐츠 기획」 세션
이 문서 하나로 지금 게임에 무엇이 있고, 무엇을 기획해야 하고, 어떤 규칙으로 정해야 하는지 파악할 수 있게 정리했다.
관련 문서: `docs/GAME_DESIGN.md`(세계관·줄거리), `docs/COMPANION_GUIDE.md`(동료 추가 규칙), `docs/HANDOFF_NATIVE.md`(앱 전환), `docs/RANKING.md`(랭킹·우편), 프로젝트 문서 `claude/COMPANION_*.md`(전설 동료 3명 기록), `claude/RELEASE_NATIVE.md`(출시 준비).

---

## 0. 이 세션의 역할

- **기획만 한다.** 정한 내용은 문서로 남기고(이 저장소 `docs/`와 claude.ai 프로젝트 문서), 구현은 다른 세션이 맡는다.
  - 웹 버전: `index.html` (main 브랜치, GitHub Pages)
  - 네이티브 앱: Flutter + Flame (`app/`, PR #133~#146 진행 중, 아직 main 미병합)
  - 동료: `docs/COMPANION_GUIDE.md` 절차
- 기획서에는 **구현 담당이 바로 쓸 수 있게** 수치·조건·문구·필요한 그림 목록을 함께 적는다.
- 한 번에 한 주제씩: 현황 정리 → 2~3안 제시 → 대표님 선택 → 확정안 문서화.

## 1. 현재 게임 콘텐츠 (2026-10-21 기준)

### 1-1. 세계관·진행
- 1부 「잃어버린 왕국」: 마왕 아래 군단장 5명이 나눠 다스리는 왕국 되찾기.
- **구현된 범위: 5지역 × 영지 10곳 = 50영지 + 왕도(잠김)**

| 지역 | 몬스터(일반/둘째) | 군단장 | 영지 이름 예 |
|---|---|---|---|
| 에르단 평원 | 역병 점액 / 저주받은 허수아비 | 역병의 군단장 모르바스 | 개울 마을 ~ 역병의 둥지 |
| 어스름 숲 | 밤그늘 박쥐 / 그림자 늑대 | 밤의 군단장 세릴 | 숲 어귀 ~ 밤의 둥지 |
| 드워프 협곡 | 강철 골렘 / 곡괭이 고블린 | 강철의 군단장 그로마크 | 협곡 입구 ~ 강철의 대장간 |
| 서리 무덤 | 서리 망령 / 서리 해골 | 망령의 군단장 알도르(루미나르의 두 번째 주인) | 얼어붙은 길 ~ 망령의 무덤 |
| 잿불 심연 | 잿불 점액 / 화염 임프 | 화염의 군단장 이그니스 | 잿빛 들판 ~ 마계의 문 |

- 영지 = 웨이브 10개 + 성주 보스(30초 제한), 각 지역 10번째는 군단장(40초).
- **아직 없는 것**: 왕도 아스테리온 공략, 마왕 발타사르, 2부·3부(엘프 왕국·사막 제국·북방 부족·마계), 회차(300년 봉인) 시스템.

### 1-2. 성장
- **칭호** 7단계: 농부(0) → 마을 지킴이(3) → 기사(10) → 영주(20) → 백작(30) → 공작(40) → 왕도 진격대장(50) · 단계마다 원정대 능력 +4%, 이삭 30
- **단련** 4종: 공격력·체력·공격 속도·치명타 (×1/×10/최대, 꾹 누르기)
- **장비(성유물)**: 6부위, 등급 6단계(일반·고급·희귀·영웅·전설·신화 = 배율 1/1.6/2.5/4/6.5/11), 상자 레벨 1~10, 10연속(영웅 이상 1개 확정), 부위 강화(광석)
- **동료**: 직업 4자리(광부·어부·양봉가·요리사) + 카엘. 이야기 동료 4명 + 모집 동료(일반·희귀·영웅·전설), 카드로 합류·별 올리기, 동료 레벨업, 동료 전용 무기 강화(광석)
- **은퇴(환생)**: 처음으로 돌아가며 「은퇴의 추억」 → 모든 능력·골드 영구 보너스. 카드·별은 유지.

### 1-3. 마을·생활
- 건물 6종(최대 레벨): 여관(10, 방치 보상 시간) · 밭(6, 칸 수) · 식당(10, 체력) · 낚시터(10, 생선) · 양봉장(10, 동료 공격력·꿀) · 광산(10, 카엘 장비·광석). 공사 시간 있음, Lv.6+는 광석 필요, 공사 대기열 2.
- 작물 3종: 밀(1분) · 은빛 당근(5분) · 달빛 호박(20분). 마물에게서 씨앗 획득, 밭 칸을 이삭으로 추가.
- 요리 4종(30분 버프): 마르타의 밀빵(공격력 +20%) · 생선 당근 스튜(공속 +20%) · 꿀 호박 파이(골드 +50%) · 드워프 돌판 구이(치명타 +10%)
- 방치 보상: 최대 6+여관 Lv시간, 광고/이삭으로 2배.

### 1-4. 반복·이벤트·경쟁
- 오늘의 할 일 3개(마물 100·상자 10·작물 10, 각 이삭 10) + 모두 끝내기 이삭 20
- 피트의 무료 선물(광고 보상): 상자·이삭·카드, 하루 횟수 제한
- 황금 고블린: 1-3 이후 6~12분마다 등장, 골드·이삭·장비, 아주 드물게 전용 배지·테두리
- 랭킹: 2주 시즌(최고 영지) · 명예의 전당 · 황금 고블린 주간 / 우편함 보상 / 시즌·주간 결과 창
- 프로필 꾸미기: 테두리 11종, 배지 14종(업적형·고블린 희귀·랭킹 보상)

### 1-5. 상점·수익
- 황금 이삭 꾸러미 6종(₩1,200~₩99,000, 첫 구매 2배), 첫 거래 특가(₩1,200, 이삭 100+장비), 피트의 정기 배송(₩5,500/월), 이삭→골드 바꾸기, 동료 카드 3장(이삭 30)·30장(270)
- 광고: 보상형만(강제 광고 없음)
- 지금은 결제·광고 모두 시험 모드. 성유물 상자는 **유료 확률형 아이템** → 확률 공개 의무(장비 탭에 표시 중)

### 1-6. 동료 현황
| 상태 | 동료 |
|---|---|
| 게임에 있음 (10) | 카엘 / 브론·하랄·리엘·마고(이야기) / 고든(일반 광부) / 데이지(희귀 양봉가) / 루카(영웅 요리사)·넬라(영웅 어부) / 브리다(전설 광부, 마을 스킬 「여왕의 대장간」) |
| 기획·그림 완료, 등록 보류 (3) | 막례(전설 어부·해녀, 말순이) / 말봉(전설 양봉가, 데이지 아빠) / 덕배(전설 요리사, 마고의 스승) — 프로젝트 문서 `claude/COMPANION_*.md` |

| # | 주제 | 왜 필요한가 | 결정할 것 |
|---|---|---|---|
| A | **왕도 아스테리온 + 1부 엔딩** | 50영지 이후 할 게 없음(최상위 유저 이탈) | 왕도 구조(영지 수·보스 연전), 마왕 발타사르 전투, 엔딩 연출, 왕관을 들고 사라지는 2부 연결 |

| C | **은퇴(환생) 심화** | 지금은 보너스 % 하나뿐 | 은퇴 전용 상점/특성 트리, 회차별 변화, 은퇴 횟수 보상 |

| E | **정기 이벤트** | 재방문·매출 | 시즌 테마 이벤트(추수제·눈꽃제 등), 이벤트 재화·상점, 기간 한정 보스, 출석 7일 |

| G | **도전 콘텐츠** | 고성장 유저 목표 | 무한의 탑, 보스 재도전(난이도 단계), 일일 던전(재료별) |

## 3. 기획 원칙 (지금까지 대표님이 정한 것)

- 톤: 정통 판타지 + 은퇴만 꿈꾸는 농부의 유쾌함. 루미나르(자존심 센 성검)·카엘(투덜거리는 평화주의자) 대사 합.
- 동료는 평범한 마을 사람·장인·자연 직업인. 직업 4자리 고정, 새 직업은 만들지 않는다.
- 이야기 동료는 일반 등급, ★3까지. 전설 동료는 마을 스킬 1개.
- 카드는 묶음으로 팔지 않는다. 상점 문구는 친근하게(피트 말투).
- 확률형 아이템은 확률 공개. 강제 광고 없이 보상형 광고만.
- 숫자는 기존 공식을 깨지 않게: 새 콘텐츠의 보상은 같은 시간 플레이 대비 기존 대비 비슷하게(밸런스 시뮬레이터 `tools/balance_sim.py`, `tools/sim/`).
- 웹과 앱이 **같은 서버·같은 저장 데이터**를 쓰므로, 새 콘텐츠의 저장 필드·서버 함수는 두 버전에 같이 들어가야 한다.

## 4. 기획서 작성 형식 (구현 세션에 넘길 때)

각 주제는 `docs/content/{주제}.md`와 claude.ai 프로젝트 `claude/CONTENT_{주제}.md`에 아래 순서로 남긴다.

1. 목적 (어떤 유저의 어떤 문제를 푸는지)
2. 확정 내용 요약 (한 단락)
3. 규칙·수치 표 (해금 조건, 보상, 비용, 시간, 확률)
4. 화면 흐름 (어느 탭/버튼에서 어떻게 들어가는지, 창 문구)
5. 대사·텍스트 (카엘·루미나르·동료, 대사 형식 `k@표정:`, `q@표정:`, `m:이름|`)
6. 필요한 그림 목록 + ChatGPT 프롬프트([공통 규칙] 포함, 10장 미만 묶음)
7. 저장 데이터·서버 변경 (새 필드, SQL/RPC 필요 여부)
8. 웹/앱 구현 메모, 검증 기준
9. 미정 사항

## 5. 작업 규칙

- 대표님과의 대화는 **한국어**, 쉬운 말로. 선택지는 번호와 짧은 설명으로, 추천안 표시.
- 실존 인물·상표와 겹치지 않게(예: 막례는 실존 유튜버 실명과 같아 성 없이).
- 그림 프롬프트에는 항상 [공통 규칙]: 밝고 선명한 정통 판타지 화풍 / 완전 투명 배경 PNG(배경 일러스트 제외) / 글자·숫자·로고·워터마크 없음 / 크기 명시.
- 확정된 기획은 저장소 `docs/`에 커밋(브랜치 → PR → main 병합)하고, 프로젝트 문서에도 같은 내용을 올린다.

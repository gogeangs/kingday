# 네이티브 앱 QA 보고서 (0~8단계까지)

- 날짜: 2026-10-21
- 대상: Flutter 앱 `app/` (브랜치 `native/qa`, 8단계 서버 연결까지)
- 기준: 웹 버전 `index.html` (같은 공식·같은 저장 구조)

## 결과 요약

- **웹과 같은 계산**: 공식·전투·조작에 더해 이번에 넣은 **긴 플레이 비교(30~60분, 3가지 기록)** 까지 웹과 결과가 같아요.
- **문제 10개를 찾아 고쳤어요.** 그중 바로 체감되는 것은 둘이에요.
  - 방치 보상 창의 「광고 보고 2배 받기」가 보상을 주지 않던 문제
  - 모든 창의 금테가 웹보다 약 3배 굵게 그려지던 문제
- **예외 상황**: 깨진 저장 11종, 시계 되돌림, 50년 넘게 꺼 둔 경우, 화면을 켠 채 10분 자동 플레이에서 모두 앱이 멈추지 않았어요. 골드·이삭이 음수나 NaN이 되는 일도 없었어요.
- **화면 비교**: 웹과 앱 화면 35쌍을 같은 크기(390×844)로 찍어 나란히 봤어요. 금테·시작 화면을 고친 뒤에는 눈에 띄는 차이가 없어요.

## 3. 일부러 웹과 다르게 둔 것

- **앱으로 돌아올 때도 방치 보상**: 웹은 처음 켤 때만 줘요. 휴대폰 앱은 다른 앱을 오가는 일이 잦고 그동안 전투가 멈추니, 1분 넘게 비웠다면 그 시간만큼 보상을 줘요. 최대 시간 제한은 같아요.
- **원정대 하위 탭(편성/동료/카드)을 기억**: 다음에 켜도 보던 탭이 열려요. 웹은 이 값을 무시하니 저장 호환에는 문제가 없어요.

## 4. 아직 남은 것 (9단계 이후)

- **피트의 상점 탭이 빈 화면**: 오늘의 할 일 보상, 무료 선물, 골드 바꾸기, 카드 팩, 첫 거래 특가, 정기 배송, 이삭 꾸러미가 없어요.
  - 그래서 이삭 옆 빨간 점이 떠도 받을 곳이 없어요.
  - 「할 일」 안내 8번째(상점에서 할 일 보상 받기)에서 안내가 멈춰요. → 우선 처리 권장.
- **구글·애플 로그인, 인앱결제, AdMob**: 광고는 지금 3초짜리 가짜예요.
- **진동·소리**: 진동 패턴이 한 번 진동으로 단순화돼 있어요. 소리는 아직 없어요.
- **화면 효과**: 골드·전투력 숫자 반짝임과 떠오르는 「+N」 글자가 없어요.
- **실제 폰 확인 필요**: 이모지(⚔ ⚙ 🏆)는 시험 환경 글꼴에 없어 네모로 찍혔어요. 실제 폰에서는 기본 글꼴로 보일 거예요. 서버는 가짜 서버로만 시험했으니 첫 실행 때 랭킹·우편이 열리는지 확인해 주세요.

## 5. 저장 호환

웹과 앱은 같은 저장 키(`acorn-idle-v1`)와 같은 JSON을 써요. 앱은 모르는 필드도 지우지 않아요. 웹이 만든 저장 코드 3개, 깨진 저장 11종으로 확인했어요.

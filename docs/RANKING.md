# 랭킹 기획 (확정)

마지막 정리: 2026-10-20

## 1. 서버
- **Supabase 무료 플랜**으로 시작 (카드 등록 없음)
- 로그인: 익명 로그인으로 자동 가입 → 나중에 구글·애플 계정 연결
- 무료 약점(7일 무접속 시 잠듦) 대응: 개발 기간 GitHub Actions로 하루 한 번 깨우기, 랭킹이 안 열려도 게임은 정상, 기록은 휴대폰에 모았다가 재전송
- 유료(Pro 월 $25) 전환 기준: 하루 이용자 수천 명 이상 또는 DB 500MB 근접

## 2. 랭킹 종류
| 탭 | 기준 | 초기화 |
|---|---|---|
| 시즌 | 2주 동안 도달한 최고 스테이지 (같으면 먼저 도달한 사람) | 2주마다 |
| 명예의 전당 | 역대 최고 스테이지 | 없음 |

## 3. 보상
### 시즌 (2주마다, 우편함 지급)
| 순위 | 보상 |
|---|---|
| 1위 | 황금 이삭 500 + 전용 테두리 「시즌 왕관」(시즌마다 색 다름) + 전용 배지 + 유니크 카드 15장 |
| 2~10위 | 황금 이삭 300 + 전용 배지 + 유니크 카드 8장 |
| 상위 10% | 황금 이삭 150 + 동료 카드 30장(영웅 이상) + 유니크 카드 4장 |
| 상위 50% | 황금 이삭 50 + 유니크 카드 2장 |
| 참여(기록 1회 이상) | 황금 이삭 20 + 유니크 카드 1장 |

- 유니크 카드(2026-10-23 추가, `docs/companions/KAEL_CHIEF.md`): 서버 `supabase/stage6_unique.sql`을 실행한 뒤 정산되는 시즌부터 지급. 2026-10-23 장수를 절반쯤으로 줄임(전에는 30·15·8·3·1)

### 명예의 전당
- 50곳 모두 탈환: 「명예의 전당」 전용 테두리 (최초 1회)
- 1~3위: 이름 옆 금·은·동 왕관 표시 (보상 없음)

## 4. 화면
- 진입: 지도 탭 「랭킹」 버튼, 프로필 창 「랭킹 보기」
- 위: 시즌 남은 기간·보상 안내 / 1~3위 크게(초상화·테두리·배지·이름·스테이지) / 4~100위 목록 / 맨 아래 내 순위 고정
- 닉네임: 처음 열 때 정함, 욕설 필터, 시즌마다 1회 변경

## 5. 부정 기록 방지
- 속도 검사(가입 시간 대비 진행), 전투력 검사, 관리자 숨김

## 6. 개발 단계
1. 익명 로그인, 닉네임, 기록 전송, 랭킹 창(시즌·명예의 전당 탭)
2. 시즌 정산(2주), 우편함 보상, 전용 테두리·배지
3. 클라우드 저장, 구글·애플 계정 연결, 주간 황금 고블린 랭킹

## 7. 연결 방법 (1단계)
1. Supabase 대시보드 → SQL Editor → `supabase/schema.sql` 전체를 붙여 넣고 Run (여러 번 실행해도 안전)
2. Authentication → Sign In / Providers → Allow anonymous sign-ins 켜기
3. `index.html`의 `const SB={url:'',key:''}`에 Project URL과 anon(public) 키 넣기
   - 비어 있으면 랭킹 버튼은 「준비 중이에요」만 보여 줌

### 데이터 구조
- `profiles`: 닉네임(대소문자 무시 중복 금지)·테두리·배지·칭호
- `records`: (user, season) 최고 스테이지. season=0 은 명예의 전당
- 함수: `kd_set_nick` · `kd_submit`(가입 시간 대비 너무 빠르면 hidden) · `kd_ranking`(상위 100 + 내 순위)
- 시즌: 2026-10-19 00:00 KST부터 14일 단위 (`kd_season()`)

## 8. 2단계: 우편함 + 시즌 정산 (supabase/stage2_mail.sql)
- 우편함 버튼: 전투 화면 오른쪽 위(닉네임을 정한 뒤 보임), 안 받은 우편 수 빨간 점
- 우편: 서버(`mails`)에서만 만들고 `kd_mail_claim`으로 받기 확인 → 게임이 보상을 넣음. 보관 30일
- 시즌 정산: 끝난 시즌은 누군가 우편함을 열 때 `kd_settle_due`가 한 번만 정산(`settlements`)
- 명예의 전당: 정산 때 1~3위 금·은·동관 배지(각 한 번), 50곳 탈환 시 「정복자」 테두리(한 번, 1년 보관)
- 운영 우편(SQL Editor 전용): `select public.kd_admin_mail(null, '점검 보상', '고마워요', '{"gem":100}');`
- 새 꾸미기: 테두리 season·conquer, 배지 champ·top10·crown1~3 (그림은 임시 → 교체 예정), 우편함 아이콘 icon_mail, 배너 hd_mail

## 9. 임시 닉네임 + 환영 우편 (supabase/stage2b_welcome.sql)
- 게임을 시작하면(온라인) `kd_ensure_profile`이 계정을 준비: 닉네임이 없으면 임시 닉네임 「영주12345」 발급
- 환영 우편: 계정마다 한 번, 황금 이삭 50 (기존 유저에게도 발송)
- 닉네임은 프로필 창에서 정하기/바꾸기. 임시 닉네임은 시즌 제한 없이 한 번 바꿀 수 있음, 「영주+숫자5자리」 형식은 직접 못 씀

## 10. 3단계-1: 황금 고블린 주간 랭킹 (supabase/stage3a_goblin.sql)
- 주차: 2026-10-19(월) 0시 KST부터 1주 단위. 랭킹 창 세 번째 탭 「고블린」
- 기록: 이번 주 잡은 황금 고블린 수(게임이 30초마다 보냄). 3분에 1마리보다 빠르면 숨김
- 정산: 우편함을 열 때 끝난 주를 한 번만 정산 → 1위 이삭 100 + 고블린 사냥꾼 배지, 2~10위 50, 상위 30% 20

## 11. 3단계-2: 클라우드 저장 + 구글 계정 연결 (supabase/stage3b_cloud.sql)
- 자동 저장: 3분마다(바뀐 게 있을 때) + 앱을 내릴 때. 서버 `saves`(1인 1행, 300KB 제한)
- 수첩 「계정」: 게스트면 [구글 계정 연결] [다른 기기 기록 불러오기], 연결되면 이메일·마지막 저장 시각·[지금 저장]
- 연결: 익명 계정에 구글을 붙임(identities/authorize) → 연결 선물 이삭 50(우편, 한 번)
- 새 기기: 구글 로그인 → 클라우드 기록과 이 기기 기록을 비교해 고름
- 이미 다른 기록에 연결된 구글이면 → 그 기록 불러오기 안내
- 2지역(11번째 영지) 도달 시 게스트에게 한 번 연결 안내
- 필요 설정: Google OAuth 클라이언트, Supabase Google 제공자, URL 설정(사이트·리디렉트), 수동 연결(Manual linking) 켜기

## 1. 동료 시스템 규칙 (대표님 확정 사항)

- **직업 자리 5칸 고정**: 광부 · 카엘 · 어부 · 양봉가 · 요리사. 새 동료는 반드시 이 4개 직업 중 하나. (직업은 무조건 기존과 동일해야 함)
- 한 자리에 한 명만 출전. 같은 직업 동료끼리 교체(자리를 눌러 선택, 추천 편성 버튼 있음).
- **이야기 동료**(브론·하랄·리엘·마고): 일반 등급, ★3까지. 스토리 진행으로 합류.
- **모집 동료**: 같은 직업의 이야기 동료가 합류해야 카드가 나오기 시작. 카드 30장 모으면 「맞이하기」(★1), 이후 카드로 별 올림.
- 등급별 최대 별·능력 배율·카드 확률 가중치

| 등급 | 최대 별 | 배율 | 가중치 | 별 올리는 카드 수 (★1→…) |
|---|---|---|---|---|
| 일반 common | 3 | 1.0 | 55 | 30(합류) · 15 · 30 |
| 희귀 rare | 4 | 1.1 | 30 | 30 · 20 · 40 · 80 |
| 영웅 epic | 5 | 1.2 | 12 | 30 · 30 · 60 · 120 · 200 |
| 전설 legend | 5 | 1.35 | 3 | 30 · 40 · 80 · 160 · 300 |

- **등급별 전투력 목표 (2026-10-26 맞춤)**: 같은 직업 일반 동료 평균 = 1.00일 때, Lv.50 기준 √(공격×공속×체력)×배율로 **희귀 ≈1.12 · 영웅 ≈1.30 · 전설 ≈1.6~1.8**. 맞출 때는 **약한 동료만 올리고 센 동료는 내리지 않음**(대표님 결정).
  - 2026-10-26 올림: 토비(희귀 어부) 1.08→1.13 · 넬라(영웅 어부) 1.26→1.32 · 나이아(전설 어부) 1.55→1.62
  - 나머지는 목표 근처라 그대로. 베르나르(전설 요리사)는 2.46으로 많이 셈 — 내리지 않기로 해서 그대로 둠(스킬이 회복 위주라 실제 전투 차이는 더 작음)
- 모집 동료 스킬은 ★3, ★5에서 강화(`skPow`: ★3 ×1.3, ★5 ×1.6).
- **전설 동료는 마을 스킬 1개**: 합류만 하면(출전 안 해도) 늘 적용, 별이 오를수록 강해짐. 효과는 하나만.
- 카드 묶음은 만들지 않는다(여러 장 묶음 상품 X).

- 모바일 방치형 RPG 「왕이 되는 그날까지」의 캐릭터 에셋
- 화풍: 밝고 선명한 정통 판타지, 귀여운 2~2.5등신 치비 캐릭터, 굵고 깔끔한 외곽선, 셀 셰이딩, 기존 동료(밀짚모자 농부 카엘, 드워프 광부 브론, 늙은 어부 하랄, 요정 양봉가 리엘, 식당 아주머니 마고)와 같은 화풍·같은 등신
- 배경: 완전 투명(PNG), 바닥·그림자·주변 장면 없음
- 글자·숫자·로고·워터마크·말풍선 절대 넣지 말 것
- 모든 프레임에서 같은 캐릭터·같은 옷·같은 크기·같은 발 높이 유지

[캐릭터 설정]
- 이름/직업/등급: ○○ / 어부 / 희귀
- 생김새: (나이·체형·머리·옷·대표 색 2가지)

- **스킬 아이콘**: "스킬 「○○」 아이콘. 정사각형 1024×1024, 가운데에 상징 물건과 효과, 둥근 테두리 없이, 40px로 줄여도 알아볼 수 있게."

## 6. 코드에 추가할 곳 (index.html, 동료 id = `xxx`)

| 위치(상수/함수) | 할 일 |
|---|---|
| `COMP` | `xxx:{n,role,desc,join:'동료 카드 30장을 모으면 합류',base:{atk,hp,aps},per:{atk,hp}}` — 같은 직업 동료 수치를 기준으로 등급에 맞게 |
| `JOB` | `xxx:'fisher'` 등 |
| `RECRUITS` | `xxx:{job,title,lines:[합류 대사…],ok:'버튼 문구'}` — 대사 형식 `m:이름|대사`, `k@표정:카엘`, `q@표정:루미나르`, `sys:안내` |
| `GRADE` | `xxx:'rare'|'epic'|'legend'` |
| `VPAS` (전설만) | `xxx:{n:'스킬 이름',d:st=>'효과 문장 +'+vpPct(st)+'%'}` + 효과 함수(`vpMine` 같은) 연결 |
| `HEIGHT`, `SPRITES`, `FORM` | 키·프레임 수·대형 위치(같은 직업 위치 복사) |
| `SKILLS` | `{n,d,line,need,face}` |
| `castSkill()` | `else if(id==='xxx'){…}` 스킬 효과 구현(`skPow(id)` 반영) |
| `FXDEF` | `skill_xxx:4` |
| `SPRITE_ALT`, `DRAW` | 그림 오기 전 대체 |
| `NPCID` | `'이름':'xxx'` (대화 초상화 연결) |
| `tools/extract_skill_fx.py` | `build(...)` 한 줄 |

수정 후: `node --check`로 문법 확인 → 화면 확인 → `python3 tools/build_sw.py` → 브랜치·PR·병합 → Artifact 갱신.

## 7. 검증 체크리스트

- 카드 탭: 직업 동료 합류 전엔 「???」, 합류 후 카드가 나오고 희망(♡) 설정 가능
- 카드 30장 → 맞이하기 → 합류 장면(초상화·대사) → 편성 자리에서 교체 가능
- 전투: 스프라이트 크기·발 위치·공격 모션, 스킬 게이지·컷인 초상화·효과·수치
- ★3/★5 스킬 강화 문구와 실제 수치, 전설은 마을 스킬 표시(출전 안 해도 적용)
- 「다음 목표」 카드, 원정대 노란 점, 추천 편성이 새 동료를 고려하는지
- 화면 폭 320·360·390·430에서 넘침 없음, 장시간 시뮬레이션(능력치 NaN 없음)
- 밸런스: 같은 직업 기존 동료보다 등급만큼만 강한지(`cPow` 비교)

# 은퇴 심화 「카엘의 은퇴 일기」 기획서

작성일: 2026-10-22 · 상태: **구현 완료 (웹·앱, 2026-10-22)** — 시뮬레이터로 추억 보정 1곳 조정(10장)
선택: 추억 +5% 유지 + 같은 수만큼 추억 포인트 / 시작 영지 건너뛰기 넣기(최고 영지의 절반까지) / 특성 초기화 첫 1회 무료, 이후 이삭 100
그림 프롬프트: `claude/ART_RETIRE.md`

## 1. 목적
- 지금 은퇴는 「모든 능력치·골드 +5% × 추억」 숫자 하나만 커진다 → 은퇴할 때 **고르는 재미**(특성)를 준다.
- 은퇴할수록 처음 구간을 다시 미는 지루함이 커진다 → **시작 영지 건너뛰기**로 줄인다.
- 왕도(재탈환 보너스)·시련의 탑(층 유지)과 묶어 은퇴를 반복할 이유를 만든다.
- 기존 유저가 손해 보지 않게: 지금의 +5%는 그대로.

## 2. 확정 내용 요약
「은퇴의 추억」은 지금처럼 쌓이고 개당 +5% 효과도 그대로다. 여기에 더해 **받은 추억 수만큼 「추억 포인트」**가 생기고, 이것으로 3갈래 특성 트리(⚔ 검의 기억 · 🌾 밭의 기억 · 🎒 여행의 기억, 갈래마다 6개)를 찍는다. 포인트를 써도 +5%는 줄지 않는다. 기존 유저는 지금까지 받은 추억 수만큼 포인트를 바로 받는다. 「여행의 기억 · 지름길」을 찍으면 은퇴 뒤 영지 1이 아니라 더 앞에서 시작한다(최고 영지의 절반까지). 은퇴 1·3·5·10·20회에 보상을 주고, 은퇴 장면 대사가 회차마다 달라진다. 단련 탭의 은퇴 상자는 「은퇴 일기」 창(특성 · 기록 · 다음 보상)으로 바뀐다. 서버 변경은 없다.

## 3. 규칙·수치

### 3-1. 추억 포인트
- 쓸 수 있는 포인트 = `S.memory`(받은 추억 총수) − 지금까지 찍은 특성 비용 합.
- 추억 개당 모든 능력치·골드 +5%(`memMul`)는 **그대로**.
- 특성은 은퇴해도 유지(영구).
- 특성 초기화: 찍은 포인트 전부 돌려받음. **첫 1회 무료, 이후 황금 이삭 100**.

### 3-2. 특성 트리
- 갈래마다 3줄 × 2개. **2줄은 그 갈래에 10포인트, 3줄은 30포인트를 써야 열림.**

### 3-3. 지름길 규칙 (중요)
- 은퇴 후 시작 영지 = `min(1 + 5 × 단계, floor(S.best ÷ 2))`, 최소 1. 은퇴 창에서 「시작 영지 ○부터」 표시, 원하면 **영지 1부터 시작**도 고를 수 있음(체크 박스).
- 건너뛴 영지의 보스 첫 처치 보상(`gemLord` 등)은 주지 않는다 — 이미 받은 것이므로 변화 없음.
- 건너뛴 영지는 지도에서 「되찾음」으로 표시.
- **추억 계산 보정**(건너뛰고 바로 은퇴를 반복하는 것 방지):
  `retirePts = max(0, floor((stage − 10) ÷ 5) − floor(max(0, start − 10) ÷ 5))`
  → **건너뛴 구간의 추억은 빼고 친다**(처음 안은 「절반만」 = `÷ 10`이었으나 시뮬레이터에서 반복 이득이 커서 조정, 10장). 예: 30에서 시작해 61에서 은퇴 = 10 − 4 = 6개(+ 회고록·왕도 보너스). 영지 1부터 시작을 고르면 보정 없음.
- 은퇴 가능 조건: 지금처럼 영지 20 이상 **그리고 이번 회차 영지 10곳 이상 되찾음**.
- 랭킹 속도 검사(`kd_submit`)에 걸리지 않는지 확인(은퇴 직후 기록은 시즌 최고 기록보다 낮아 제출되지 않는 게 정상).

## 4. 화면 흐름
1. 단련 탭 은퇴 상자: 요약 1줄(「은퇴의 추억 ○개 · 모든 능력치·골드 +○% · 쓸 수 있는 포인트 ○」) + 버튼 2개 **「은퇴 일기」**, **「은퇴하기」**. 쓸 수 있는 포인트가 있으면 단련 탭과 「은퇴 일기」 버튼에 노란 점.
2. 「은퇴 일기」 창 (머리 배너 `hd_retire`) — 탭 3개
   - **특성**: 갈래 3개를 가로 탭(⚔ 🌾 🎒)으로, 각 갈래는 3줄 × 2칸 카드. 카드 = 아이콘·이름·「○/최대」·지금 효과·다음 단계 효과·「찍기 (○포인트)」. 잠긴 줄은 「이 갈래에 ○포인트 더 쓰면 열려요」. 맨 아래 「특성 초기화」(무료 / 이삭 100).
   - **기록**: 은퇴 횟수, 받은 추억 합, 가장 멀리 간 영지, 시련의 탑 최고 층, 왕도 탈환 횟수(`capClears`).
   - **다음 보상**: 3-4 표, 받은 것 체크.
3. 「은퇴하기」 확인 창: 지금 정보에 더해 「시작 영지 ○부터 (지름길)」 / □ 영지 1부터 시작 / 「씨앗 주머니·비상금 받음」 미리 표시 / 받을 추억(회고록·왕도 보너스 포함 계산) 표시.

## 7. 저장 데이터·서버
```

```

## 8. 구현 메모·검증
- 효과 연결 위치(예): 공격·체력 → `stats()`, 치명타 피해 → 치명타 계산, 보스 시간 → `bossLim()`, 스킬 게이지 → 보스 등장·도전 시작, 탑·던전 피해 → `hitMon`(모드 확인), 작물 시간 → 작물 성장, 생산 → 생산 건물, 공사 시간 → `bldTime`, 요리 → 요리 버프 시간, 2배 수확 → 수확, 방치 최대 시간 → `offline()` cap, 단련 비용 → 단련 비용 식, 고블린 → `gobT`, 추억 → `retirePts`.
- `retirePts`는 은퇴 창 표시와 실제 지급이 같은 함수를 쓰게.
- 기존 세이브: `trait` 없으면 `{}` → 지금까지 받은 추억이 그대로 포인트가 됨. 은퇴 횟수 보상 소급 지급.
- 밸런스: `tools/balance_sim.py`로 ① 은퇴 5·10·25회 유저의 61 도달 시간이 지금보다 빨라지되 너무 빨라지지 않는지(목표: 25회 유저 기준 한 회차 1~2일), ② 지름길로 추억 보정이 반복 이득을 막는지 확인. 조정한 값은 기획서에 적기.
- 검증: 특성 찍기·잠김·초기화(무료→이삭 100), 은퇴 후 특성 유지, 지름길 시작 영지(최고 영지 절반 제한, 영지 1부터 선택), 추억 보정 계산, 은퇴 조건(이번 회차 10곳), 비상금·씨앗 지급, 회차별 대사, 보상 1회만·소급, 기존 세이브 불러오기, 화면 폭 320·360·390·430.

## 10. 밸런스 확인 (tools/retire_sim.py, 2026-10-22)
- 방법: `tools/sim/retire_sim.js` — 은퇴한 유저의 한 회차를 자동 전투 + 욕심쟁이 소비(동료 레벨·단련·상자)로 61까지 돌림. 마을·카드·모집 동료는 빼서 실제보다 약함(왕도 기획서 10장과 같은 방식). 은퇴 N회 유저의 추억은 「매번 61까지 + 왕도 보너스 3」으로 셈(지금 규칙 13개/회). 특성은 전투·여행 갈래부터 싼 단계 순서로 찍음. 시간은 **게임을 켜 둔 전투 시간**.
- ① 한 회차(시작 영지 → 61) 걸린 시간

  | 은퇴 | 지금 규칙 (영지 1부터) | 새 규칙 (지름길·특성) |
  |---|---|---|
  | 7~8회 | 60(발타사르)에서 막힘 | 60에서 막힘 |
  | 9회 | 막힘 (추억 117) | **5.3시간에 61** (추억 102) |
  | 10회 | 막힘 (추억 130) | 0.29시간 (17분) |
  | 25회 | 0.32시간 (19분) | 0.18시간 (11분) |

  - 해석: 특성(공격·체력 +24~32%, 보스 시간 +2~6초)이 발타사르 벽을 은퇴 약 2번 앞당김(지금 은퇴 약 11번 → 약 9번, 「1부 완결 약 10일」 → 약 8~9일). 그 뒤 회차는 지금도 새 규칙도 수십 분.
  - **「25회 유저 한 회차 1~2일」 목표는 특성 값으로는 맞출 수 없음**: 지금 규칙에서도 이미 19분(추억 +5%/개가 골드·능력치에 곱해져 초반 영지를 몇 분에 지나감). 회차 길이는 실제로는 하루 플레이 시간이 정함 → 9장 미정으로 넘김.
- ② 지름길 + 추억 보정이 반복 이득을 막는지 (시간당 추억, 왕도 보너스 제외)

  | 은퇴 | 보정 | 지름길로 30 시작 → 40에서 바로 은퇴 | 지금 규칙 가장 좋은 짧은 반복 (1 → 40) |
  |---|---|---|---|
  | 10회 | 처음 안(절반, ÷10) | 71.6 /시간 | 32.2 /시간 |
  | 25회 | 처음 안(절반, ÷10) | 127.1 /시간 | 46.2 /시간 |
  | 10회 | **조정(빼기, ÷5)** | **36.9 /시간** | 32.1 /시간 |
  | 25회 | **조정(빼기, ÷5)** | **62.8 /시간** | 39.6 /시간 |

  - 처음 안은 「건너뛰고 바로 은퇴」가 지금보다 2~3배 이득 → 보정을 「건너뛴 구간은 빼기」로 바꿈. 조정 뒤 1.1~1.6배(남는 차이는 영지 1~10이 원래 추억 0인 구간이라 건너뛰는 만큼 생기는 것 + 회고록 올림).
  - 대신 지름길로 61까지 가면 한 회차 추억이 13 → 9(+회고록) 정도로 줄고 시간은 절반 → 시간당은 비슷. 「영지 1부터 시작」을 고르면 지금처럼 다 받음.
- 다시 돌리기: `python3 -m http.server 8765` 뒤 `python3 tools/retire_sim.py 10,25 '{}' 12` (은퇴 횟수, BAL 덮어쓰기, 한 판 최대 시간, 보정 나누는 수 — 처음 안과 비교는 마지막에 `10`)

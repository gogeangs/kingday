# 정기 이벤트 「신년축제」 기획서

작성일: 2026-10-29 · 상태: **확정(대표님 「좋아. 정리해줘」) · 그림 16장 반영 · 웹 구현 2026-11-10 (8-1) · 앱은 안드로이드 0.0.8에서**
선택: ① 1/1~1/21(3주, **1월 1일 포함**)·상점 1/28까지 + 설날 보너스 2/6~2/8 ② 재화 「소원 등불」 + **윷놀이 판** + 매일 **복주머니** + 등불 상점 + 이벤트 출석 ③ 한정 동료 **양 수인 양봉가 「몽글이」**(2027 정미년 = 양의 해)
- 눈꽃제(`CONTENT_EVENT_SNOW.md`)에서 만드는 **이벤트 틀**(`EVT` 표·`kd_events` 서버 한 줄)을 그대로 씀. 이 기획서는 신년축제 표에 들어갈 내용만.

## 1. 목적
- 눈꽃제(12/11~12/31) 바로 다음 날인 **1월 1일 0시에 새해 축제가 시작**해, 12월 중순부터 1월 말까지 이벤트가 끊기지 않게.
- 눈꽃제(보스 싸움·미니게임)와 **다른 재미**: 한국 유저에게 익숙한 설 놀이 **윷놀이 판**(던지고 말 옮기기)과 매일 여는 **복주머니**.
- 설날(2/6~2/8)에도 들어올 이유(그림 없는 접속 선물).

## 2. 확정 내용 요약
**2027년 1월 1일 ~ 1월 21일** 동안 에르단 하늘에 소원 등불이 뜨는 「신년축제」가 열린다. 마물을 쓰러뜨리면 이벤트 재화 **「소원 등불」**이 떨어지고(하루 한도), 접속·전투로 모은 **윷**을 던져 **윷놀이 판**에서 말을 옮기며 칸마다 보상을 받는다(한 바퀴 돌 때마다 큰 보상). 매일 **복주머니** 1개를 무료로 열 수 있다(확률 공개). 등불은 **「등불 상점」**에서 한정 동료 **몽글이**(영웅 양봉가, 양 수인) 카드·테두리 「복 등불」·배지 「신년축제」 등으로 바꾼다. **1월 1일 당일**은 새해 인사 장면과 큰 선물. 상점은 1월 28일까지 열리고 그 뒤 등불은 사라진다. 설날 연휴 **2/6~2/8**에는 접속 선물(그림 없음).

### 3-3. 윷놀이 판
**윷 얻기**
| 곳 | 양 |
|---|---|
| 매일 접속 | **1개** (8-1에서 2 → 1) |
| 전투(켜 둔 사냥) 마물 100마리마다 | 1개 (하루 **2개**까지, 방치 처치는 세지 않음 · 8-1에서 3 → 2) |

| 모서리 칸(3곳) | 1개 |
| 새해 첫날 선물 | 5개 |
| 등불 상점 | 60 등불에 1개 (하루 5개까지) |
- (8-1) 윷판 한 바퀴 = 윷 약 6.5번(지름길 포함). 시뮬레이터: 매일 오는 유저 하루 약 4번 던짐·21일 **9~13바퀴**, 하루 1번 유저 약 2.5번·**6~9바퀴**(처음 목표 6~7 / 3~4보다 많지만 칸·완주 보상을 줄여 등불 총량을 맞춤).

**던지기** (실제 윷 4개를 던지는 것과 같은 확률, **확률 공개**)
| 결과 | 칸 | 확률 |
|---|---|---|
| 도 | 1 | 25% |
| 개 | 2 | 37.5% |
| 걸 | 3 | 25% |
| 윷 | 4 + **한 번 더** | 6.25% |
| 모 | 5 + **한 번 더** | 6.25% |
- 빽도는 넣지 않음(뒤로 가면 아쉬움만 큼).

**판** (실제 윷판과 같은 모양, 말은 카엘 말 하나)
- 바깥 20칸을 한 바퀴(출발점 = 오른쪽 아래, 시계 반대 방향). **모서리 칸(오른쪽 위·왼쪽 위)이나 가운데에 딱 멈추면 다음 번에 지름길**(가운데를 가로질러 빨리 출발점으로) — 실제 윷놀이처럼. (8-1) 왼쪽 아래 모서리는 실제 윷놀이처럼 지름길이 없음(바로 아래 줄로 출발점까지). 지나가기만 하면 꺾지 않음.
- 칸 종류
| 칸 | 보상 |
|---|---|
| 등불 칸(13곳) | 소원 등불 **10 / 20 / 30** (8-1에서 20/30/50 → 줄임) |
| 재료 칸(5곳) | 골드 1시간 / 광석 30 / 성유물 상자 2(2곳) |

### 3-9. 한정 동료 「몽글이」 (영웅 양봉가)
| 항목 | 값 |
|---|---|
| 콘셉트 | 양의 해에만 나타난다는 양 수인 소녀. 몸을 감싼 복슬복슬한 양털 속에서 꿀벌들이 겨울잠을 자고, 벌들과 함께 꿀을 나누며 새해 복을 빌어 줌. 말끝마다 「~메에」, 졸리면 아무 데서나 잠 |
| 등급·직업 | 영웅 · 양봉가 (같은 직업 일반 대비 약 1.30) |
| 스킬 「포근한 양털 구름」 | 양털 구름 속 벌떼가 깨어나 8초 동안 **원정대 공격 속도 +30%** (지금 공격 속도를 올리는 동료 스킬은 카엘 촌장 하나뿐이라 겹치지 않음) |
| 얻는 법 | 윷판 바퀴 보상·출석·등불 상점·복주머니(1%) 카드 30장 → 합류 장면 → 「바로 출전」. 일반 카드 뽑기엔 안 나옴. ★은 몽글이 카드로만 |
| 다음 해 | 다음 신년축제에서 다시 카드를 얻어 ★ 올리기 |

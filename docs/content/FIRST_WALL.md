# 첫 막힘 기획서 (초안 · 대표님 결정 필요)

작성일: 2026-10-23 · 상태: **C안으로 결정 (2026-10-23 대표님) · 구현 완료**
근거: UX 전체 점검 17번, 리뷰 1·2회차 문제 4번 「첫날 진행이 너무 빨라 탑·던전·은퇴가 첫 판에 다 열림」

## 1. 목적
- 처음 온 사람이 **첫날 한 번은 막혀서** 강화·동료·마을을 둘러보게 한다(막힘 = 다른 콘텐츠를 배우는 때).
- 탑·던전(영지 20)·은퇴(영지 20 + 10곳)가 「첫 판 20분」이 아니라 「첫날 끝 ~ 둘째 날」에 열리게.

## 2. 지금 숫자
| 측정 | 영지 10 | 영지 20 | 영지 30 | 첫 막힘 |
|---|---|---|---|---|
| 리뷰 2·3회차 (실제 화면, 8분에 껐다 켬) | 약 5분 | 약 9~10분 | 약 16분 | 없음 (21분에 영지 36~39) |
| `tools/balance_sim.py 1.5` (출석·방치 보상 없이, 가장 싼 것부터 사기) | 6분 | 33분 | 1시간 30분 넘음 | 영지 30 |

- 차이의 대부분은 **8분에 다시 켰을 때 받는 골드(방치 최대 시간분 + 출석 1시간분 ≈ 9만, 그때 가진 골드의 약 30~100배)**. 이 골드로 상자·강화를 한꺼번에 사서 영지 18 → 36을 막힘 없이 지나감.
- 군단장(영지 10·20·30…) 체력을 올려도 출석 골드가 그대로면 막힘이 몇 분 늦춰질 뿐(시뮬: 군단장 체력 ×2 → 영지 10 도달 6분 → 7분, ×3 → 14분).

## 3. 안 (하나 고르기)
| 안 | 바꾸는 것 | 기대 | 걱정 |
|---|---|---|---|
| **A (추천)** | 첫 은퇴 전에는 방치 보상 최대 시간을 **6시간+여관 → 2시간+여관**으로 · 출석 7일 판 1일째 골드 꾸러미(1시간분)를 **상자 무료권 3장**으로 | 8분에 받는 골드가 약 9만 → 약 2만 5천(2시간분). 실제 플레이가 시뮬(영지 20 ≈ 30분)에 가까워짐. 여관을 지을 이유가 생김 | 「다시 켰는데 보상이 작다」는 느낌 → 창에 「여관을 지으면 더 오래 쌓여요」 안내 |
| B | 군단장 체력 ×12 → ×24 (영지 10·20·30…) | 군단장마다 1~3분 막힘. 할 일 「추천 강화 하기」가 그때 나옴 | 출석 골드로 바로 뚫려서 첫날 효과는 작음. 은퇴한 유저도 같이 어려워짐 |
| C | 그대로 두고 막힘 대신 「첫 은퇴」를 일찍 권함(영지 25에서 은퇴 안내 창) | 숫자는 그대로, 은퇴 루프를 일찍 배움 | 「첫날에 다 열림」 문제는 그대로 |

## 4. 화면·대사 (A안일 때)
- 방치 보상 창 아래 줄: 「최대 2시간 · 여관을 재건하면 더 오래 쌓여요」 (여관 0일 때)
- 출석 1일째 칸: 골드 꾸러미 그림 → 상자 무료권 그림, 이름 「성유물 상자 무료권 3장」

## 5. 저장 데이터
- 새 필드 없음 (첫 은퇴 전 여부는 `S.retires`, 여관은 `S.bld.inn`).

## 6. 검증 (고른 뒤)
- 폭 360 새 게임 20분 Playwright(8분에 껐다 켬): 영지 20 도달 시각, 처음 1분 넘게 같은 영지에 머문 곳, 할 일 길잡이가 그때 무엇을 보여 주는지
- `tools/balance_sim.py`와 비교

## 7. 결정 · 구현 (C안)
- 숫자(방치 보상·출석·체력 공식)는 그대로.
- **은퇴 전, 처음 영지 25를 되찾으면 한 번** 루미나르가 은퇴를 권하는 창(`S.done.retHint`, 웹 `retHint`·앱 `_retHint`). 같은 때 다른 새 소식이 있으면 「새 소식」 한 장에 같이.
- 버튼: 노란 「은퇴 계획 보기」 → 단련 탭 「카엘의 은퇴 계획」 상자로 내림 / 「나중에」.
- 대사: 루미나르 「마족이 점점 단단해지는 게 느껴지지 않나?」 → 카엘 「…이제 은퇴해도 된다는 뜻?」 → 루미나르 「잠깐 쉬었다 오라는 뜻이다 … 다시 끌려 나오겠지만」 → 카엘 「끌려 나오는 건 확정이구나」 + 은퇴하면 남는 것·추억 +5%·첫 은퇴 뒤 「태초」 안내.
- 할 일 길잡이 「단련 탭에서 첫 은퇴를 해 봐요」는 그대로 이어짐.
- 첫날이 빠른 문제(A·B안)는 출시 후 데이터를 보고 다시 검토.

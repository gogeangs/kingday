# 정기 이벤트 「눈꽃제」 기획서

작성일: 2026-10-28 · 상태: **확정(대표님 「추천 내용으로 진행」), 그림·구현 대기** · 22:35 수정: 기간 12/11~12/31(신년축제가 1/1부터) + **크리스마스 주간(12/21~25)·미니게임 「선물 배달」·미니게임 랭킹(필수)** 추가
선택: ① 12/11~12/31(3주)·서버 설정으로 켜고 끔 ② B안(눈송이·눈꽃 상점·이벤트 출석 + 한정 보스 「눈사람 대장」 + 한정 동료 1명) ③ 끝난 뒤 한정 보상은 **다음 겨울 눈꽃제에서 다시 얻을 수 있음**

## 1. 목적
- 출시 뒤 첫 겨울에 **다시 들어올 이유**(매일 보스 3번·출석·상점)와 **모으는 재미**(한정 동료·테두리·배지)를 준다.
- 처음 만드는 「기간 한정 이벤트」이므로 **다시 쓸 수 있는 이벤트 틀**로 만든다 → 설날·봄꽃제·추수제는 그림·이름·숫자 표만 바꿔 씀.
- 앱 재심사 없이 날짜를 켜고 끌 수 있게 **서버 설정**으로.

## 2. 확정 내용 요약
**12월 11일 ~ 12월 31일(21일)** 동안 에르단에 첫눈이 내리고 「눈꽃제」가 열린다. 전투 화면에 눈이 내리고, 마물을 쓰러뜨리면 이벤트 재화 **「눈송이」**가 떨어진다(하루 한도). 도전 탭의 **「눈사람 대장」**(하루 3번, 이길수록 단계가 오르는 보스)과 **이벤트 출석 14칸**으로 눈송이를 더 모으고, **「눈꽃 상점」**에서 한정 동료 **소복이**(영웅 광부·얼음 조각가) 카드, 테두리 「눈꽃 왕관」, 배지 「눈꽃제」, 전설 만능 카드·황금 이삭 등으로 바꾼다. 크리스마스 주간(12/21~25)에는 산타 피트의 선물·산타 눈사람 대장·마을 트리와 미니게임 **「선물 배달」(점수 랭킹 + 순위 보상)**이 열린다. 이벤트가 끝나도 **1주일(1/7까지) 동안 상점은 열려 있고**(1/1부터는 신년축제가 따로 시작), 그 뒤 눈송이는 사라진다. 한정 보상은 다음 겨울 눈꽃제에 다시 나온다.

### 3-2. 눈송이 (이벤트 재화)
| 얻는 곳 | 양 | 하루 한도 |
|---|---|---|
| 전투(마물 처치, 방치 포함) | 처치 25마리마다 1 | **100** |
| 눈사람 대장(하루 3번) | 이기면 20 + 단계×2 (최대 60) · 져도 10 | 약 120~180 |
| 이벤트 출석 | 3-4 표 | 20~100 |
| 원정 일지(패스) 점수 | 이벤트 중 「눈사람 대장 도전」을 점수 항목에 추가(1번 +20점) | — |
- 매일 들어오는 유저 기준 21일 동안 **약 4,000~4,500**, 하루 한 번만 오는 유저 **약 2,000** (시뮬레이터로 확인해 상점 가격만 조정).
- 이벤트 끝 + 1주 뒤 남은 눈송이는 사라짐(사라지기 3일 전 알림 「눈송이를 써 주세요」).

### 3-3. 눈사람 대장 (기간 한정 보스)
| 항목 | 값 |
|---|---|
| 들어가는 곳 | 도전 탭 맨 위 「눈꽃제」 칸 + 이벤트 창 「도전하기」 |
| 횟수 | 하루 3번(광고 보면 +1, 하루 1번) |
| 전투 | 30초 안에 처치. 배경은 하른 설원(북방) 배경 재사용 |
| 단계 | 1단계부터, 이기면 다음 단계. 체력은 **내 최고 영지 기준**(단계 1 = 최고 영지 성주의 0.8배, 단계마다 ×1.15) → 누구나 처음 몇 번은 이기고, 점점 막힘 |
| 보상 | 눈송이(3-2) · 5단계마다 첫 돌파 보상(황금 이삭 30 / 10단계마다 전설 만능 카드 2) |
| 기술 | 「눈덩이 굴리기」 10초마다 앞줄 동료에게 큰 피해 + 2초 느려짐(경고 표시 1초 전) |
| 기록 | 이번 눈꽃제 최고 단계 → 이벤트 창에 표시 (랭킹은 이번엔 안 함, 9장) |

### 3-4. 이벤트 출석 14칸 (21일 안에 14번 받으면 끝)
| 칸 | 보상 |
|---|---|
| 1~6, 8~13 | 눈송이 20 (짝수 칸은 + 골드 1시간) |
| 7 | 눈송이 100 + 동료 카드 10장 |
| 14 | 눈송이 100 + **소복이 카드 10장** |
- 기존 출석부(7일·한달)와 따로, 이벤트 창 안에 있음. 광고 2배 없음.

### 3-5. 눈꽃 상점 (눈송이로 교환, 개수 제한)
| 상품 | 가격 | 한도 |
|---|---|---|
| **소복이 카드 10장** | 400 | 3번 (출석 10장 + 상점 30장 = 40장 → 합류 30장 + ★ 일부) |
| 테두리 「눈꽃 왕관」 | 600 | 1번 |
| 배지 「눈꽃제」 | 200 | 1번 |
| 전설 만능 카드 5장 | 500 | 2번 |
| 황금 이삭 50 | 150 | 5번 |
| 성유물 상자 5개 | 100 | 5번 |
| 광석 50 | 50 | 10번 |
| 골드 2시간분 | 30 | 10번 |
- 전부 사면 5,050 → 매일 오는 유저는 **소복이·테두리·배지는 확실히**, 나머지는 골라서. 하루 한 번 유저도 소복이 합류(출석 10 + 상점 2번 = 30장)는 가능하게.
- 다음 겨울: 같은 상점이 다시 열려 **소복이 ★ 올리기 카드**를 계속 살 수 있음, 테두리·배지는 못 받은 사람만.

### 3-9. 미니게임 「선물 배달」 (크리스마스 주간에만)
- **하는 법**: 카엘이 썰매를 타고 밤하늘을 날고, 아래로 눈 덮인 집들이 오른쪽에서 왼쪽으로 지나감. **화면을 누르면 선물 상자가 떨어지고, 굴뚝에 들어가면 점수.** 지붕·땅에 떨어지면 점수 없음(연속 끊김).
- **점수**: 굴뚝 1개 = 10점 × 연속 배수(연속 5번마다 +1배, 최대 5배). 굴뚝 한가운데 「딱 맞음」이면 +5점.
- **어려움**: 30초. 시간이 갈수록 집이 빨라지고, 굴뚝 높이·간격이 달라짐. 가끔 「황금 굴뚝」(30점) · 「장작 연기 굴뚝」(넣으면 연속 끊김).
- **횟수**: 하루 3판(광고 보면 +1판, 하루 1번). 연습판(보상·기록 없음)은 무제한.
- **보상(판마다)**: 점수 ÷ 10 = 눈송이, 최대 100.
- **조작**: 누르기 하나. 화면 폭 320에서도 집 3채 이상 보이게, 선물 떨어지는 시간은 약 0.6초(굴뚝이 오기 「조금 전」에 눌러야 함), 처음 판에 「굴뚝이 오기 조금 전에 눌러요」 안내 손가락.

## 4. 화면 흐름
1. **이벤트 시작 날 처음 접속**: 시작 장면(5-1, 일러스트) → 「눈꽃제가 열렸어요」 창 → 이벤트 창으로.
2. **상단**: 이벤트 기간 동안 오른쪽 위 상점 버튼 옆에 **눈꽃제 버튼**(눈송이 아이콘 + 남은 날 「D-12」) · 받을 것(출석·도전 남음)이 있으면 노란 점.
3. **이벤트 창**(맨 위 배너 hd_snow): 내 눈송이 · 오늘 전투 눈송이 ○/100 · 탭 3개 「출석」「눈사람 대장」「눈꽃 상점」.
4. **눈사람 대장 탭**: 오늘 남은 도전 ○/3 · 다음 단계 · 최고 단계 · 「도전하기」(광고 +1 버튼).
5. **눈꽃 상점 탭**: 상품 칸(남은 한도), 소복이 칸은 맨 위 금테 + 「합류까지 ○장」.
6. **도전 탭**: 탑·던전 위에 「눈꽃제 · 눈사람 대장」 칸(기간에만). 크리스마스 주간엔 「선물 배달」 칸도.
6-1. **크리스마스 주간**: 이벤트 창에 탭 「선물 배달」 추가(오늘 남은 판 ○/3 · 내 최고 점수·순위 · 「시작」·「연습」·「랭킹」) · 마을 광장 트리 · 25일 접속 때 산타 피트 큰 선물 창 · 12/26 첫 접속 때 랭킹 결과 창(순위·보상은 우편)
7. **이벤트 끝 뒤 1주**: 버튼은 「상점만 열림 D-○」, 출석·보스 탭 잠김. 그 뒤 버튼 사라짐.

## 7. 저장 데이터·서버
```
ev: {
  id: 'snow2026',          // 지금 이벤트 id (다른 id가 오면 아래 값을 새로 시작)
  sf: 0,                   // 눈송이
  day: { d: '', bat: 0 },  // 오늘 전투 눈송이
  boss: { d: '', n: 0, ad: 0, st: 1, best: 0, mile: {} }, // 오늘 도전 횟수·광고·지금 단계·최고·단계 보상 받음
  att: { last: '', cnt: 0 }, // 이벤트 출석
  shop: {},                // 상품별 산 횟수
  seen: { start: 0, end: 0, xmas: 0, mgEnd: 0 },
  xm: { gift: {}, tree: '', days: {} },     // 크리스마스 주간: 피트 선물 받은 날·트리 누른 날·접속한 날
  mg: { d: '', n: 0, ad: 0, best: 0 }       // 선물 배달: 오늘 판 수·광고·최고 점수(서버 기록이 기준)
}
evOwn: { frame_snow: 1, badge_snow: 1 } // 이벤트가 바뀌어도 남는 것 (테두리·배지는 기존 프로필 저장에)
```
- 소복이 카드·합류·★은 기존 동료 저장 그대로.
- 서버: 표 `kd_events`(id, start_at, end_at, shop_end_at, 읽기만 공개) + 처음 한 줄(`snow2026`) + 미니게임 랭킹(3-10, `stage11_minigame.sql`). **기존 표·함수는 바꾸지 않음**. 서버를 못 읽으면 코드 기본값(랭킹은 「연결 안 됨」 표시, 판은 할 수 있음·기록은 다음 접속 때 제출 안 함).
- 웹·앱 같은 필드. **앱은 심사 통과 뒤 12월 초 업데이트에 넣기**(웹 먼저).

## 8. 구현 메모·검증
- **이벤트 틀**: `EVT` 표 하나(이벤트 id·이름·재화·출석 표·보스·상점·그림 이름)로 만들고, 화면·저장은 표만 읽게 → 다음 이벤트는 표 하나 추가.
- 미리 보기: `?demo=snow`(기간 무시하고 이벤트 켬), `?demo=xmas`(크리스마스 주간 켬), `?demo=mg`(선물 배달 바로 시작) — 저장 안 섞이게, 대표님 테스트용.
- 선물 배달: 같은 시간 단위(프레임 수와 무관)로 움직여 기기 속도가 점수에 영향 없게. 점수 계산은 웹·앱 같게(나중 앱 반영 때 비교 시험).
- 밸런스: `tools/balance_sim.py`에 이벤트 21일 추가 → 매일 오는 유저·하루 1번 유저 눈송이 총량(목표 4,000~4,500 / 약 2,000), 하루 1번 유저 소복이 합류 가능 확인, 눈사람 대장 단계 진행(첫 3일은 매번 이김, 2주 뒤 하루 1~2번 이김) → 가격·단계 배율만 조정해 기획서에 적기.
- 검증: 기간 전·중·상점만·끝 4가지 화면, 영지 10 미만 잠김, 시계 되돌림, 전투 눈송이 하루 100(방치 포함), 보스 3번 + 광고 1번·단계·5단계 보상, 출석 14칸(21일 안), 상점 한도, 소복이 30장 합류·스킬·★, 테두리·배지, 눈송이 사라짐 알림, 다음 id로 바뀌면 새로 시작, 눈 내리는 효과·효과 줄이기, 크리스마스 주간 5일(피트 선물·25일 큰 선물·트리·산타 눈사람 2배·배지 3일), 선물 배달(굴뚝 판정·연속 배수·황금/연기 굴뚝·하루 3판+광고·연습판·눈송이 최대 100), 랭킹(제출·위 100·내 순위·부정 기록 거절·12/26 정산 우편·결과 창), 화면 폭 320·360·390·430.

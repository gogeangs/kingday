# 출석체크 기획서 (확정)

작성일: 2026-10-21 · 상태: **웹 구현 완료** (앱은 같은 필드명·규칙으로 다음 단계)
선택: 한달 판 = 매달 1일 새로 시작 / 보상 = 초안대로 / 광고 보고 2배 = 넣기

## 1. 목적
- 매일 한 번 들어올 이유를 만든다(출시 첫 주·첫 달 재방문).
- 보상은 정기 배송(하루 이삭 100)보다 확실히 작게. 지금 하루 무료 이삭 ≈ 65(오늘의 할 일 50 + 광고 15).

## 2. 확정 내용 요약
하루 한 번 출석하면 **7일 판과 한달 판에 동시에 도장**이 찍힌다. 빠진 날이 있어도 처음으로 돌아가지 않고 다음 칸에 이어 찍는다(누적형). 7일 판은 7칸을 채우면 1칸부터 다시 반복. 한달 판은 **매달 1일 0시(기기 날짜)에 새로 시작**하고 그 달 출석 횟수만큼 칸이 찬다. 그날 처음 들어오면 출석 창이 자동으로 뜨고, 상단 바 달력 아이콘으로 언제든 열 수 있다. 출석 창 위 탭으로 「7일」「한달」을 오간다. 광고를 보면 그날 받은 출석 보상을 한 번 더 받는다(2배).

## 3. 규칙·수치

### 3-1. 7일 판 (7칸, 반복)
| 칸 | 보상 | 메모 |
|---|---|---|
| 1 | 골드 꾸러미 | 방치 보상 **1시간분** (GOLDX 계산 방식과 같게) |
| 2 | 황금 이삭 10 | |
| 3 | 성유물 상자 무료 개봉권 3장 | 보관형, 장비 탭에서 상자 열 때 골드 대신 먼저 사용 |
| 4 | 광석 20 | |
| 5 | 황금 이삭 10 | |
| 6 | 동료 카드 3장 | `gainCard(3)`. 받을 카드가 없으면 이삭 30으로 대체 |
| 7 | 황금 이삭 30 + 상자 10연속 무료권 1장 | 10연속 규칙(영웅 이상 1개 확정) 그대로 |
- 한 바퀴 이삭 50, 한 달(약 4.3바퀴) 약 215.

### 3-2. 한달 판 (최대 31칸, 매달 1일 초기화)
| 칸 | 보상 |
|---|---|
| 1·4·10·13·17·20·24·27 | 골드 꾸러미 (방치 보상 30분분) |
| 2·5·9·12·16·19·23·26 | 씨앗 묶음 (밀 5 · 은빛 당근 3 · 달빛 호박 1) |
| 3·6·8·11·15·18·22·25 | 광석 10 |
| **7** | 동료 카드 10장 (`gainCard(10)`, 없으면 이삭 100) |
| **14** | 황금 이삭 100 |
| **21** | 영웅 이상 동료 카드 10장 (`gainCard(10,'epic')`, 없으면 일반 카드 → 그것도 없으면 이삭 100) |
| **28** | 황금 이삭 100 + **그달 출석 배지** (프로필 배지) |
| 29·30·31 | 골드 꾸러미 (방치 보상 1시간분) |
- 큰 보상 칸(7·14·21·28)은 판에서 크게, 금테로 표시.
- 한 달 이삭 약 200(+대체 지급분). 7일 판과 합쳐 **약 415/월** (광고 2배 제외). 정기 배송 한 달 3,300의 1/8 수준.
- 28회 출석 = 그 달에 최대 (그달 일수 − 28)일까지 빠져도 배지 획득 가능. 2월은 개근해야 함 — 의도된 난이도로 둔다.

### 3-3. 출석 배지
- 프로필 배지에 「○월 출석」 추가(id `att_YYYYMM`). 한 번 받으면 영구 보관.
- 그림은 월별 테마. 그림이 없는 달은 공용 배지 그림 + 이름만 「2027년 3월 출석」.

### 3-4. 광고 2배
- 출석 후 같은 창에 「▶ 광고 보고 한 번 더 받기」 버튼. 하루 1회(`ADS.att={n:1,t:'출석 보상 2배'}`).
- 그날 두 판에서 받은 보상을 **한 번 더 지급**. 단, **출석 배지는 두 번 주지 않는다**(이삭 100은 2배 적용).
- 보상은 광고 SDK의 「보상 지급」 콜백에서만 지급(웹은 지금의 `watchAd` 흐름 사용).

### 3-5. 날짜 규칙
- 날짜 기준은 지금 게임과 같은 기기 날짜 `today()`(자정 초기화).
- **시계 되돌리기 방지**: 마지막 출석 날짜보다 이른 날짜면 출석 불가 + 안내 「날짜가 이상해요. 휴대폰 시간을 확인해 주세요.」
  - 주의: `today()` 문자열은 0을 붙이지 않음(`2026-1-5`). 비교는 반드시 숫자(연·월·일)로 바꿔서.
- 앞으로 날짜를 당겨 미리 받은 경우는 막지 않는다(그 뒤 원래 날짜로 돌아오면 위 규칙으로 막힘).

## 4. 화면 흐름
1. 그날 처음 게임을 열면 대기열(`queue`)에서 **방치 보상 창 다음**에 출석 창이 뜬다. 튜토리얼 초반(1-3 이전)에는 뜨지 않고 1-3 도달 후 첫 접속부터.
2. 출석 창
   - 머리 장식 배너 「피트의 출석부」
   - 탭 2개: **7일**(기본) · **한달**. 마지막으로 본 탭 기억.
   - 7일 판: 칸 7개(7칸째 크게). 한달 판: 7×5 달력 격자, 큰 보상 칸 금테, 맨 위에 「10월 · 이번 달 12회 출석」과 다음 큰 보상까지 남은 횟수.
   - 오늘 칸이 반짝임 → 「출석하기」 버튼 → 도장이 쾅 찍히는 애니메이션 + 진동 → 받은 보상 목록 표시(두 판 합쳐서).
   - 받은 뒤 버튼이 「▶ 광고 보고 한 번 더 받기」로 바뀜 → 받은 뒤 「내일 또 만나요」(비활성).
3. 상단 바에 달력 아이콘. 오늘 아직 출석 안 했으면 노란 점(`gemDot`과 같은 방식). 누르면 출석 창.
4. 지금 영지가 1-3 이전이면 아이콘 숨김.

## 5. 대사·텍스트 (피트 말투)
- 창 제목: 피트의 출석부
- 처음 열 때(1회): `m:피트|어서 와요, 영주님! 오늘부터 출석부를 만들었어요. 하루 한 번 얼굴만 보여 주시면 선물을 챙겨 드릴게요.` / `k@smile:얼굴만 보여 주면 된다고? 그건 은퇴하고도 할 수 있겠네.` / `q:주인, 출석도 왕의 덕목이다.`
- 출석 직후 토스트: 「출석 완료! 7일 판 ○일째 · 이번 달 ○회째」
- 7칸째 받을 때: `m:피트|일주일 개근! 특별히 상자 10번 여는 표를 넣었어요.`
- 28회째 받을 때: `m:피트|이번 달 출석부를 다 채우셨네요! 이 배지는 아무나 못 받아요.`
- 광고 버튼: 「▶ 광고 보고 한 번 더 받기」 / 받은 뒤 토스트 「피트가 한 번 더 챙겨 줬어요」
- 이미 받음: 「오늘은 이미 받았어요. 내일 자정에 또 만나요」
- 날짜 오류: 「날짜가 이상해요. 휴대폰 시간을 확인해 주세요.」

## 7. 저장 데이터·서버
- 저장 필드(`S`에 추가, `fresh()`·`hydrate()`에 기본값):
```
att: {
  last: '',            // 마지막 출석 날짜 today() 형식
  w: 0,                // 7일 판 다음 칸 (0~6)
  ym: '',              // 한달 판 기준 연-월 '2026-10'
  m: 0,                // 이번 달 출석 횟수
  ad: '',              // 광고 2배 받은 날짜
  got: [],             // 오늘 받은 보상 목록(2배 지급용)
  intro: 0,            // 처음 대사 봤는지
  tab: 'w'             // 마지막으로 본 탭
}
tickets: { box: 0, box10: 0 }   // 상자 무료권
```
- 출석 배지: 기존 프로필 배지 목록에 `att_YYYYMM` 추가 방식(받은 배지 저장 필드 재사용).
- 서버(Supabase): **변경 없음.** 클라우드 저장에 `S`째로 들어가므로 자동으로 같이 저장됨.
- 웹과 앱은 같은 `S`를 쓰므로 **두 버전 모두 같은 필드명·같은 규칙**으로 구현.

## 8. 구현 메모·검증
- 웹 `index.html` 먼저. 앱(`app/`)은 브랜치 병합 후 같은 규칙으로.
- 무료 개봉권은 `openBox()`에서 골드 차감 전에 `tickets.box` 확인. 10연속권은 10연속 버튼에서.
- 검증
  - 날짜를 하루씩 바꿔 가며 7일 판이 8일째에 1칸으로 돌아가는지, 한달 판이 다음 달 1일에 0으로 초기화되는지
  - 하루 건너뛰어도 칸이 이어지는지, 같은 날 두 번 못 받는지
  - 날짜를 뒤로 돌리면 막히는지(`2026-1-5` 같은 0 없는 형식 포함)
  - 광고 2배: 배지는 한 번만, 하루 1회만
  - 카드 대체 지급(합류 전·모든 카드 만렙일 때)
  - 화면 폭 320·360·390·430에서 한달 판 격자가 넘치지 않는지
  - 클라우드 저장 → 다른 기기 불러오기 후 출석 상태 유지

### V-W1 에르단 대륙 지도 → `assets/map/world_map.jpg`
```
[첨부 그림] 우리 게임 「왕이 되는 그날까지」의 마을 지도야. 이 그림과 같은 화풍(밝고 선명한 판타지, 굵고 깔끔한 외곽선, 셀 셰이딩)으로 대륙 지도를 그려 줘.

[요청] 에르단 대륙 전체를 비스듬히 위에서 내려다본 판타지 세계 지도 한 장
- 크기: 세로로 조금 긴 그림 (가로 1024 × 세로 1536), 꽉 찬 그림
- 글자·숫자·지명·로고·워터마크 절대 넣지 말 것. 안개·구름으로 땅을 가리지 말 것(안개는 게임에서 따로 덮어)
- 한 줄기 흙길이 맨 아래 마을에서 시작해 아래 지역들을 지그재그로 모두 지나 맨 위 왕도까지 이어져야 해. 길은 끊기지 않고 또렷하게, 지역마다 길이 충분히 구불구불하게

[지역 배치] (아래에서 위로, 길이 지나는 순서)
1. 맨 아래(남쪽) 「에르단 평원」: 밝은 초록 들판, 밀밭, 굽이치는 강과 작은 다리. 맨 아래 가장자리에 빨간 지붕 집들이 모인 작은 시골 마을(길의 시작점). 평원 한쪽에 허수아비가 선 넓은 밀밭
2. 왼쪽 가운데 「어스름 숲」: 보랏빛이 도는 깊고 어두운 숲, 커다란 빛나는 버섯, 숲속에 작은 동굴 입구(고블린 소굴)
3. 오른쪽 가운데 「드워프 협곡」: 붉은 바위 협곡과 절벽, 광산 레일과 갱도 입구, 바위에 새긴 드워프 성문
4. 왼쪽 위(북서) 「서리 무덤」: 눈 덮인 땅, 얼음 바위, 기사들의 묘비가 늘어선 서리 묘지, 얼어붙은 호수
5. 오른쪽 위(북동) 「잿불 심연」: 검붉은 화산과 용암 강, 잿빛 땅, 붉게 빛나는 거대한 돌 문(마계의 문)
6. 맨 위 가운데 높은 고원 「왕도 아스테리온」: 하얀 성벽과 파란 지붕 첨탑이 모인 큰 왕성, 성으로 오르는 긴 돌계단(길의 끝)

[명소]
- 지도 한가운데(어스름 숲과 드워프 협곡 사이) 작은 언덕 위에 구름에 닿을 듯 높고 가는 회색 석탑 「시련의 탑」
- 지역마다 길가에 작은 마족 진지·폐허·제단 같은 표시가 드문드문(나중에 깃발을 꽂을 자리)

[가장자리]
- 지도 왼쪽과 오른쪽 가장자리는 푸른 바다
- 왼쪽 바다 멀리 섬 위의 거대한 나무, 오른쪽 바다 멀리 모래 언덕과 둥근 지붕 도시, 맨 위 산맥 너머 멀리 설산과 천막 — 셋 다 아주 작고 흐릿하게, 먼 곳처럼
- 지역 사이 경계는 강·산줄기·숲으로 자연스럽게
```

```

- 화풍: 밝고 선명한 판타지 게임 그림, 부드러운 셀 셰이딩, 굵지 않은 옅은 외곽선
- 배경: 완전 투명(PNG)
- 글자·숫자·로고·워터마크 절대 넣지 말 것

[요청] 위에서 내려다본 안개 구름 덩어리 6개를 3열 × 2행으로 (가로 1536 × 세로 1024, 덩어리끼리 넉넉히 떨어지게)

- 여러 장을 겹쳐 깔아도 자연스럽게 이어지는 모양
```

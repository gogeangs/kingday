# 상점·패스 기획서 — 「원정 일지」 시즌 패스 · 「영주의 첫걸음」 성장 패키지

작성일: 2026-10-23 · 상태: **확정, 구현 대기**
선택: 시즌 패스 ₩3,300 / 성장 패키지 ₩11,000 / 패스 무료 줄 넣기 / 기존 상품은 그대로
그림 프롬프트: 이 문서 6장

## 1. 목적
- 지금 상점은 이삭 꾸러미 6종 · 첫 거래 특가 · 정기 배송 · 카엘 촌장. **2주마다 돌아오는 결제 이유**(시즌 패스)와 **초반 결제를 끌어낼 상품**(성장 패키지)이 빠져 있다.
- 크게 늘리지 않는다: 새 상품은 2개, 새 할 일 없이 이미 하는 플레이로 패스가 오른다.

## 2. 확정 내용 요약
**원정 일지**는 2주 랭킹 시즌과 같은 날 시작·끝나는 20단계 패스다. 오늘의 할 일·영지 탈환·마물 처치·탑·던전·마을 주문·출석으로 점수가 쌓인다. 누구나 받는 **무료 줄**(골드·광석·씨앗·이삭 조금)과 ₩3,300으로 여는 **유료 줄**(이삭·동료 카드·상자 10연속권, 20단계 시즌 한정 테두리)이 있다. 시즌 중간에 사도 지난 단계 유료 보상을 한꺼번에 받는다. **영주의 첫걸음**은 계정당 1번 ₩11,000 상품으로, 사는 즉시 이삭 300을 주고 영지 10·20·30·40·50을 처음 되찾을 때마다 이삭을 더 준다(합계 2,800, 이삭 꾸러미 대비 약 4배). 이미 지난 영지 보상은 사자마자 받는다. 서버는 기존 결제 검증(`kd-iap`)에 상품 2개만 추가.

### 3-2. 영주의 첫걸음 (성장 패키지)
| 항목 | 값 |
|---|---|
| 가격 | ₩11,000 (스토어 상품 `kd_growth`, 비소모형 — 계정당 1번) |
| 열리는 때 | 영지 3 이후(튜토리얼 끝나고) 상점에 보임, 영지 50을 넘긴 뒤 사도 받을 것이 있으면 계속 판매 |
| 사는 즉시 | 이삭 300 |
| 영지 10 처음 탈환 | 이삭 300 |
| 영지 20 | 이삭 400 |
| 영지 30 | 이삭 500 |
| 영지 40 | 이삭 600 |
| 영지 50 | 이삭 700 |
- 합계 이삭 2,800(₩11,000 이삭 꾸러미 680의 약 4배).
- 「처음 탈환」은 `S.best` 기준 — 이미 지난 영지는 사자마자 받음, 은퇴해도 다시 받지 않음.
- 다 받으면 상점에서 사라짐.

- 강제 광고 없음 원칙 그대로.

## 4. 화면 흐름
1. **상점 맨 위에 「원정 일지」 배너**(`hd_pass`): 「시즌 ○ · ○일 남음 · 12/20단계」 + 진행 막대. 누르면 패스 창.
2. **패스 창**: 가로로 밀리는 20칸 두 줄(위 무료, 아래 유료). 받을 수 있는 칸은 반짝 + 「받기」, 유료 줄은 사기 전에 자물쇠. 맨 위에 「모두 받기」. 아래에 「오늘 얻은 점수」 목록(할 일별 ○/하루 최대). 유료 줄 사기 버튼 「₩3,300 원정 일지 열기」.
3. **성장 패키지 카드**: 상점 이삭 꾸러미 위에. 「영지 30/50 · 다음 보상 영지 40에서 이삭 600」, 산 뒤에는 받기 단계표.
4. 노란 점: 패스에 받을 보상이 있으면 상점 버튼·패스 배너에. 성장 패키지는 받을 것이 있을 때만.
5. 지도 탭 위쪽 탐험 막대 옆에 작은 「원정 일지 ○/20」 (누르면 패스 창) — 매일 보이게.

## 7. 저장 데이터·서버
```
pass: { s: 0,            // 시즌 번호
        pt: 0,           // 이번 시즌 점수
        paid: 0,         // 이번 시즌 유료 줄 열었는지
        got: { f: [], p: [] },  // 받은 단계
        day: { d: '', src: {} }, // 오늘 할 일별 얻은 점수(하루 한도)
        intro: 0 },
grow: { buy: 0, got: {} }  // 성장 패키지 구매·받은 단계 {0:1, 10:1, ...}
```
- 시즌 번호는 랭킹 시즌 계산(`seasonEnd()` 등)과 같은 값. 시즌이 바뀌면 남은 보상을 우편(로컬)으로 넘기고 `pass`를 새로.
- 결제: 스토어 상품 2개 추가 — `kd_pass` ₩3,300(관리형 소모성), `kd_growth` ₩11,000(관리형 비소모성). 서버 `kd-iap` 검증 함수에 상품 2개 추가(유료 줄은 시즌 번호와 함께 기록, 같은 시즌 중복 구매 막기). 웹·시험 모드는 지금처럼 바로 지급.
- `docs/RELEASE_NATIVE.md` 5-1 상품표에 2개 추가 → 대표님 할 일: 스토어 상품 등록.
- 웹·앱 같은 필드·같은 규칙.

## 8. 구현 메모·검증
- 점수 연결: 출석·오늘의 할 일·영지 보스 처치·마물 처치 수·탑 층·던전 입장/소탕·마을 주문 납품에 `passAdd(src, n)` 한 줄씩, 하루 한도는 `pass.day.src`.
- 밸런스: `tools/balance_sim.py`로 하루 2~3번 접속 유저가 20단계를 끝내는 날(목표 10~12일), 출석만 하는 유저(약 4~5단계)를 확인. 조정한 값은 기획서에 적기.
- 검증: 시즌 시작·중간 구매(지난 보상 한꺼번에)·하루 한도·시즌 끝 우편 넘기기·같은 시즌 중복 구매 막기·마감 3일 전 경고, 성장 패키지(영지 35에서 사면 10·20·30 즉시, 40·50 나중에, 은퇴 뒤 중복 없음, 다 받으면 사라짐), 동료 카드 받을 곳 없을 때 이삭 대체, 화면 폭 320·360·390·430에서 20칸 가로 밀기.

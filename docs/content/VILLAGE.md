# 마을 확장 「다시 살아나는 에르단 마을」 기획서

작성일: 2026-10-22 · 상태: **구현 완료(2026-10-23, 웹·앱)** (같은 날 추가: 브론의 대장간을 마을로 이전, 마을 일꾼, 마을 화면을 지도 한 장으로 개편 / 10-23: 새 주민 6명 → 원정대 동료·마을 사람으로 대체, 예배당 주인 리엘)
선택: 새 건물 4종(브론의 대장간 이전·시장·목장·예배당) / 마을 레벨·동료 마을 에피소드 넣기(새 주민 없이 원정대 동료와 기존 마을 사람으로 — 2026-10-23 변경) / 주문 보상에 이삭 소량(하루 최대 20) / 꾸미기는 나중에
선택(마을 일꾼): 출전하지 않는 동료만 / 아무 동료나, 잘 맞는 직업이면 2배 / 건물마다 1칸, 건물 Lv.5에 2칸 / 교체 자유
그림 프롬프트: `claude/ART_VILLAGE.md`

## 1. 목적
- 남는 생선·꿀·작물의 쓸 곳이 「창고 모두 판매」뿐 → **주문 게시판**으로 더 비싸게, 재미있게 쓰게 한다.
- 건물 6종을 다 지으면 마을에서 할 일이 끝남 → **새 건물 3종 + 마을 레벨**로 장기 목표를 만든다.
- 매일 들어올 이유 추가 → 주문 갱신, 예배당 축복.
- 「되찾은 땅에 사람이 돌아온다」는 세계관을 눈으로 보여 준다 → 마을 레벨마다 **동료 마을 에피소드**, 마을 길 위에 쉬는 동료와 마을 사람.
- 출전 4칸 밖에서 쉬는 동료가 많음 → **마을 일꾼**으로 일하게 해서 동료 수집·별 올리기의 쓸모를 늘린다.
- 장비 탭 안의 버튼이던 **브론의 대장간을 마을 건물로 옮겨**, 마을에서 키우는 건물로 만든다(대장간 레벨로 강화 한도·비용이 좋아짐).

## 2. 확정 내용 요약
마을 동쪽에 빈터 4칸이 생기고 **브론의 대장간(장비 탭에서 이사) · 피트의 시장(주문 게시판) · 목장 · 별빛 예배당**을 지을 수 있다. 대장간은 지금 기능(성유물 부위 강화 · 동료 무기)을 그대로 갖고, 대장간 레벨이 오르면 강화 한도가 늘고 광석 비용이 줄어든다. 시장에서는 주민들이 올린 주문(예: 생선 10 + 꿀 5)에 납품하면 그냥 파는 것보다 많은 골드와 광석·카드·이삭(하루 최대 20)을 받는다. 목장은 달걀·우유를 방치로 만들고, 새 요리 2종(우유 수프 · 달걀 호박전)이 생긴다. 예배당에서는 하루 1번(광고 +1번) 축복 3개 중 하나를 골라 몇 시간 동안 효과를 받는다. 모든 건물 레벨 합으로 **마을 레벨(1~10)**이 오르고, 레벨마다 보상과 함께 피난 갔던 **주민 5명**이 차례로 돌아온다. 마을 레벨은 방치 골드를 올려 주고, 돌아온 주민은 마을 화면에 서 있고 주문을 올린다. 또 출전하지 않는 동료를 건물마다 1~2명 **일꾼**으로 넣으면 그 건물의 주 효과가 오른다(등급·별에 따라, 잘 맞는 직업이면 2배). 서버 변경은 없다.

## 3. 규칙·수치

### 3-1. 새 건물 (`BLD`에 추가, 비용 식 `bldCost` 그대로 = base × 2.2^레벨, 광석 규칙 `bldOre` 그대로)
| k | 이름 | 주인 | 최대 | base | 열리는 조건 | 레벨 효과 |
|---|---|---|---|---|---|---|
| `forge` | 브론의 대장간 | 브론 | 10 | 1500 | 광산 Lv.1 (지금과 같음) | 성유물 강화·동료 무기 최대 단계 20 + floor(레벨÷2) (Lv.10 = 25), 강화 광석 비용 −3%/레벨 (Lv.10 −30%) |
| `market` | 피트의 시장 | 피트 | 10 | 800 | 영지 12 되찾기 | 주문 칸 2 + floor(레벨÷3) (최대 5칸), 주문 보상 골드 **+3%/레벨** (밸런스 조정, 처음 +5%) |
| `ranch` | 목장 | 마르타 | 10 | 1200 | 영지 18 + 밭 Lv.3 | 달걀 레벨개/3분, 우유 레벨병/6분 · 원정대 체력 +3%/레벨 |
| `chapel` | 별빛 예배당 | 리엘 (400살 요정) | 10 | 3000 | 영지 25 | 축복 시간 2시간 + 10분/레벨, Lv.5부터 축복 선택지 4개 |
- 공사 시간 식 `bldTime`, 공사 예약 규칙 그대로.
- **대장간 이사 규칙**
  - 기존 강화 기록(`S.slotEn`·`S.cwEn`)은 그대로 유지.
  - 기존 유저: 광산이 Lv.1 이상이면 업데이트 후 대장간을 **Lv.1로 공짜로 지어 줌** → 지금처럼 바로 쓸 수 있음. 대장간 Lv.1 = 지금 한도(20)·지금 비용과 똑같음(비용 감소는 Lv.2부터: −3% × (레벨−1)로 계산).
  - 새 유저: 광산을 지으면 대장간 빈터가 열리고, 재건해야 사용.
  - 장비 탭의 「브론의 대장간」 버튼은 **바로가기로 남김**(누르면 같은 대장간 창, 창 제목 위에 「마을 · 대장간 Lv.○」 표시). 대장간이 폐허면 「마을에서 대장간을 재건해요」 안내 후 마을 탭으로 이동.
  - 대장간 창의 기능·탭(성유물 강화 | 동료 무기)은 그대로, 마을 탭에서 대장간을 고르면 아래 창에 같은 내용.
- 새 재료: `egg` 달걀(판매 9), `milk` 우유(판매 16) → `GOODS`에 추가(`b:'ranch'`), 창고 판매·아이템 아이콘 동일 방식.

### 3-2. 피트의 시장 — 주문 게시판
| 항목 | 값 |
|---|---|
| 주문 칸 | 2~5칸 (시장 레벨) |
| 주문 내용 | 재료 1~2종. 지금 열린 재료(밀·당근·호박·생선·꿀·광석·달걀·우유)에서만. 수량 = 그 재료 2분 생산량 × 10~25 (낮은 레벨에서도 하루 안에 모을 수 있게) |
| 주문 올린 사람 | 합류한 동료 + 마을 사람(마르타·티모·피트) 중 무작위. 좋아하는 재료는 3-6 |
| 보상 | 골드 = 재료 판매가 합(`itemPrice`) × **1.6** × (1 + 시장 레벨 × 3% + 시장 일꾼 효과 ÷ 2) — 밸런스 조정(8-1), 처음 ×2·+5% |
| 덤 (주문마다 하나, 확률) | 광석 10~30 (40%) · 씨앗 묶음 (30%) · 동료 카드 2장 (15%) · **황금 이삭 3~5 (15%)** |
| 이삭 한도 | 하루 이삭 합 **최대 20**. 넘으면 이삭 대신 광석 |
| 새 주문 | 납품하거나 버린 칸은 **1시간 뒤** 새 주문. 접속하지 않아도 시간은 흐름 |
| 버리기 | 마음에 안 드는 주문은 「다른 주문 받기」: 칸마다 하루 1번 바로, 그다음은 1시간 기다림 |
- 납품 버튼은 재료가 다 있을 때만. 창고 「모두 판매」에 **「주문에 필요한 재료는 남기기」 체크 박스**(기본 켜짐) 추가.

### 3-5. 마을 레벨
- 마을 레벨 = 모든 건물 레벨 합(최대 86)에 따라:
| 마을 Lv | 건물 레벨 합 | 보상 | 동료 마을 에피소드 |
|---|---|---|---|
| 1 | 0 | — | — |
| 2 | 8 | 이삭 20 | ① 브론과 하랄의 힘자랑 |
| 3 | 16 | 이삭 20 | |
| 4 | 24 | 이삭 30 | ② 마고와 마르타의 국거리 다툼 |
| 5 | 32 | 이삭 30 + 배지 「마을의 영웅」 | |
| 6 | 40 | 이삭 40 | ③ 하랄의 고래 허풍과 티모 |
| 7 | 50 | 이삭 40 | |
| 8 | 60 | 이삭 50 | ④ 리엘의 별빛 이야기 |
| 9 | 70 | 이삭 50 | |
| 10 | 80 | 이삭 100 + 테두리 「에르단 마을」 | ⑤ 마을 잔치 |
- 에피소드는 늘 합류해 있는 이야기 동료(브론·하랄·리엘·마고)와 마을 사람(마르타·티모·피트)만 등장 → 누구나 볼 수 있음. 대사는 5-2.
- 마을 전체 보너스: **방치 골드 +2% × 마을 레벨** (최대 +20%).
- 은퇴해도 건물은 그대로라 마을 레벨도 유지(지금 은퇴 규칙과 같음).

### 3-6. 마을 사람 (새 주민 없음 — 원정대 동료 + 기존 마을 사람)
- **새 주민 캐릭터를 만들지 않는다.** 이미 그림(초상화·서 있는 그림)이 있는 원정대 동료와 마을 사람(마르타·티모·피트)이 마을을 채운다.
- **마을 길 위**: 일꾼이 아닌 **쉬는 동료**(출전·일꾼 아님) 중 최대 6명 + 마르타·티모·피트가 건물 사이 길에 서 있음(동료 대기 그림·마을 사람은 초상화를 작은 원으로, 살짝 흔들림). 매일 0시에 서 있는 동료가 바뀜. 초반에 동료가 적어도 마을 사람 3명은 늘 있음.
- **일꾼**: 건물 옆에 서서 일함(3-7).
- **누르면 한 줄 대사**: 이야기 동료 4명·마을 사람 3명은 전용 대사 3개씩, 그 밖의 동료는 직업별 마을 대사 3개 중 무작위(5-3).
- **주문을 올리는 사람과 좋아하는 재료**
| 주문자 | 좋아하는 재료 |
|---|---|
| 광부 동료 | 광석 |
| 어부 동료 | 생선 |
| 양봉가 동료 | 꿀 |
| 요리사 동료 | 달걀·우유·작물 |
| 마르타 | 밀·당근 |
| 티모 | 호박·우유 |
| 피트 | 아무 재료 |
- **예배당 주인은 리엘**: 400살 요정이 300년 전에도 있던 별빛 예배당을 다시 돌봄. 예배당 일꾼에 잘 맞는 직업(양봉가)과도 맞음. 리엘이 출전 중이어도 주인 역할(대사·축복 창 얼굴)은 그대로.
- 대장간 주인은 브론(일꾼 칸에는 다른 광부 동료를 넣음 — 브론 본인도 쉬는 중이면 넣을 수 있음).
- 「촌장」 자리는 비워 둔다(나중에 유니크 동료 「카엘 촌장」과 연결, `claude/COMPANION_CHONJANG.md`).

### 3-7. 마을 일꾼
**기본 규칙**
| 항목 | 값 |
|---|---|
| 열림 | 출전하지 않는 동료가 1명 이상 생기면(첫 모집 동료 합류 때) |
| 넣을 수 있는 동료 | **출전 편성에 없는 동료만**. 카엘은 안 됨. 한 동료는 한 건물에만 |
| 칸 수 | 건물마다 **1칸**, 그 건물 **Lv.5부터 2칸**. 폐허(Lv.0) 건물은 0칸 |
| 교체 | 언제든 자유, 비용·대기 없음 |
| 편성과의 관계 | 일하는 동료를 출전 편성에 넣으면 일꾼 칸에서 자동으로 빠짐(토스트 「○○이(가) 원정대로 돌아갔어요」). 추천 편성 버튼은 일꾼도 후보로 봄 |
| 은퇴 | 일꾼 배치 유지(동료 합류·별은 은퇴해도 남으므로) |

**일꾼 한 명의 효과**
- 기본 = 등급: 일반 10% · 희귀 15% · 영웅 20% · 전설 30%
- 별 하나당 +2% (예: 영웅 ★5 = 20 + 10 = 30%)
- **잘 맞는 직업이면 ×2** (예: 전설 광부 ★5를 광산에 = (30 + 10) × 2 = 80%)
- 동료 레벨·무기 강화는 영향 없음(전투용)
- 2칸이면 두 일꾼의 효과를 더함

**건물별로 오르는 것**
| 건물 | 일꾼 효과가 적용되는 것 | 잘 맞는 직업 | 비고 |
|---|---|---|---|
| 광산 | 광석 생산 +효과% | 광부 | |
| 대장간 | 강화 광석 비용 −(효과 ÷ 2)% | 광부 | 건물 레벨 감소와 합쳐 **최대 −50%** |
| 낚시터 | 생선 생산 +효과% | 어부 | |
| 시장 | 주문 보상 골드 +(효과 ÷ 2)% | 어부 | 밸런스 조정(8-1): 여관처럼 절반 |
| 양봉장 | 꿀 생산 +효과% | 양봉가 | |
| 예배당 | 축복 시간 +효과% | 양봉가 | |
| 식당 | 요리 버프 시간 +효과% | 요리사 | 덕배 마을 스킬·은퇴 특성과 더함 |
| 목장 | 달걀·우유 생산 +효과% | 요리사 | |
| 밭 | 작물 자라는 속도 +효과% | 없음(누구나 ×1) | |
| 여관 | 방치 골드 +(효과 ÷ 2)% | 없음(누구나 ×1) | 정기 배송(+50%)보다 커지지 않게 절반 |
- 생산은 지금 생산 식(레벨 × 개수/주기)에 (1 + 일꾼 합%)를 곱한다. 전설 동료의 마을 스킬(`vpMine` 등)과도 곱.
- 예시: 낚시터 Lv.10(생선 10마리/2분)에 영웅 어부 넬라 ★5(60%) + 희귀 어부 토비 ★4(46%) → 생선 21마리/2분.

**추천 일꾼**
- 마을 창 위쪽 「추천 일꾼」 버튼: 비어 있는 칸에 쉬는 동료를 효과가 큰 순서로 자동 배치(이미 넣은 일꾼은 그대로). 「모두 다시 배치」는 길게 누르기.

## 4. 화면 흐름

### 4-0. 마을 화면 구조 (개편: 한 장짜리 마을 지도)
선택: **3안 「위에서 내려다본 마을 지도 한 장」 + 공통 3가지(마을 할 일 줄 · 건물 창 탭 · 일꾼 관리)**. 지금의 「확대된 가로 배경을 좌우로 밀기」 방식은 없앤다.

위에서부터:
1. **마을 Lv 막대** — 「마을 Lv.○ · 방치 골드 +○%」, 다음 레벨까지 막대. 누르면 마을 레벨 창.
2. **마을 할 일 줄** — 할 일이 있을 때만 보이는 칩 한 줄(가로로 넘치면 옆으로 밀기):
   「🌾 수확 3」 「📋 납품 2」 「✨ 축복 받기」 「🏗 공사 완료」 「🔨 일꾼 빈칸」 「⚒ 강화 가능」 …
   - 칩을 누르면 그 건물을 선택(지도에서 반짝 + 아래 창 열림).
   - 「🌾 수확 3」 칩 옆에는 **「모두 수확」** 버튼(밭 화면에 가지 않고 바로 수확 + 빈 칸에 같은 씨앗 다시 심기).
3. **마을 지도** — 비스듬히 위에서 내려다본 마을 한 장(세로로 조금 긴 그림, 화면 폭에 꽉 차게, 밀기 없음). 건물 10채가 모두 한 화면에 보인다.
   - 건물마다 이름표(작게) + 상태 배지(「수확!」 「공사 2:10」 「주문 2」 「축복」 「🔨1」).
   - 잠긴 자리는 빈터 + 자물쇠, 폐허는 폐허 그림.
   - 쉬는 동료·마을 사람이 길 위에, 일꾼은 건물 옆에 서 있음(누르면 대사, 3-6).
   - 밤(19시~6시)에는 지금처럼 어둡게 + 창문 불빛.
   - 지도를 두 손가락으로 벌려 크게 보기(최대 2배)는 **나중에**(이번에는 한 화면 고정).
4. **「일꾼 관리」 「추천 일꾼」 버튼** 한 줄.
5. **건물 창** — 지도에서 건물을 누르면 아래에서 올라오는 반 창(⤢로 크게, 지금 장비·원정대 창과 같은 방식). 창 안은 **탭**으로 나눔:
   | 건물 | 탭 |
   |---|---|
   | 여관 · 식당 · 낚시터 · 양봉장 · 광산 · 목장 | 정보(레벨·효과·확장) · 일꾼 · (식당은 「부엌」) |
   | 밭 | 밭(심기·수확) · 정보 · 일꾼 |
   | 대장간 | 강화(성유물 · 동료 무기) · 정보 · 일꾼 |
   | 시장 | 주문 · 정보 · 일꾼 |
   | 예배당 | 축복 · 정보 · 일꾼 |
   - 기능 탭이 있는 건물은 기능 탭이 먼저 열림. 마지막으로 본 탭은 건물마다 기억.

### 4-2. 각 건물 기능 (탭 안 내용)
1. 대장간 「강화」 탭: 지금 대장간 창과 같은 내용(성유물 강화 | 동료 무기). 강화할 수 있으면 할 일 줄에 「⚒ 강화 가능」.
2. 시장 「주문」 탭: 칸마다 주문자(동료·마을 사람) 얼굴·이름·필요한 재료(가진 수/필요 수)·보상 미리보기·「납품」 / 「다른 주문」. 빈 칸은 「새 주문까지 ○분」.
3. 목장: 생산 정보(기존 낚시터와 같은 형식). 새 요리는 식당 「부엌」 탭에 추가.
4. 예배당 「축복」 탭: 카드 3(4)장 중 고르기, 받은 축복과 남은 시간, 광고 버튼. 받은 축복은 전투 화면 버프 줄에 표시.
5. 「일꾼」 탭: 일꾼 칸(1~2칸). 빈 칸 「+ 일꾼」 → 쉬는 동료 목록(얼굴·등급·별·직업, 「잘 맞음」, 「+○%」 미리보기, 효과 큰 순서) → 고르면 배치. 일꾼 칸을 누르면 「빼기 / 바꾸기」.
6. 원정대 탭 동료 카드: 일하는 동료에 「🔨 낚시터」 표시.

### 4-3. 일꾼 관리 창
- 표 한 장: 줄 = 건물 10채, 칸 = 일꾼 1·2(Lv.5 미만은 2번 칸 잠김), 오른쪽 끝에 그 건물 일꾼 효과 합 「+○%」.
- 칸을 누르면 그 자리 동료 고르기(4-2의 5번과 같은 목록).
- 아래에 「쉬는 동료 ○명」 얼굴 줄.
- 버튼: 「추천 일꾼」(빈 칸만 채움) · 「모두 다시 배치」 · 「모두 빼기」.

### 4-4. 노란 점 규칙 (마을 탭)
- 켜짐: 수확 가능 · 납품 가능 주문 · 축복 받기 · 공사 완료 · 강화 가능 · 마을 레벨 보상.
- 일꾼 빈칸은 할 일 줄에는 늘 보이지만, 노란 점은 하루 한 번만(한 번 열어 보면 그날은 꺼짐).

### 4-5. 마을 레벨이 오르면
- 보상 창 → (짝수 레벨) 동료 마을 에피소드 장면(5-2).

## 8-1. 밸런스 확인 결과 (2026-10-23, `python3 tools/balance_sim.py village`)
방법: `tools/sim/village_sim.js` — 웹 게임 함수를 그대로 써서 시험용 저장(mid 영지25 · late 영지46 · tr 영지61)에 건물 레벨을 바꿔 계산. 재료는 하루 24시간 생산(건물 생산 식 그대로), 작물은 하루 4시간 사냥하며 주운 씨앗만큼(밭이 감당하는 양 이하), 주문 확인은 깨어 있는 16시간 동안 2시간마다(하루 8번), 6시간 넘게 모아야 하는 주문은 하루 1번 「다른 주문」.

① 주문 골드 ÷ 같은 시간 사냥 골드(게임 켜 둔 시간 기준) — 목표 20~40%
| 상태 | 처음 값(×2, +5%/Lv) | **조정(×1.6, +3%/Lv, 시장 일꾼 ÷2)** |
|---|---|---|

| 영지25 · 시장 Lv.5 | 27~30% | **21~22%** |
| 영지46 · 시장 Lv.5 | 27~28% | **20~21%** |
| 영지46 · 시장 Lv.10 | 54~55% | **38~41%** |
| 영지61(1부 완결 뒤) · 시장 Lv.10 | 85~95% | 60~62% |
- 시장 Lv.10(칸 5개·보너스 최대)에서 40%를 넘어서 조정. 시장 Lv.1(칸 2개)은 낮지만 초반이라 그대로. 1부 완결 뒤(영지61)는 사냥 골드가 60단계에서 멈춰 비율이 높게 나옴(괜찮음).

② 마을 Lv.10(건물 레벨 합 80)까지 걸리는 시간 — 목표 은퇴 없이 3~4주, 은퇴 반복 2주

③ 이삭 하루 +20 상한 — 상점 균형

④ 일꾼 꽉 채움(동료 24명 모두 합류·별 최대, 출전은 이야기 동료 4명 → 쉬는 20명을 추천 일꾼으로)

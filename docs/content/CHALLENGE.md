# 도전 콘텐츠 (시련의 탑 · 요일 던전) 기획서

작성일: 2026-10-22 · 상태: **구현 완료 (웹·앱)** — 밸런스 조정 결과는 10장
선택: 탑 도전 횟수 제한 없음 / 탑 랭킹은 기록만(나중에) / 요일 던전에 동료 카드 없음
그림 프롬프트: `docs/content/ART_CHALLENGE.md` (claude.ai 프로젝트 `claude/ART_CHALLENGE.md`)

## 1. 목적
- 고성장 유저(왕도까지 간 유저 포함)에게 **끝없는 목표**를 준다 → 시련의 탑.
- 은퇴를 반복할 이유를 키운다 → 탑 층수는 은퇴해도 유지, 은퇴로 강해질수록 더 올라감.
- 부족한 재료(광석·씨앗·골드)를 매일 채울 곳을 만든다 → 요일 던전.
- 새 그림을 최소로: 보스·몬스터·배경은 기존 것을 다시 쓴다.

## 2. 확정 내용 요약
지도 탭에 **「도전」** 버튼을 둔다. 안에 두 가지가 있다. **시련의 탑**은 층마다 보스 한 마리와 싸우는 끝없는 탑으로, 도전 횟수 제한이 없고 실패해도 잃는 게 없다. 층수는 은퇴해도 남고, 층 첫 돌파 보상 + 최고 층에 비례하는 **매일 탑 보급**을 준다. **요일 던전**은 요일마다 광석·씨앗·골드 던전이 열리고, 하루 입장권 2장(광고 +1)으로 3분 동안 웨이브를 버틴다. 잡은 수로 별 1~3개, 별 3개를 받은 단계는 소탕할 수 있다. 서버 변경은 없다.

## 3. 규칙·수치

### 3-0. 공통
- 해금: **영지 20 탈환**(첫 은퇴가 가능해지는 시점) 때 「도전」이 열린다. 한 번 열리면 은퇴해도 계속 열림(`S.chOpen=1`).
- 도전 전투는 **본 진행과 따로**: 들어가면 지금 영지 진행(웨이브·보스)은 멈추고, 끝나면 원래 영지·웨이브로 돌아온다. 도전 중에는 방치 보상·황금 고블린이 나오지 않는다.
- 원정대 편성·능력치·스킬은 지금 그대로 사용.
- 전투 화면 위쪽에 「나가기」 버튼(확인 없이 바로 나감, 탑은 그 층 실패 처리, 던전은 그때까지 잡은 수로 정산).

### 3-1. 시련의 탑
| 항목 | 값 |
|---|---|
| 층 → 난이도 | 층 f = 영지 단계 **s = f + 5** 의 보스 수치 (`monHp(s,true)`, `monAtk(s,true)`). 1층 = 6단계 성주, 55층 = 60단계 수준, 그 위 끝없음 |
| 일반 층 | 보스 1마리, **30초** |
| 10층마다 「수문장」 | 군단장 수치(체력 ×12, 공격 ×3), **40초** |
| 5층마다(10층 제외) 「시련 규칙」 | 아래 표 중 하나, 순서대로 돌림 |
| 도전 횟수 | **제한 없음** |
| 실패 | 잃는 것 없음, 같은 층 다시 |
| 은퇴 | 층수 **유지** |

- 보스 그림: 지금 있는 보스를 층에 따라 돌려 쓴다. 일반 층은 7층 주기로 성주 5종(에르단~잿불) → 마왕 근위대장 → 잔영(군단장 5명 차례로). 10층 수문장은 군단장 5종을 차례로, 100층마다 발타사르(1단계 그림, 2단계 전환·봉인의 파동 없음).
- 이름: 「○층 · {보스 이름}」, 10층마다 「○층 수문장 · {군단장 이름}」.
- 수문장·시련 판정은 영지 단계가 아니라 **층 기준**(10층 = 수문장).

**시련 규칙 (5·15·25… 층에 차례로)**
| # | 이름 | 내용 |
|---|---|---|
| 1 | 회복 금지 | 원정대 회복 효과 0 (요리사 치유·스킬 회복·전투 중 자연 회복) |
| 2 | 쌍둥이 | 보스 2마리, 각각 체력 60% |
| 3 | 급한 전투 | 제한 시간 20초, 보스 체력 80% |
| 4 | 단단한 껍질 | 보스가 받는 피해 −50%, 대신 공격 −50% (스킬·광역보다 단일 큰 피해가 유리) |
- 화면에 규칙 이름·한 줄 설명을 전투 시작 때 띠로 보여 준다(도전 창에도 다음 층 규칙 표시).

**보상**
| 언제 | 보상 |
|---|---|
| 층 첫 돌파 | 골드 = `reward(s,true) × 3`, 광석 = 5 + floor(f/5) |
| 10층마다 첫 돌파 | + 황금 이삭 30 |
| 25층 | 배지 「탑 25층」 (`tower25`) |
| 50층 | 테두리 「시련의 탑」 (`tower`) |
| 100층 | 배지 「탑의 주인」 (`tower100`) |
| **매일 탑 보급** (하루 1회, 도전 창에서 받기) | 골드 = 방치 보상 **(30 + 최고 층)분** 어치, 최대 120분 / 광석 = 5 + floor(최고 층 ÷ 5) × 2 |
- 방치 보상 계산은 `offline()`의 식을 함수로 뺐다: `idleGold(sec)`(sec초 동안의 골드), `idleGoldPerSec()=idleGold(1)`. offline·탑 보급·고블린 금고가 같이 쓴다.
- 「소탕」은 탑에는 없다.
- 탑 랭킹: 이번에는 만들지 않는다. 최고 층은 프로필에 표시하고 클라우드 저장에 남긴다(나중에 랭킹 붙일 때 사용).

### 3-2. 요일 던전
| 요일 | 던전 | 몬스터(재사용) | 배경(재사용) | 보상 |
|---|---|---|---|---|
| 월·목 | 브론의 폐광 | 강철 골렘 `golem_steel` | 드워프 협곡 | 광석 |
| 화·금 | 마르타의 들판 | 저주받은 허수아비 `scarecrow_cursed` | 에르단 평원 | 씨앗 |
| 수·토 | 고블린 금고 | 곡괭이 고블린 `goblin_pick` + 황금 고블린 1번 | 어스름 숲 | 골드 |
| 일 | 셋 다 열림 | | | 고르기 |

| 항목 | 값 |
|---|---|
| 입장권 | 하루 2장(자정 초기화) + 광고 보고 1장(`ADS.dun={n:1,t:'던전 입장권 +1'}`) |
| 방식 | **3분** 동안 몬스터가 계속 몰려옴(화면에 3마리가 남도록 0.3초마다 채움). 원정대가 모두 쓰러지면 그때 끝 |
| 던전 단계 L | floor(최고 영지 ÷ 5), 1~12. 몬스터 = 영지 단계 `max(1, 최고 영지 − 3)` 일반 몬스터 (체력 그대로, **공격 50%** — 10장) |
| 별 | 처치 수 **30 / 60 / 95** 마리 → ★1 / ★2 / ★3 (처음 안 40/80/120 → 시뮬레이터로 조정, 10장) |
| 보상 비율 | ★1 40% · ★2 70% · ★3 100% (★0이면 입장권 돌려줌) |
| 소탕 | 그 단계에서 ★3을 한 번이라도 받았으면 「소탕」 버튼: 입장권 1장으로 ★3 보상 바로 받기 |

**★3 보상 (단계 L 기준)**
| 던전 | 보상 |
|---|---|
| 브론의 폐광 | 광석 20 + L × 5 (L12 = 80) |
| 마르타의 들판 | 밀 씨앗 6 + L · 은빛 당근 씨앗 3 + floor(L/2) · 달빛 호박 씨앗 1 + floor(L/4) |
| 고블린 금고 | 골드 = 방치 보상 60분 어치. 황금 고블린을 잡으면 +20% (판당 최대 1번 등장, 40~120초 사이) |
- 단계가 오르면(최고 영지가 오르면) 소탕은 새 단계에서 ★3을 받아야 다시 열림. 소탕은 「지금 단계 이상에서 ★3을 받은 적이 있으면」 지금 단계 ★3 보상.
- 동료 카드는 주지 않는다. 던전 중 잡은 마물은 골드·카드·씨앗 드롭이 없다(보상은 별 정산으로만).

## 4. 화면 흐름
1. 지도 탭: 「🏆 랭킹 보기」 옆에 **「⚔ 도전」** 버튼. 오늘 탑 보급을 안 받았거나 던전 입장권이 남았으면 노란 점(지도 탭에도 점). 영지 20 전에는 「도전 🔒」, 누르면 「영지 20을 되찾으면 열려요」.
2. 「도전」 창 (머리 배너 `hd_challenge`, 없으면 글자만) — 위아래 카드 2개
   - **시련의 탑** 카드: 「최고 ○층」, 「다음 ○층 {보스 이름}」 + 시련 규칙/수문장 표시, 버튼 「도전하기」 / 「🎁 탑 보급 받기」(받았으면 「보급 받음 · 내일 다시」)
   - **요일 던전** 카드: 오늘 열린 던전(일요일은 3개), 각 던전에 「단계 L · 최고 ★ · 보상」, 입장권 「○/2」, 버튼 「입장」 「소탕」, 광고 버튼 「▶ 광고 보고 입장권 +1」
3. 탑 전투: 배경 = 탑 내부(그림이 없으면 서리 무덤을 어둡게), 보스 체력바에 「○층」 태그. 위쪽 표시줄 「시련의 탑 ○층 · 수문장/시련 규칙」, 「나가기」 버튼. 이기면 「○층 돌파!」 띠 + 보상 창 → 「다음 층 ▶」 / 「나가기」(위쪽에도 「다음 층 ▶」). 지면 「○층 실패」 창 → 「다시 도전」 / 「나가기」.
4. 던전 전투: 위쪽에 「던전 이름 · 단계 L」, 「⏱ 남은 시간 · 처치 수」, 별 3칸이 처치 수에 따라 차오름. 끝나면 별·보상 창 → 「도전 창」 / 「확인」.
5. 프로필: 「시련의 탑 최고 ○층」 한 줄 추가(도전이 열린 뒤).

## 7. 저장 데이터·서버
```
chOpen: 0,                 // 도전 해금 (은퇴해도 유지)
tower: { top: 0,           // 최고 돌파 층 (은퇴해도 유지)
         day: '' },        // 탑 보급 받은 날짜 today()
dun: { d: '', used: 0, ad: 0,          // 오늘 날짜·쓴 입장권·광고 입장권
       star: { mine:{}, field:{}, vault:{} },  // 단계별 최고 별 {L: 0~3} (은퇴해도 유지)
       seen: {} }          // 던전 소개 대사 본 것
```
- `fresh()`·`hydrate()`에 기본값(옛 저장은 star 3종·seen을 채움). `retire()`에서 `chOpen`·`tower`·`dun.star`는 **초기화하지 않는다**(도전 중 은퇴하면 먼저 나감).
- 배지 `tower25`·`tower100`, 테두리 `tower` 를 `BADGES`·`PFRAMES`에 추가.
- 서버: 변경 없음(클라우드 저장에 `S`째로 들어감).
- 웹·앱 같은 필드·같은 규칙. 앱: `app/lib/core/challenge.dart`(규칙), `battle/sim.dart` `ChState`(전투), `screens/challenge_sheet.dart`(창), `test/challenge_test.dart`(웹 값과 비교).

## 8. 구현 메모
- 도전 전투는 지금 전투 루프를 재사용하고 모드 값으로 나눈다: 웹 `CH`(없으면 field) / `fightMode()` = `'field' | 'tower' | 'dun'`. 모드가 바뀔 때 `S.stage`/`S.wave`를 건드리지 않는다.
- `spawn()`은 도전 중이면 `chSpawn()`, 처치는 `chKill()`(골드·카드·씨앗·`S.stage++`·`gemLord`·칭호·황금 고블린 전리품 없음), 전멸·시간 초과(`resetFight`)는 `chLose()`.
- 시련 규칙 1(회복 금지)은 `healOk()`로 요리사 치유·스킬 회복·전투 중 자연 회복을 막고, 4(단단한 껍질)는 `hitMon`에서 `m.shell`이면 피해 ×0.5.
- 던전: `chDunStep()`이 3분 타이머와 스폰(살아 있는 마물이 3마리 미만이면 0.3초마다 1~3마리)을 맡는다.

- 방법: 처음부터 자동 전투 + 욕심쟁이 소비(동료 레벨·단련·상자, 마을·카드·모집 동료는 빼서 실제보다 약함). 같은 영지에서 40분 막히면 그 상태로 ① 탑을 1층부터(층마다 2번까지) ② 그 단계 폐광을 10번 돌린 뒤 은퇴(추억 +floor((영지−10)/5))하고 다음 회차.
- 다시 돌리기: `python3 -m http.server 8765` 뒤 `python3 tools/challenge_sim.py 8 6 999 '{}' 2400 10` (회차당 시간, 은퇴 수, 마지막 회차 멈출 영지, 덮어쓰기 `{"star":[..],"dun":{..},"dvar":[..]}`, 막힘 판정 초, 던전 횟수)

**① 시련의 탑 (공식 그대로, 바꾸지 않음)**
| 유저 | 막힌 영지 | 탑 |
|---|---|---|
| 은퇴 0회 (추억 0) | 40 | 34층 |
| 은퇴 1회 (추억 6) | 46~47 | 39층 |
| 은퇴 2회 (추억 13) | 48~49 | 43층 |
| 은퇴 3~4회 (추억 20~28) | 50 | 44층 |
| 은퇴 5회 (추억 36) | 50 | 46~47층 |
| 은퇴 6~7회 (추억 44~53, **왕도 첫 도달**) | 51~55 | **47~49층** |
- 해석: 탑 층 ≈ 막힌 영지 − 5 안팎. 왕도에 처음 들어선 유저가 47~49층 → 목표 45~55 안. 실제 유저는 마을·카드·모집 동료가 있어 조금 더 높을 것.

**② 요일 던전**
- 처음 안(몬스터 그대로, 화면 3마리·0.45초 스폰): 처치 수가 강함과 상관없이 **약 150마리로 고정**(스폰이 부족) → 누구나 ★3.
- 화면 6마리로 늘리면: 3분 연속 전투에서 원정대가 몰매를 맞아 **7~50마리에서 전멸**(운에 따라 크게 흔들림).
- 조정: 화면 3마리 유지, 스폰 0.3초, **몬스터 공격 50%**(체력은 그대로) → 전멸 없이 처치 수가 원정대 힘을 따라감.
- 그 단계에 막 도달한(막힌 영지의) 유저 14명분 처치 수: 145, 92, 87, 101, 120, 133, 83 / 95, 105, 102, 101, 115, 141, 84 → 별 기준을 **30 / 60 / 95**로 하면 ★3 약 71%(10/14), 처음 안 120이면 21%.
- 은퇴 직후(최고 영지는 그대로인데 지금 원정대가 약한 회차)는 처치 수가 크게 낮다(예: 6~66마리) → 같은 단계라도 회차 후반에 다시 오면 ★3.

# 왕도 아스테리온 + 1부 엔딩 기획서

작성일: 2026-10-21 · 상태: **구현 완료 (2026-10-22, 웹·앱)** — 9장 항목은 초안대로 확정, 발타사르 수치는 시뮬레이터로 조정(3-3, 10장)
선택: 1안 「왕도 10구역」.

## 1. 목적
- 50영지를 끝낸 최상위 유저가 할 게 없는 문제를 푼다(지금은 51부터 1지역 몬스터가 다시 나오며 끝없이 강해지기만 함).
- 시즌 랭킹이 51에서 묶여 순위가 안 갈리는 문제를 푼다(서버 `kd_submit`은 이미 61까지 받음 → 서버 변경 거의 없음).
- 1부 이야기(마왕 = 300년 전 왕 발타사르)를 마무리하고 2부로 잇는다.

## 2. 확정 내용 요약
다섯 군단을 몰아내면 6번째 지역 **「왕도 아스테리온」**(영지 51~60)이 열린다. 다른 지역과 같은 규칙(영지마다 웨이브 10개 + 보스)이지만, 홀수 영지에는 **쓰러뜨린 군단장 5명의 잔영**이 차례로 막아서고, 짝수 영지는 **마왕 근위대장**이 지킨다. 60번째 「알현실」에서 **마왕 발타사르와 2단계 전투**(60초)를 치르고, 이기면 1부 엔딩이 나온다. 엔딩 뒤에는 「왕궁 뜰」(61)에서 보스 없이 사냥이 이어지고, 은퇴를 권한다. 왕도를 처음 되찾을 때와 은퇴 후 다시 되찾을 때마다 추가 보상을 준다.

- **잔영**: 기존 군단장 그림을 그대로 쓰고 보랏빛 반투명 + 어두운 테두리 효과로 그린다(새 그림 없음). 이름 앞에 「잔영:」.
- 잔영·근위대장은 모두 지금 성주와 같은 취급(체력 ×6, 공격 ×2.5, 30초).

### 3-3. 체력·공격 (기존 공식 그대로 이어서)
- `monHp`, `monAtk`, `reward`는 단계 숫자만 이어서 계산(51~60). 참고: 60단계 일반 몬스터 체력 약 94만, 성주급 약 563만.
- **발타사르** (2026-10-22 시뮬레이터로 조정 — 처음 안 ×24 / ×3 → ×3.6 은 목표보다 3배쯤 어려웠음, 10장)
  | 단계 | 체력 | 공격 | 특징 |
  |---|---|---|---|
  | 1단계 「검은 왕」 | **×12** (군단장과 같은 배율, 60단계라 이그니스보다 약 6배) 전체를 하나의 체력바로 | **×2** | 100%~50% |
  | 2단계 「옛 왕」 | (같은 체력바, 50%부터) | **×2.4** | 8초마다 「봉인의 파동」 |
  - 코드: `BAL.demHp=12`, `BAL.demAtk=2`, `BAL.demAtk2=2.4`, `BAL.seal=2`(파동 = 공격 ×2)
  - 제한 시간 **60초** (전체). 실패하면 **59(왕궁 회랑) 마지막 웨이브**로 되돌아감 → 59 잔영을 다시 넘어 재도전.
  - 50%가 되면 전투가 1.5초 멈추고 정체 공개 대사 2줄 → 보스 그림이 2단계로 바뀜, 체력바 색 보라→금. 체력바 가운데 50% 눈금.
  - 「봉인의 파동」: 2초 전에 바닥에 금색 원 표시 → 원정대 전체에 공격의 2배 피해. 브론 버팀목(피해 절반)·브리다 방어·버치 벌통 방패·덕배 불굴로 버틸 수 있음.
  - 목표: 50 첫 도달부터 60 첫 탈환까지 활동 7~14일 → 결과는 10장.

### 3-4. 보상
| 언제 | 보상 |
|---|---|
| 51~59 보스 첫 처치 | 지금 성주와 같음 |
| 잔영 첫 처치(51·53·55·57·59) | 황금 이삭 30씩 (`GHOST_GEM`) |
| 60 발타사르 첫 처치 | 황금 이삭 300 (`DEMON_GEM`) + 프로필 테두리 「왕도의 별」(`frame_capital`) + 배지 「1부 완결」(`badge_part1`) |
| 칭호 | 60곳 탈환 시 새 칭호 **「왕도 탈환자」**(+4%, 이삭 30). 「왕」은 3부를 위해 남김 |
| 은퇴 후 다시 60 처치 | 그 회차 첫 1회만 **은퇴의 추억 +3 추가**(`CAP_MEM`, 아래 3-5) |
- 서버 우편 「정복자」 테두리(50곳)는 그대로 둔다. 업적 배지 「농부 왕」도 50곳 기준 그대로(`S.best>50`).

### 3-5. 엔딩 이후 (61 「왕궁 뜰」)
- 60을 깨면 `S.stage` = 61. 전투 화면 이름은 「왕궁 뜰」, 몬스터는 60단계 일반 몬스터 반복, **보스 없음**(골드·씨앗·장비 사냥용). 62 이상은 생기지 않음.
- 랭킹은 61이 끝(같은 61끼리는 지금처럼 먼저 도달한 순).
- 은퇴 칸에 「👑 왕도 재탈환 보너스: 다음 회차에 왕도를 되찾으면 은퇴의 추억 +3」 안내(한 번이라도 깬 뒤부터).
- 은퇴 추억 계산 `retirePts` = floor((stage−10)/5) 그대로 → 61에서 10 + 왕도 보너스.

### 3-6. 랭킹·서버
- `kd_submit`: 이미 1~61 허용 → **변경 없음**. 클라이언트 `Math.min(S.stage, MAXLAND+1)`도 MAXLAND가 60이 되면 자동으로 61.
- 속도 검사 기준(단계당 1.5분)은 그대로.

## 4. 화면 흐름
1. 50 탈환 → 기존 대사 뒤 **「왕도로 가는 길」 장면**(아래 5-1) → 지역 소개(5-2) → 51 시작. (처음 한 번만, 은퇴 뒤에는 알림 한 줄)
2. 지도: 아래쪽 「왕도 아스테리온」 성 아이콘 자리를 **6번째 줄(영지 10칸)** 로 바꾸고, 성 아이콘은 그 줄 끝(알현실)에 크게.
3. 전투 상단: 「6-3 왕도 아스테리온 / 대장장이 골목 탈환전」처럼 지금 형식 그대로. 61은 「왕궁 뜰 / 보스 없이 사냥 중 · 1부 완결」.
4. 보스 표시 태그: 잔영 / 근위대장 / 마왕. 마왕은 체력바 2단계 색 변화(보라→금).
5. 엔딩: 장면 3개(5-4, 1·3번에 일러스트 — 없으면 건너뜀) → 「1부 완결」 창(받은 보상, 2부 예고 문구, 「은퇴 계획 보기」/「계속 사냥하기」 버튼).

## 8. 구현 메모·검증 (주의할 점)
- `REGIONS`에 6번째를 넣으면 `MAXLAND`가 60이 된다. 같이 바뀐 곳:
  - 업적 「농부 왕」 → **50 기준 그대로**(`S.best>50`).
  - 칭호 `RANKS`(+「왕도 탈환자」 at 60)·`RANKIMG`·`landCount`·지도 「되찾은 영지 ○/60」, 마지막 칭호 뒤 「모든 칭호를 얻었어요」.
  - `region()`은 61 이상에서 왕도에 머묾(`%` 대신 최댓값), `terrName(61)` = 「왕궁 뜰」.
  - `stgName`/`stLabel` → 61 = 「왕궁 뜰」.
  - `rankSubmit`·`cloudBody`·`cloudPick`은 `MAXLAND+1` 그대로 → 61.
  - 61 전투·방치 보상·황금 고블린 보상은 60단계 기준(`fightSt()`).
  - 지도 6줄, 성 아이콘은 60번째 칸.

## 10. 난이도 확인 (tools/capital_sim.py)
- 방법: 처음부터 자동 전투 + 욕심쟁이 소비(동료 레벨·단련·상자, 마을·카드·모집 동료는 빼서 실제보다 약함)로 한 판 3시간. 은퇴의 추억(MEM)만 바꿔 가며 어디서 막히는지 본다. 은퇴 한 번(51~60에서)에 추억 +8~10.
- 처음 안(체력 ×24, 공격 ×3→×3.6): 50은 추억 약 40에서 깨지는데 발타사르는 약 260이 필요 → 은퇴 25번쯤(목표의 2~3배). 원인은 공격(전멸)과 체력(시간 초과) 둘 다.
- 조정 후(체력 ×12, 공격 ×2→×2.4, 파동 ×2):
  | 추억 | 결과 |
  |---|---|
  | 30 | 50 군단장에서 막힘 |
  | 40 | 50 깸 → 54에서 막힘 |
  | 50 | 56에서 막힘 |
  | 70 | 58에서 막힘 |
  | 90·130 | 60까지 가지만 발타사르에게 짐 |
  | 140 | 60 깸 (약 30분) |
- 해석: 50 첫 탈환(추억 ~40)에서 60 탈환(~135)까지 추억 약 95 = 은퇴 약 10번. 하루 한 번 은퇴 기준 **약 10일** → 목표 7~14일 안. 실제 유저는 마을·카드·모집 동료가 있어 조금 더 빠를 수 있음.
- 다시 돌리기: `python3 -m http.server 8765` 뒤 `python3 tools/capital_sim.py 3 140 3 '{"demHp":12}'` (시간, 추억, 은퇴 수, BAL 덮어쓰기)

# 디자인 작업 의뢰서

「왕이 되는 그날까지」의 그래픽과 UI 디자인을 의뢰합니다. 지금 프로토타입(`index.html`)은 모든 그림을 Canvas 코드로 임시로 그려 둔 상태입니다. 이 그림들을 실제 게임 아트로 바꾸는 것이 목표입니다.

## 1. 게임 한 줄 소개

은퇴만 꿈꾸는 농부가 성검을 뽑는 바람에, 평민 동료들과 마족에게 빼앗긴 영지를 하나씩 되찾다가 왕이 되는 자동사냥 방치형 RPG.

- 플랫폼: 모바일 세로 화면 웹게임 (기준 폭 400px, 최대 폭 480px)
- 레퍼런스: 버섯커 키우기(한 화면 구성, 단순한 UI), 세븐나이츠 키우기(SD 캐릭터 파티 전투)
- 톤: 세계는 진지한 정통 판타지, 주인공과 동료는 유쾌하고 소박한 평민. 무거운 배경 위에 귀여운 인물이 대비되는 느낌

## 2. 화면 구성 (위에서 아래로)

1. 상단 바: 지금 영지 이름, 지역·영지 번호, 보유 골드
2. 전투 화면: 왼쪽에 원정대가 서고 오른쪽에서 마물이 다가옴. 웨이브 표시, 버프 아이콘, 보스 체력바, 캐릭터 말풍선
3. 요약 4칸: 전투력, 원정대 인원, 칭호, 되찾은 영지
4. 탭 5개: 장비 · 원정대 · 단련 · 마을 · 지도
5. 탭 내용 영역 (스크롤)
6. 팝업: 스토리 장면, 장비 획득 비교, 방치 보상

## 3. 캐릭터 (SD 2~2.5등신, 오른쪽을 보는 측면)

| 캐릭터 | 역할 | 외형 요청 | 필요한 동작 |
| --- | --- | --- | --- |
| 카엘 | 주인공, 농부 용사 | 밀짚모자(붉은 띠), 파란 멜빵바지, 흰 셔츠, 붉은 스카프. 어울리지 않게 푸르게 빛나는 성검을 듦 | 대기, 걷기, 베기, 피격, 쓰러짐 |
| 성검 루미나르 | 말하는 성검 | 금색 가드와 푸른 보석. 말할 때 빛남. 대화창 초상화용 표정 3종(거만, 화남, 감동) | 빛나기 |
| 브론 | 광부, 앞줄 방어 | 드워프. 노란 광산 헬멧과 헤드램프, 주황 수염, 곡괭이 | 대기, 걷기, 곡괭이 휘두르기, 피격 |
| 하랄 | 어부, 원거리 | 노인. 노란 우비와 모자, 흰 수염, 작살 | 대기, 걷기, 작살 던지기, 피격 |
| 리엘 | 양봉가, 광역 | 400살 요정. 양봉 모자와 망사, 초록 원피스, 주변을 도는 꿀벌 | 대기, 걷기, 벌 떼 부리기, 피격 |
| 마고 | 요리사, 회복 | 통통한 식당 아주머니. 요리사 모자, 붉은 옷에 흰 앞치마, 국자 | 대기, 걷기, 수프 던지기, 피격 |

마을 사람(초상화만): 마르타 할머니(농부), 행상인 피트(수상한 상인), 꼬마 토비(카엘의 팬).

## 4. 적

| 지역 | 일반 마물 | 군단장(보스) |
| --- | --- | --- |
| 에르단 평원 | 역병 점액 (초록 점액, 작은 마족 뿔) | 역병의 군단장 모르바스 |
| 어스름 숲 | 밤그늘 박쥐 | 밤의 군단장 세릴 (요정의 빛을 모으는 수집광) |
| 드워프 협곡 | 강철 골렘 | 강철의 군단장 그로마크 (오거 대장장이) |
| 서리 무덤 | 서리 망령 | 망령의 군단장 알도르 (저주받은 기사단장) |
| 잿불 심연 | 잿불 점액 | 화염의 군단장 이그니스 (마계의 문지기) |

- 모든 마물에 작은 마족 뿔을 달아 "마족 편"임을 통일해서 보여 주세요.
- 영지 성주(중간 보스)는 일반 마물의 큰 버전에 금색 왕관. 군단장은 따로 디자인.

## 6. 마을 화면

폐허 → 재건 → 확장 3단계가 보여야 합니다. 건물: 밭, 여관, 식당, 낚시터, 양봉장, 광산. 낮과 밤 두 가지 버전.

## 7. UI

- 지금 색 체계: 배경 남색 `#141a29`, 패널 `#1f2740`, 강조 금색 `#ffc94a`, 좋음 `#7be08f`, 나쁨 `#ff6b7d`
- 글꼴: 제목은 함렛(Hahmlet), 본문은 IBM Plex Sans KR
- 필요한 것: 로고(「왕이 되는 그날까지」, 밀짚모자나 괭이와 왕관을 엮은 모티프 제안), 탭 아이콘 5종, 장비 부위 아이콘 6종, 장비 등급 테두리 6종(일반·고급·희귀·영웅·전설·신화), 성유물 상자, 작물·생선·꿀·광석 아이콘, 버튼, 팝업 프레임, 영지 지도의 탈환·미탈환·군단장 노드

## 8. 납품 형식

- 캐릭터와 마물: PNG 스프라이트 시트(투명 배경), 프레임 크기와 프레임 수 명시
- 아이콘: SVG 또는 PNG(2배 해상도)
- 배경: 레이어별 PNG, 가로 반복 가능하게
- 파일 위치 제안: `assets/characters/`, `assets/monsters/`, `assets/bg/`, `assets/ui/`

## 9. 코드에서 바꿔 끼울 곳

`index.html`의 그리기 함수가 각 그림을 맡고 있어요. 디자인 파일이 오면 이 함수들을 이미지 그리기로 교체하면 됩니다.

- 캐릭터: `drawKael`, `drawBron`, `drawHaral`, `drawRiel`, `drawMargo`
- 마물: `drawMon` (지역별 `kind` 값: slime, bat, golem, ghost)
- 배경: `drawBg`
- 마을: `drawVillage`
- 지도: `drawMap`

# 전설 양봉가 「엘름」 기획 기록

작성일: 2026-10-25 · 상태: **기획·그림 완료, 게임 등록은 보류**

## 추가 배경
- 전설 동료 2차 4명(정통 판타지 스타일) 중 세 번째. 나이아·베르나르 완료 후 **엘름** 진행 (대표님 결정, 2026-10-25). 하그린(광부)은 아직 미진행.

## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 엘름 / `elm` |
| 직업 / 등급 | 양봉가(벌집을 품은 고목 정령) / 전설 |
| 콘셉트 | 천 년 된 걸어 다니는 나무 정령. 몸 곳곳에 벌집이 붙어 벌들의 집이 되어 줌. 느릿느릿하고 말이 아주 느림 |
| 관계 | **리엘이 어릴 때 놀던 나무**. 리엘을 아직도 「꼬마 요정」이라 부름 (합류 대사 웃음 포인트) |
| 생김새 (참고 시트 기준) | 땅딸막하고 둥근 고목 정령, 이끼 낀 갈색 나무껍질 몸(배에 나이테 소용돌이), 머리 위 가지 뿔 + 초록 잎·흰 꽃 왕관, 풍성한 초록 이끼 콧수염·수염, 옹이 구멍 같은 순한 호박색 눈, 뿌리처럼 갈라진 짧은 발 |
| 벌집 | 어깨·가슴에 붙은 금빛 벌집(꿀이 흘러내림) |
| 도구 | 덩굴처럼 꼬인 나무 지팡이 한 자루, 끝에 큰 분홍 연꽃 봉오리 |
| 대표 색 | 나무 갈색 + 이끼 초록 + 꿀 금색 |
| 성격 | 느긋하고 다정함, 말이 느림, 졸음이 많음 |
| 스킬 「생명의 수액」 | 수액이 흐르는 동안 아군이 **때릴 때마다 체력을 회복** — 동료 중 첫 흡혈 |
| 마을 스킬 | 밭 작물이 빨리 자람 (수치는 등록 세션에서) |

## 차별점
- 리엘(요정)·데이지(소녀)·말봉(근육 아저씨)·안단테(지휘자)·멜로(꿀단지 지게)·버치(목수)와 겹치지 않게 **사람이 아닌 나무 정령** 실루엣.

- 등록 시 확인:
  - 공격 2프레임은 지팡이가 앞으로 길게 뻗어 프레임 폭이 넓음 → 몸(발) 기준으로 중심 맞출 것. 공격 1프레임은 지팡이가 머리 위로 올라가 키 기준 주의.
  - 초상화 원본은 두 그림이 아래쪽에서 붙어 있어 알파가 가장 적은 곡선 경로로 잘라 나눔.
  - 효과는 연두 빛 번짐이 넓음 → 아군 위에 겹칠 때 크기 작게, 어두운 배경에서 확인. 지속형이라 3프레임 반복 재생 가능.

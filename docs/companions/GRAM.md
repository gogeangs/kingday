## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 그램 / `gram` (판타지 이름, 「그램프(할아버지)」에서) |
| 직업 / 등급 | 요리사(군감자 장수) / 일반 |
| 콘셉트 | 화로에 군감자를 굽는 느긋한 할아버지. 원정대 쉬는 시간마다 감자를 나눠 줌. "뜨끈할 때 하나씩 들어." |
| 관계 | 마을 어귀에서 군감자를 팔다가, 카엘 일행이 지나갈 때마다 공짜로 쥐여 주던 사이. 마고와는 "감자는 굽는 게 최고"·"삶는 게 최고"로 늘 말다툼 (합류 대사 웃음 포인트) |
| 생김새 | 70대 할아버지, 작고 동글동글한 체구, 정수리 대머리 + 하얀 옆머리, 굵고 하얀 눈썹, 둥글고 빨간 코, 짧은 흰 턱수염, 늘 웃는 실눈 |
| 옷 | 털 귀마개가 달린 갈색 가죽 모자, 겨자색 누빔 조끼 + 갈색 긴팔 셔츠, 빨강 체크무늬 목도리, 헐렁한 회색 바지, 털 달린 갈색 장화 |
| 도구 | 등에 멘 원통형 쇠 화로(멜빵 끈, 위에 군감자 수북, 안에 숯불), 손에 쇠 부젓가락 |
| 대표 색 | 겨자색 + 갈색 + 숯불 주황 |
| 성격 | 느긋하고 인심 좋음, 남 먹이는 걸 제일 좋아함 |
| 스킬 「군감자 한 알」 | 따끈한 군감자를 나눠 줘 **아군 전체를 조금 회복** — 일반 등급 단순 효과 (일반 최대 ★3 → ★3 ×1.3 적용). 마고(전체 회복+공격↑)보다 양이 적고 공격력 증가 없음 |

## 차별점
- 마고(가마솥)·루카(빵)·덕배(상투·소반)·카라(웍)·포리(냄비)와 겹치지 않게 **등의 쇠 화로 + 부젓가락 + 귀마개 모자** 실루엣.
- 덕배·롤로·하랄 등 할아버지와 구분: 작고 둥근 체구, 대머리, 빨간 코, 겨자색.

| ③ 스킬 아이콘 | 받음 | 반으로 쪼개진 군감자(노란 속살) + 흰 김 + 연두 회복 십자 |
| ④ 스킬 효과 시트 | 받음 | 가로 4프레임: 감자가 빛과 함께 떨어짐 → 쪼개지며 김 → 연두 회복 십자·감자 조각 → 옅어짐 |

- 등록 시 확인:
  - **화로가 몸 뒤로 크게 나와** 프레임 폭이 넓음 → 몸(발) 기준으로 중심 맞출 것. 공격 3프레임은 부젓가락이 앞으로 길게 뻗음.
  - 피격 땀방울 효과는 작아서 그대로 둬도 무방.
  - 효과 시트는 빛 번짐(노랑·연두)이 넓고 반투명 → 아군 위에 겹칠 때 크기를 작게, 어두운 배경에서 확인.
  - 동작 시트 가장자리에 옅은 번짐이 있어 자를 때 투명도 기준값으로 걸러낼 것.

## 추가 배경
- 일반 모집 동료가 고든(광부)뿐이라 어부·양봉가·요리사 일반 모집 동료를 1명씩 추가 기획 (대표님 결정, 2026-10-21). 추천안: 모라(어부)·멜로(양봉가)·포리(요리사).

## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 모라 / `mora` (판타지 이름) |
| 직업 / 등급 | 어부(생선 장수) / 일반 |
| 콘셉트 | 시장에서 목청 큰 생선 장수 아주머니. "싱싱해요, 싱싱해!" |
| 관계 | 마고 식당에 생선을 대는 단골, 마고와 친한 수다 친구 (합류 대사: 마고가 소개) |
| 생김새 | 40대 아주머니, 통통하고 튼튼한 체구, 발그레한 뺨, 시원하게 웃는 얼굴, 짙은 갈색 곱슬머리를 뒤로 올려 묶고 노란 두건(옆 매듭) |
| 옷 | 소매 걷은 하늘색 셔츠, 멜빵식 짙은 초록 고무 앞치마 + 허리에 밧줄 끈, 노란 고무장화 |
| 도구 | 어깨에 멘 자기 몸통만 한 은빛 생선(동그란 눈, 입 벌린 우스꽝스러운 표정 — 꼬리를 잡고 듦), 허리에 작은 생선이 담긴 대나무 바구니 |
| 대표 색 | 노랑 + 초록 + 은빛 |
| 성격 | 목청 크고 시원시원, 흥정에 강함, 정 많음 |
| 스킬 「싱싱한 한 방」 | 커다란 생선을 휘둘러 **앞의 적 하나에 피해** — 일반 등급 단순 효과 (일반 최대 ★3 → ★3 ×1.3 적용) |

## 차별점
- 하랄(작살)·넬라(그물)·막례(빗창)·토비(노)와 무기가 다른 「생선」 실루엣. 노란 두건·장화로 색 구분.

  - **생선이 몸 앞뒤로 크게 나와** 프레임마다 그림 폭이 다름 → 몸(발) 기준으로 중심 맞출 것. 공격 2프레임은 생선이 머리 위로 높이 올라감(키 기준 주의).
  - 동작 시트 가장자리에 옅은 번짐이 있어 자를 때 투명도 기준값으로 걸러낼 것.

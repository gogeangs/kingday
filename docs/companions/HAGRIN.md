## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 하그린 / `hagrin` |
| 직업 / 등급 | 광부(산맥의 거인) / 전설 |
| 콘셉트 | 옛날에 맨손으로 산맥을 파서 왕국의 길을 낸 늙은 거인. 순하고 수줍음 많음. "…미안… 또 부쉈네…" |
| 관계 | 몸이 너무 커서 **브리다의 대장간 문에 늘 머리를 찧음**. 브론·브리다(드워프)와는 오랜 친구 (합류 대사 웃음 포인트) |
| 생김새 (참고 시트 기준) | 크고 듬직한 늙은 거인, 바위처럼 거친 회갈색 피부에 이끼와 하늘색 수정 조각, 대머리, 굵은 흰 눈썹, 돌 구슬 장식의 두 갈래 땋은 흰 수염, 작고 순한 호박색 눈 |
| 옷 | 기운 갈색 가죽 조끼, 밧줄 허리띠 + 둥근 돌 버클, 헐렁한 회색 바지, 맨발, 양 손목의 넓은 쇠 팔찌 |
| 도구 | 돌 곡괭이 한 자루 — 밧줄 감은 굵은 나무 자루 + **하늘색 수정이 박힌 회색 돌 날**(기획의 바위 덩어리 날 대신, 실루엣이 좋아 확정) |
| 대표 색 | 회갈색(바위) + 흰 수염 + 하늘색 수정 |
| 성격 | 순하고 수줍음, 말이 적음, 힘 조절을 못 해 늘 미안해함 |
| 스킬 「바위 깨기」 | 체력이 적게 남은 적을 **한 번에 쓰러뜨림**(보스에게는 큰 피해) — 동료 중 첫 마무리 |
| 마을 스킬 | 장비 강화에 드는 광석 감소 (수치는 등록 세션에서) |

## 차별점
- 브론·브리다(드워프)·고든(석공)·페피(발파공)·베릴(감정사)·롤로(광차 노인)·뚝딱이(도깨비)와 겹치지 않게 **거인 체격 + 바위 피부 + 수정 박힌 돌 곡괭이**.

| 그림 | 상태 | 메모 |
|---|---|---|
| ⓪ 참고 캐릭터 시트 | 받음 | 정면·측면·뒷모습·표정 4종(머리 찧기 포함)·꽃 들기·곡괭이 치켜들기·내리치기·쪼그려 쉬기·걷기 7. 투명 배경 |
| ① 동작 시트 | 받음 (2번째로 확정) | 4줄 4/6/4/2, 오른쪽 측면, 투명 배경, 효과 없음. 대기·걷기·피격=곡괭이 등에, 공격=등에서 뽑아 치켜듦→머리 위에서 내리치는 중(등 비움)→앞쪽 바닥에 박음→다시 멤. 1차는 **공격 2프레임에 곡괭이가 등에 메인 채 손에 날 없는 자루만 쥠**(곡괭이 둘) → 그 프레임만 다시 요청 |
| ② 초상화 2종 | 받음 | 왼쪽 머리 긁적이며 수줍은 웃음 / 오른쪽 눈 감고 볼 붉혀 웃으며 손바닥에 흰 꽃 |
| ③ 스킬 아이콘 | 받음 | 수정 박힌 돌 곡괭이가 바위를 쪼개며 금빛 충격 + 바위·수정 조각 |
| ④ 스킬 효과 시트 | 받음 | 가로 4프레임: 하늘색 수정 빛줄기 내리꽂힘 → 금빛 충격·땅 갈라짐 → 바위·수정 조각 튐 → 먼지·수정만 남음 |

- 등록 시 확인:
  - **공격 3프레임의 앞으로 뻗은 곡괭이 날이 공격 4프레임에 거의 붙어 있음** → 직선 말고 알파가 가장 적은 곡선 경로로 자를 것.
  - 덩치가 커서 다른 광부보다 키를 크게(`HEIGHT`). 공격 1·2프레임은 곡괭이가 머리 위로 올라가 키 기준 주의.
  - 효과는 빛 번짐이 넓음 → 어두운 배경에서 확인.

- 일반 동료 2명 제안(베티·살로) 중 살로를 먼저 진행했고, 전설 2차 4명을 마친 뒤 **베티** 진행 (대표님 결정, 2026-10-25).

## 차별점
- 브론·브리다(드워프)·고든(석공)·페피(발파공)·베릴(감정사)·롤로(광차 노인)·뚝딱이(도깨비)·하그린(거인)과 겹치지 않게 **작은 소녀 체격 + 모자 위 초 + 장대 등불** 실루엣.
- 일반 동료 효과: 고든(기절+반격)·모라(단일 피해)·멜로(피해+감속)·포리(단일 회복)·롤로(관통)·살로 등과 달리 **아군 치명타 버프**.

- 등록 시 확인:
  - 동작 시트의 **걷기 줄 아래와 공격 줄 위가 높이상 겹침**(걷기 553px까지, 공격 546px부터) → 가로 직선 자르기 말고 덩어리(연결 영역)별로 떼어 낼 것.
  - 걷기 6프레임 등불이 오른쪽 끝(3px 여백)에 거의 닿음 — 잘리진 않음.
  - 피격 프레임이 다른 프레임보다 작게 그려짐(키 약 220px vs 275px) → 크기 맞출 것.
  - **스킬 효과 2·3·4프레임의 빛 번짐이 서로 붙어 있음** → 알파가 가장 적은 곡선 경로로 자르고, 어두운 배경에서 가장자리 확인. 아군 전체에 겹쳐 재생하므로 크기 작게.

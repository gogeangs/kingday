| 항목 | 내용 |
|---|---|
| 이름 / id | 버치 / `birch` (판타지 이름, 벌통 짜는 자작나무에서) |
| 직업 / 등급 | 양봉가(벌통 목수) / 일반 |
| 콘셉트 | 리엘과 멜로의 벌통을 전부 만들어 준 느긋하고 듬직한 목수 청년. "튼튼한 집이 있어야 벌도 꿀을 모으지." |
| 관계 | 리엘의 벌통을 수리해 주는 단골 목수, 멜로가 지게 꿀단지를 깨뜨릴 때마다 지게도 고쳐 줌 (합류 대사: 멜로가 소개) |
| 생김새 | 20대 후반 청년, 듬직하고 통통한 체구, 부스스한 밤색 곱슬머리, 귀에 꽂은 노란 몽당연필, 졸린 듯 순한 눈, 굵은 눈썹, 턱에 수염 자국 |
| 옷 | 소매 걷은 크림색 셔츠, 청색 데님 멜빵바지, 허리에 도구 가죽 벨트(주머니·줄자), 갈색 작업 부츠, 목에 두른 자작나무 무늬(흰 바탕 검은 줄) 수건 |
| 도구 | 커다란 나무 망치(메, 쇠 띠), 등에 멘 나무 벌통(앞면 육각 출입구) |
| 대표 색 | 데님 청색 + 크림 + 나무 갈색 |
| 성격 | 느긋하고 말이 느림, 손재주 좋고 남 챙기기 좋아함 |
| 스킬 「벌통 방패」 | 벌통을 세워 **체력이 가장 낮은 아군의 받는 피해↓** — 일반 등급 단순 효과 (일반 최대 ★3 → ★3 ×1.3 적용) |

## 차별점
- 리엘(요정)·데이지(소녀)·말봉(근육 아저씨, 노랑·검정)·안단테(지휘자, 와인색)·멜로(꿀단지 지게, 연두)와 겹치지 않게 **데님 목수 + 나무 망치 + 등의 벌통** 실루엣.
- 일반 동료 효과 중 첫 **보호(피해 감소)**.

| ② 초상화 2종 | 받음 | 둘 다 망치를 어깨에. 왼쪽 연필을 만지며 느긋한 미소 / 오른쪽 눈 감고 하하 웃음 |
| ③ 스킬 아이콘 | 받음 | 육각 출입구 나무 벌통 + 하늘색 방패 빛(벌집 무늬) + 튕겨 나가는 화살 |
| ④ 스킬 효과 시트 | 받음 | 가로 4프레임: 금빛 속도선과 함께 떨어짐 → 쿵 박히며 먼지·조각 → 하늘색 보호막·반짝임 → 옅어지며 사라짐 |

- 등록 시 확인:
  - **동작 시트 투명 부분 밑에 짙은 갈색 배경색과 넓은 번짐이 숨어 있음**(투명도는 정상) → 자를 때 투명도 기준값으로 반드시 걸러낼 것.
  - 공격 2·3프레임 효과: 타격감이 있어 그대로 써도 되지만, 효과 때문에 프레임 폭이 넓으니 몸(발) 기준으로 중심 맞출 것. 어색하면 그 프레임만 다시 받기.
  - 스킬 효과 1프레임은 벌통이 공중에 떠 있음 → 바닥 높이 기준은 2~4프레임으로 맞출 것.
  - 초상화 원본은 두 그림이 붙어 있어 덩어리 단위로 좌우 분리함.

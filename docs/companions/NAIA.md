- 등록 시 확인:
  - **걷기 줄 프레임끼리 머리카락이 1~2픽셀 닿음** → 직선 자르기 말고 알파가 가장 적은 곡선 경로로 자를 것.
  - **피격 프레임이 다른 프레임보다 작게 그려짐**(키 약 207px vs 265px) → 크기 맞출 것.
  - 물통 수레가 커서 프레임 폭이 넓음 → 바퀴 기준으로 중심 맞추기. 하랄(수레 미는 사람)은 그림에 없음.
  - 효과는 빛 번짐이 넓고 반투명 → 어두운 배경에서 확인.

## 차별점
- 리엘(요정)·데이지(소녀)·말봉·안단테·멜로·버치·엘름(나무 정령)·오스카(기사)·브루노(곰)·골디(용)와 겹치지 않게 **엘프 귀 + 긴 연두 머리 + 이파리 망토 + 꽃 지팡이**.
- 효과: 즉시 회복(마고·포리·그램·루시안)·흡혈(엘름)과 달리 **시간에 걸쳐 차오르는 회복**.

| ③ 스킬 아이콘 | 받음 | 덩굴 지팡이 끝 분홍 꽃 + 아래 들꽃밭 + 떠오르는 연두 하트·빛 방울 + 꽃 위 꿀벌 |
| ④ 스킬 효과 시트 | 받음 | 가로 4프레임(모두 아래 붙임): 새싹 → 들꽃 타원 → 꽃밭 가득 + 하트·빛 방울(최고조) → 꽃잎·빛 방울만 남음. 프레임 사이 빈 줄 있음 |

- 등록 시 확인:
  - 동작 시트 **공격 1프레임 치켜든 지팡이 꽃이 바로 위 걷기 줄에 닿음**(공격 1프레임 덩어리가 272~778px로 걷기 1프레임과 붙음) → 줄 사이를 곡선 경로로 자를 것(`slice_frames.py` CUTS). 긴 머리·망토가 뒤로 넓어 발 기준(`anchor: foot`).
  - 초상화 원본은 두 그림 머리카락이 옆으로 살짝 겹쳐 있어 그림 덩어리별로 나눔(잘림 없음 확인).
  - 원본 RGB에 투명 영역 색이 남아 있음 → 알파 기준으로만 처리, 가장자리 어두운 테 확인.
  - 스킬 효과는 각 아군 발밑에 아래 붙여(`bottom=True`) 재생, 최고조(3프레임)를 지속 시간 동안 반복.

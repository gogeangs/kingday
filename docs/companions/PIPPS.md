## 추가 배경
- 대표님 지시 "다른 동료를 추천해줘" (2026-10-26). 후보 4명(영웅 광부 핍스 / 희귀 광부 노크 / 일반 양봉가 틸리 / 일반 요리사 토마) 중 **핍스** 선택. 나머지는 미진행.
- 영웅 광부가 페피 한 명뿐이라 추천. 기존 영웅: 페피(광부)·넬라·반 데르(어부)·안단테·오스카(양봉가)·루카·소피(요리사).
- **id 참고:** 게임 코드에 이미 `pips`(영지 진행 점 요소·CSS)가 있어 겹치지 않게 **`pipps`**로 정함. 보이는 이름은 「핍스」.

## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 핍스 / `pipps` |
| 직업 / 등급 | 광부(번개 수정을 캐는 노움 기술자) / 영웅 |
| 나이 | 성인 노움(키만 작음) |
| 콘셉트 | 땅속 깊은 곳에서 번개를 품은 수정을 캐는 노움 발명가. 직접 만든 번개 곡괭이를 켤 때마다 머리가 쭈뼛. 말이 빠르고 늘 뭔가를 고치는 수다쟁이 |
| 관계 | **베릴이 감정한 수정을 허락 없이 곡괭이에 끼워서 늘 혼남** (합류 대사 웃음 포인트) |
| 생김새 (참고 시트 기준) | 아주 작은 키, 정전기로 사방에 붕 뜬 하얀 머리, 큰 둥근 분홍 코, 흰 콧수염, 뾰족 귀, 반짝이는 눈 |
| 옷 | 이마에 황동 고글(렌즈 둘), 기름 얼룩 남색 작업복, 렌치·드라이버 꽂힌 가죽 공구 벨트, 가죽 장갑, 갈색 작업 장화, 등에 푸른 빛 나는 황동 배터리 통 + 곡괭이로 이어진 구리 전선 |
| 도구 | 황동 톱니·나사 장식 기계 곡괭이 **하나** — **날 전체가 푸른 번개 수정**(기획의 "날 끝에 수정" 대신, 실루엣이 좋아 확정), 손잡이에 푸른 배터리 관 |
| 대표 색 | 남색 + 황동 + 번개 하늘색 |
| 성격 | 수다쟁이, 호기심 많음, 실험하다 늘 감전됨 |
| 스킬 「연쇄 번개」 | 수정 곡괭이로 번개를 쏘면 **적에서 적으로 튀며 여러 번 맞힘**(튈 때마다 조금씩 약해짐) — 동료 중 첫 연쇄 공격. 영웅 등급 (★3 ×1.3, ★5 ×1.6) |
| 마을 스킬 | 영웅 기존 규칙(없음) |

## 차별점
- 브론·브리다(드워프)·고든·페피(발파공)·베릴(감정사)·롤로·베티·하그린(거인)·뚝딱이(도깨비)와 겹치지 않게 **작은 노움 + 붕 뜬 흰 머리 + 고글 + 수정 날 기계 곡괭이**.
- 효과: 전체 피해(페피·뚝딱이)·관통(롤로)과 달리 **적 사이를 튀는 연쇄 피해**.

- 등록 시 확인:
  - 동작 시트 공격 2·3프레임은 몸을 숙여 키가 작음(약 210px) — 정상. 공격 3프레임 곡괭이 날이 공격 4프레임·아래 줄에 가까움 → 틈을 따라 자를 것. 작은 노움이라 `HEIGHT`는 작게.
  - 스킬 효과 **2·3프레임 번개 줄기가 캔버스 맨 위에 닿음**(하늘에서 내려오는 번개라 정상) → 적 위에서 재생할 때 위쪽이 잘려 보이지 않게 아래 붙임(`bottom=True`).
  - 연쇄: 맞은 적마다 효과를 따로 짧게 재생 + 적 사이를 잇는 번개 선은 코드로 그리기(예: 하늘색 지그재그 선).

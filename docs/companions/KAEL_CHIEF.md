# 유니크 「카엘 촌장」 기획 기록

작성일: 2026-10-23 · 상태: **기획·그림 완료, 게임 등록은 보류** (대표님 지시: 기록만)

## 결정 사항 (대표님, 2026-10-23)
- 새 등급 **「유니크」** 신설. 일반·희귀·영웅·전설 위. **유료 결제로만 얻는 등급** (결제 유도 상품).
- 첫 유니크 동료: **카엘 촌장** — 은퇴하고 마을 촌장이 된 미래의 카엘. 한국 새마을운동 초록 모자를 쓴 촌장님 모습.
- 쓰임새: **카엘 자리 교체형** — 편성에서 카엘 대신 출전. 장비·칭호는 카엘 것을 그대로 이어받고, 모습·스킬·마을 스킬만 바뀜.

## 유니크 등급 얻는 방법·별 올리기 (대표님 확정, 2026-10-23)
### 처음 얻기 (카엘 촌장)
- **500원 결제** 또는 **은퇴 10회** 중 하나로 ★1 합류.
- 상품은 **첫 은퇴 때** 상점에 열림. 500원은 지금 상점 최저가(1,200원)보다 낮은 새 가격 단계 → 앱 스토어 최저 가격 단계에 맞는지 등록 때 확인.
- 카엘 촌장만 은퇴로도 얻을 수 있는 예외. **이후 유니크 동료는 결제 전용**.

### 별 올리기 = 유니크 카드로만
- **유니크 카드**: 특정 동료 카드가 아니라, 받은 뒤 **원하는 유니크 동료를 골라 쓰는 지정형 카드**.
- 별마다 필요한 카드: **★2 20장 · ★3 40장 · ★4 80장 · ★5 150장 (합계 290장)**. 은퇴 횟수로 별을 올리는 방식은 없음.

### 유니크 카드를 얻는 곳 (이 두 곳뿐)
**① 결제 상품의 덤** — 유니크 카드만 따로 파는 상품은 **절대 만들지 않음**. 황금 이삭으로 바꾸는 교환소도 없음(사실상 직접 구매가 되므로).
| 상품 (지금 가격) | 덤 유니크 카드 |
|---|---|
| 황금 이삭 60 (1,200원, `p1`) | 없음 |
| 황금 이삭 330 (5,500원, `p2`) | 2장 |
| 황금 이삭 680 (11,000원, `p3`) | 5장 |
| 황금 이삭 1,280 (22,000원, `p4`) | 12장 |
| 황금 이삭 3,280 (55,000원, `p5`) | 35장 |
| 황금 이삭 6,480 (99,000원, `p6`) | 70장 |
| 피트의 정기 배송 (5,500원/30일, `sub`) | 매일 1장 (30일에 30장, 받으러 들어와야 함) |

**② 랭킹 시즌 보상 (2주마다, 우편함)** — `docs/RANKING.md` 시즌 보상에 추가
| 순위 | 추가 유니크 카드 |
|---|---|
| 1위 | 30장 |
| 2~10위 | 15장 |
| 상위 10% | 8장 |
| 상위 50% | 3장 |
| 참여(기록 1회 이상) | 1장 |

- 참고 속도: 정기 배송만 꾸준히 → 약 10개월에 ★5. 무과금 상위 10% 유지 → 약 1년 반에 ★5.

### 능력치·스킬 (제안값, 등록 세션에서 최종 확인)
| 항목 | 제안 |
|---|---|
| 능력치 | 카엘 능력치(장비·칭호 공유) + 보너스: ★1 +5% · ★2 +7.5% · ★3 +10% · ★4 +12.5% · ★5 +15% (공격·체력). 일반 공격은 카엘과 같음 |
| 스킬 「다 함께 울력」 | 8초 동안 원정대 전원 공격력 +25%, 공격 속도 +20%. ★3 ×1.3, ★5 ×1.6 (마고 8초 공격력 +20%보다 조금 강함) |
| 마을 스킬 「새벽 종소리」 | 마을 건물 6종 전체 생산 +10%(★1) ~ +20%(★5), 별마다 +2.5% (전설은 건물 1종 +50%~) |

### 밸런스 원칙
- 전설보다 조금만 강하게. 가치는 **카엘 자리 선택권 + 전원 버프 + 마을 스킬 + 외형**에.
- 상점 결제는 지금 시험 모드 — 실제 판매는 결제 연결(RELEASE_NATIVE) 이후.

- 동작 시트 시행착오(다음 그림 요청 때 참고):
  - 1차: 성검이 두 자루(등 + 손) 나옴 → "성검은 한 자루, 손에 들면 등은 비움" 명시.
  - 2차: 보석이 칼집 끝에 붙고 칼집 끝을 쥠 + 체크무늬를 그린 가짜 투명 배경 → 칼 부위를 ①~⑤로 못 박고 "칼자루만 쥠", "체크무늬 그리지 말 것" 명시.
- 등록 시 확인:
  - 대기·공격에서 성검이 몸 앞으로 길게 나와 프레임 폭이 넓음 → 몸(발) 기준으로 중심 맞출 것.
  - 피격 2프레임은 모자가 들림 → 키 기준 주의.
  - 스킬 아이콘·효과는 빛 번짐이 넓고 반투명 → 어두운 배경에서 확인. 버프형이라 효과는 원정대 전체 위 또는 카엘 자리에 크게 재생 권장.

## 등록할 때 할 일
- 등급 `unique` 신설: GRADE 표·테두리(`frame_unique`)·등급 색. 카드 뽑기 대상에서 제외(일반 동료 카드 확률에 넣지 않음).
- 유니크 카드: 지정형 재화(`S.ucard` 등) 추가, 동료 상세 창에서 골라 사용 → 별 올리기.
- 상점: 500원 카엘 촌장 상품(첫 은퇴 후 노출), `PACKS`·`SUB`에 덤 유니크 카드. 유니크 카드 단독 상품·이삭 교환 금지.
- 은퇴 10회 달성 시 카엘 촌장 무료 합류. 랭킹 시즌 정산(`kd_settle_due`)에 유니크 카드 보상 추가.
- 카엘 자리 교체: `JSLOT`의 `kael` 자리에 `kael_chief` 선택 가능하게 (`slotMember`, `seatSheet`, `autoForm`, 편성 화면의 `j==='kael'` 분기들). 장비·칭호는 카엘 것 공유.
- 그림 파일 이름은 카엘과 같은 4종: `kael_chief_{idle,walk,attack,hit}.png`.
- 이후 COMPANION_GUIDE.md 6장 순서: COMP · RECRUITS · VPAS(새벽 종소리) · HEIGHT/SPRITES/FORM · SKILLS · castSkill(전체 버프) · FXDEF(`skill_kael_chief:4`) · SPRITE_ALT/DRAW · NPCID.

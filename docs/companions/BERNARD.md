- 등록 시 확인:
  - **공격 2프레임에서 치켜든 칼끝이 바로 위 걷기 프레임에 닿음** → 직선 말고 알파가 가장 적은 곡선 경로로 자를 것.
  - 몸 주변에 아주 옅은 붉은 번짐 점들이 있음 → 자를 때 투명도 기준값으로 걸러낼 것.
  - 공격 프레임은 칼이 앞으로 길게 나와 폭이 넓음 → 몸(발) 기준으로 중심 맞출 것.
  - 초상화 원본은 두 그림의 망토 끝이 붙어 있어 곡선 경로로 잘라 나눔.
  - 효과는 진홍 빛 번짐이 넓음 → 적마다 재생할 때 크기 작게, 어두운 배경에서 확인.

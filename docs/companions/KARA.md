## 차별점
- 마고(회복+공격↑)·루카(회복·공속)·덕배(불굴) 모두 아군 지원형 → **요리사 자리 첫 공격형**.
- 실루엣: 만두머리 + 웍. 고정관념 표현(눈 모양 과장 등)은 피하고 의상·요리 도구로만 분위기.

- 등록 시 확인:
  - 참고 시트·동작 시트는 투명 부분 밑에 붉은·갈색 배경색이 숨어 있음(투명도는 정상). 옅은 번짐이 있으니 자를 때 투명도 기준값으로 걸러낼 것.
  - **웍이 몸 뒤로 크게 나와** 프레임마다 그림 폭이 다름 → 프레임 중심을 몸(발) 기준으로 맞출 것. 공격 1·3프레임은 웍이 앞뒤로 길게 뻗음.
  - 동작 시트 공격 1프레임은 웍이 몸 앞쪽(왼쪽 아래)으로 나와 있어 측면이 살짝 어색할 수 있음 → 게임 화면에서 확인.

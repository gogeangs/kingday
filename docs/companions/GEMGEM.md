## 추가 배경
- 대표님 지시 "영웅 동료를 제안해줘" (2026-10-27)의 후보 4명(폴리·젬젬·플로라·바오) 중 바오·폴리에 이어 **젬젬** 진행. 플로라는 미진행.

## 확정 설정

|---|---|
| 이름 / id | 젬젬 / `gemgem` (게임 안 같은 이름 없음 확인) |

| 관계 | **브리다를 할머니처럼 따라다님** (합류 대사 웃음 포인트). 브론과는 힘겨루기 |
| 생김새 (참고 시트 기준) | 동글동글한 회색 바위 몸(2등신), 짧고 굵은 다리, 몸에 비해 큰 바위 주먹 둘, 가슴 한가운데 큰 보라 수정(은은히 빛남), 어깨·팔의 보라·하늘색 보석 조각, 머리 위 초록 이끼·새싹과 주황 점박이 버섯, 빛나는 하늘색 동그란 눈(입 없음 — 눈 모양으로 표정), 금 간 틈과 금빛 마름모 룬 무늬 |
| 도구 | 없음 — 바위 주먹으로 싸움 |
| 대표 색 | 바위 회색 + 보라 수정 + 이끼 초록 |
| 성격 | 순하고 듬직함, 말 대신 눈과 몸짓으로 감정 표현 |
| 스킬 「수정 표식」 | 적들에게 수정 표식을 붙임. 표식 붙은 적이 쓰러지면 **수정이 터져 주변 적까지 피해** — 동료 중 첫 처치 연쇄 폭발. 영웅 등급 (★3 ×1.3, ★5 ×1.6) |
| 마을 스킬 | 영웅 기존 규칙(없음) |

## 차별점
- 광부 동료 모두 사람·드워프·도깨비·거인·노움 → **첫 골렘(돌 몸·무기 없음·입 없음)**.
- 효과: 전체 피해(페피·뚝딱이)·연쇄 번개(핍스)·처형(하그린)과 달리 **쓰러질 때 터지는 표식**(적이 많을수록 강함).

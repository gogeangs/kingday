# 유니크 양봉가 「골디」 기획 기록

작성일: 2026-10-27 · 상태: **게임 등록 완료 (2026-10-27, 웹·앱)**

## 추가 배경
- 대표님 지시 "다른 동료를 제안해줘" (2026-10-26). 후보 5명(유니크 양봉가 골디 / 유니크 어부 세레스 / 희귀 광부 노크 / 일반 양봉가 틸리 / 일반 요리사 토마) 중 **골디** 선택. 나머지는 미진행.
- 양봉가 자리 첫 유니크. 기존 유니크: 카엘 촌장(카엘 자리)·뚝딱이(광부)·루시안(요리사).
- 골디는 처음 유니크 후보(판타지, 2026-10-26)로 제안했던 아기 황금용.

## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 골디 / `goldie` (게임 안 같은 이름 없음 확인) |
| 직업 / 등급 | 양봉가(꿀만 먹고 자란 아기 황금용) / **유니크**(유료) |
| 나이 | 아기 용(사람 나이로는 수백 살, 마음은 아기) |
| 콘셉트 | 용의 둥지에서 굴러떨어져 리엘의 벌통 꿀을 훔쳐 먹다 잡힘. 꿀만 먹고 자라 비늘이 꿀빛 황금색 |
| 관계 | **리엘을 엄마로 알고 졸졸 따라다님** (합류 대사 웃음 포인트). 브루노와는 꿀 도둑 선후배 |
| 생김새 (참고 시트 기준) | 2등신 통통한 아기 용(두 발로 섬), 꿀빛 황금 비늘(점무늬), 크림색 배(가로 줄), 크고 동그란 호박색 눈, 작은 송곳니, 발그레한 볼, **머리 둘레를 감싼 황금 가시 갈기**(기획의 작은 왕관 뿔 대신 — 실루엣이 좋아 확정), 연주황 박쥐 날개, 벌집 무늬 둥근 꼬리 끝, 갈색 발톱 |
| 소품 | 목에 끈으로 건 작은 꿀단지(꿀이 흘러내림). 손에 드는 도구 없음 |
| 대표 색 | 꿀 황금 + 크림 + 연주황 |
| 성격 | 해맑고 먹보, 혼나면 금방 울먹임, 엄마(리엘) 바라기 |
| 스킬 「황금 브레스」 | 꿀빛 불길로 **모든 적에게 큰 피해 + 겁먹어 잠깐 아무것도 못 함**(보스는 짧게) — 큰 피해와 넓은 제어를 한 번에 |
| 마을 스킬 | 유니크 규칙대로 등록 세션에서 결정 (양봉 관련 제안 예: 양봉장 꿀 생산↑ — 말봉과 겹치면 다른 것으로) |

## 판매 규칙 (KAEL_CHIEF.md · TTUKTTAK.md · LUCIAN.md 규칙 그대로)
- 유료로만 얻음. 유니크 카드는 결제 덤과 랭킹 보상으로만 받음 — 카드만 따로 파는 상품은 만들지 않음.
- 합류 방법·가격은 뚝딱이·루시안(피트 상점 「맞이하기」 ₩5,500, 소모성, `uqJoin`)과 같게 등록 세션에서 결정.

## 차별점
- 리엘(요정)·데이지·말봉·안단테·멜로·버치·엘름(나무 정령)·오스카(기사)·브루노(곰)와 겹치지 않게 **아기 용 + 가시 갈기 + 날개**. 무기 없이 몸으로 싸우는 동료.

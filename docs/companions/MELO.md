# 일반 양봉가 「멜로」 기획 기록

## 추가 배경
- 일반 모집 동료 추가 3명(모라·멜로·포리) 중 두 번째 (대표님 결정, 2026-10-21).

## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 멜로 / `melo` (판타지 이름, 꿀을 뜻하는 「멜」에서) |
| 직업 / 등급 | 양봉가(꿀 행상) / 일반 |
| 콘셉트 | 꿀단지를 잔뜩 지고 마을마다 꿀을 파는 붙임성 좋은 소년. "달콤한 꿀 있어요~" |
| 관계 | 리엘의 꿀을 떼어다 팔다가 합류. 리엘이 "꿀값은 언제 줄 거니?" 하고 쫓아다님 (합류 대사 웃음 포인트) |
| 생김새 | 15살쯤 소년, 통통한 볼, 늘 웃는 실눈, 볼에 꿀 한 방울, 부스스한 꿀빛 금발에 연두색 이마 두건(옆 매듭) |
| 옷 | 크림색 셔츠(소매 걷음) + 연두색 조끼, 허리에 밧줄 띠, 갈색 반바지(덧댄 천), 밧줄 샌들, 허리에 금 동전 장식 가죽 주머니 |
| 도구 | 등에 나무 지게(천 뚜껑을 밧줄로 묶은 꿀단지 4~5개, 꿀이 넘쳐흐름), 손에 꿀단지 하나 |
| 대표 색 | 연두 + 꿀색 + 갈색 |
| 성격 | 넉살 좋고 붙임성 있음, 장사 수완이 좋지만 셈은 서툶 |
| 스킬 「끈적 꿀단지」 | 꿀단지를 던져 **적 하나에 피해 + 느려짐** — 일반 등급 단순 효과 (일반 최대 ★3 → ★3 ×1.3 적용) |

## 차별점
- 리엘(요정)·데이지(소녀)·말봉(근육 아저씨)·안단테(지휘자)와 겹치지 않게 **꿀단지 지게** 실루엣.
- 토비(마른 소년, 주황·청록)와 구분: 통통한 체형, 실눈, 연두·꿀색.

- 등록 시 확인:
  - **지게가 몸 뒤로 크게 나와** 프레임 폭이 넓음 → 몸(발) 기준으로 중심 맞출 것. 지게 꿀단지가 머리 높이까지 올라와 키 기준 주의.
  - 효과 시트 4프레임(웅덩이)은 바닥에 깔리는 모양 → 감속 지속 표시로 반복 재생해도 됨.
  - 동작 시트 가장자리에 옅은 번짐이 있어 자를 때 투명도 기준값으로 걸러낼 것.

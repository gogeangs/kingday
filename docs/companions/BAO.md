## 차별점
- 마고·루카·카라·포리·그램·덕배·베르나르·소피·루시안·그룩(오크)과 겹치지 않게 **판다 + 등에 진 찜통 + 뚜껑 방패**. 요리사 자리 첫 방어형 영웅.
- 효과: 피해 감소(브론·브리다)·보호막 양(오스카)·도발(브루노)과 달리 **막는 횟수**.

- 등록 시 확인:
  - 동작 시트 공격 1프레임은 합성본(어두운 배경에서 확인 완료).
  - 스킬 아이콘 오른쪽 끝에 김이 4px 닿음(흐림) — 256px로 줄이면 티 안 남.
  - 스킬 효과 **3·4프레임이 서로 붙어 있음**(빈 세로줄 없음, 3프레임 별빛 꼬리가 4프레임 김에 닿음) → 곡선 경로로 자르거나 `extract_skill_fx.py`에서 x 직접 지정. 2·3프레임 사이도 좁음(빛 번짐).
  - 막기 표시: 맞을 때마다 「막음!」 글자 + 뚜껑 효과 짧게, 남은 횟수는 동료 머리 위 작은 숫자 등.

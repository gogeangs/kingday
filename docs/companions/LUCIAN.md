## 추가 배경
- 대표님 지시 "유니크 동료 1개를 만들어보자" → "판타지 스타일로" (2026-10-26). 후보 3명(어부 유령선 선장 반 데르 / 양봉가 아기 황금용 골디 / 요리사 불사조 요리장) 중 **불사조 요리장** 선택.
- **이름 변경:** 처음 이름은 「이그니스」였으나 게임에 이미 마지막 보스 **「화염의 군단장 이그니스」**(`boss_ignis`, NPCID `'이그니스':'ignis'`, `art/source/portraits/portrait_ignis_idle.png`)가 있어 겹침 → 대표님 결정으로 **「루시안」**(`lucian`)으로 변경. 그림 파일도 모두 `lucian` 이름으로 저장.
- 기존 유니크: 카엘 촌장(카엘 자리)·뚝딱이(광부). 요리사 자리 첫 유니크.

## 판매 규칙 (KAEL_CHIEF.md · TTUKTTAK.md 규칙 그대로)
- 유료로만 얻음. 유니크 카드는 결제 덤과 랭킹 보상으로만 받음 — 카드만 따로 파는 상품은 만들지 않음.
- 합류 방법·가격은 뚝딱이(피트 상점 「맞이하기」 ₩5,500, 소모성 상품)를 참고해 등록 세션에서 결정.

## 차별점
- 덕배(한식 숙수)·베르나르(기사 요리장)·소피(마녀 제과사)·루카(빵집 소년)와 겹치지 않게 **불꽃 머리 + 불사조 깃털 앞치마 + 어깨 위 아기 불사조**.

## 게임 등록 (2026-10-26)
- **합류**: 피트의 상점 「루시안 맞이하기」 ₩5,500 (처음부터 보임, 뚝딱이 줄 바로 아래, 합류하면 사라짐) → 합류 장면(덕배·베르나르와 최고 요리사 다툼) → 「바로 출전」이면 요리사 자리. 스토어 상품 `kd_lucian`(소모성), 서버 보상 우편 `{lucian: 1}`. 별은 유니크 카드(카드 탭 줄·동료 창 ★ 올리기).
- **능력치**: base 공6·체115·공속0.85, per 공1.95·체23, 유니크 배율 ×1.4 → 요리사 일반 평균 대비 **1.87**(덕배 1.81보다 약 3% 위, 뚝딱이와 같은 위치).
- **스킬 「불사조의 만찬」** (게이지 30): 원정대 체력을 모두 채우고, 8초 동안(★3 10.4초 · ★5 12.8초) 쓰러지면 한 번 체력 50%로 부활. 덕배 불굴(체력 1로 버팀)이 먼저 쓰이고, 그다음 부활. 시련의 탑 「회복 금지」 규칙에서는 회복·부활 없음. 웹 `SKX.phx`·`P[id].phx` ↔ 앱 `skx.phx`·`Member.phx`.
- **마을 스킬 「왕실 납품」**: 시장 주문 골드 +50~100%(별에 따라, `vpRoyal` → `ordGold`). 출전하지 않아도 적용.
- **유니크 공통 정리**: 뚝딱이·루시안 합류를 `uqJoin(id)`(앱 `uqJoin`·`ActUqScene`)로 묶음. 카드 탭 줄은 `uqRow(id)`.

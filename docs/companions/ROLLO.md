# 일반 광부 「롤로」 기획 기록

작성일: 2026-10-21 · 상태: **기획·그림 완료, 게임 등록은 보류** (대표님 지시: 기록만)

## 추가 배경
- 일반 모집 동료 2차 추가 4명(롤로·크랩·버치·그램)을 한 명씩 진행 (대표님 결정, 2026-10-21). 그 첫 번째.
- 참고: 일반 동료가 늘면 일반 카드 확률(가중치 55)을 나눠 가져 동료 1명당 카드가 덜 나옴 → 등록 시 확률 확인.

## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 롤로 / `rollo` (판타지 이름, 굴러가는 광차에서) |
| 직업 / 등급 | 광부(광차꾼) / 일반 |
| 콘셉트 | 평생 광석 수레만 밀어 온 허리 꼿꼿한 노인. "수레는 밀어야 굴러가는 법이여." |
| 관계 | 브론이 신참일 때부터 갱도에 있던 고참. 브론을 아직도 「꼬맹이」라 부름 (합류 대사 웃음 포인트) |
| 생김새 | 70대 사람 할아버지(드워프 아님), 볕에 탄 주름진 얼굴, 늘 감은 듯 가는 눈, 크고 하얀 팔자 콧수염, 부스스한 흰 옆머리, 둥근 코 |
| 옷 | 낡은 회갈색 헌팅캡, 소매 걷은 남색 작업 셔츠 + 갈색 멜빵, 너덜한 빨간 목수건, 무릎 덧댄 갈색 작업 바지, 검은 장화, 갈색 가죽 장갑 |
| 도구 | 끝이 갈고리인 긴 쇠 지렛대, 허리에 불 켜진 광산 랜턴과 작은 기름통 |
| 대표 색 | 남색 + 녹슨 빨강 + 갈색 |
| 성격 | 느긋하고 고집 셈, 말끝마다 옛날이야기 |
| 스킬 「광차 굴리기」 | 광석 가득한 광차를 밀어 보내 **앞줄 적들을 관통 피해** — 일반 등급 단순 효과 (일반 최대 ★3 → ★3 ×1.3 적용). 광차는 스킬 효과에서만 등장 |

## 차별점
- 브론·브리다(드워프)·고든(석공)·페피(발파공)·베릴(감정사)과 겹치지 않게 **사람 노인 + 긴 쇠 지렛대 + 하얀 콧수염** 실루엣.
- 일반 동료 효과: 고든(기절+반격)·모라(단일 피해)·멜로(피해+감속)·포리(단일 회복)와 달리 **관통 피해**.

## 받은 그림 (2026-10-21)
| 그림 | 상태 | 메모 |
|---|---|---|
| ⓪ 참고 캐릭터 시트 | 받음 | 정면·측면·뒷모습·표정 5종·지렛대 밀기·기대기·상자에 앉기·광차 등 혼합, 게임용 아님(디자인 기준) |
| ① 동작 시트 | 받음 | 4줄 4/6/4/2 프레임, 오른쪽 측면, 모든 프레임에 지렛대, 광차 없음. 공격=지렛대 잡고 당김→몸 낮춤→앞으로 길게 찌름→다시 짚고 섬 → `tools/extract_sprites.py` 대상. **피격 2프레임 머리 옆에 작은 파란 땀방울 효과가 있음** |
| ② 초상화 2종 | 받음 | 둘 다 지렛대를 어깨에. 왼쪽 콧수염 쓰다듬는 느긋한 얼굴 / 오른쪽 껄껄 웃음 |
| ③ 스킬 아이콘 | 받음 | 광석 가득한 녹슨 광차가 오른쪽으로 질주 + 바퀴 불꽃 + 속도선·먼지 |
| ④ 스킬 효과 시트 | 받음 | 가로 4프레임: 광차 출발·불꽃 → 질주·속도선 → 덜컹 튀며 광석 쏟아짐·먼지 → 먼지·돌조각만 남음 |

- 등록 시 확인:
  - **공격 2~3프레임에 지렛대가 앞으로 아주 길게 뻗어** 프레임 폭이 넓음 → 몸(발) 기준으로 중심 맞출 것. 대기·걷기의 갈고리 끝이 머리 위로 올라와 키 기준 주의.
  - 피격 땀방울 효과는 작아서 그대로 둬도 무방.
  - 스킬 효과는 광차가 오른쪽으로 이동하는 연출이라 4프레임을 앞쪽으로 조금씩 옮기며 재생하면 관통 느낌이 남.
  - 동작 시트 가장자리에 옅은 번짐이 있어 자를 때 투명도 기준값으로 걸러낼 것.

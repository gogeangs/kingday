작성일: 2026-10-21 · 상태: **기획·그림 완료, 게임 등록은 보류** (대표님 지시: 기록만)

## 진행 순서 변경
- 동료 7명 중 **전설부터** 기획: 어부(막례) → 양봉가(말봉) → 요리사(덕배). 이후 영웅(페피·안단테), 희귀.
- 희귀 어부 기획안(토비 뱃사공 소년 / 세린 집어등 어부 / 마리나 진주 잠수부)은 제시만 하고 미선택.

## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 막례 / `makrye` (「박막례」는 실존 유튜버 실명과 같아 성 없이 「막례」 권장 — 최종 확인 필요) |
| 직업 / 등급 | 어부(해녀) / 전설 |
| 단짝 | 아기 크라켄 「말순이」 — 마족이 바다를 지키라고 풀어둔 크라켄을 막례가 길들여 키움. 마족은 아직 모름 |
| 하랄과의 관계 | 같은 마을 동갑내기. 하랄의 허풍("크라켄과 사흘 밤낮 싸웠다")을 "말순이가 너랑 놀아준 거야" 하고 까발리는 앙숙 콤비 |
| 생김새 | 70대, 작고 통통, 그을린 주황빛 피부, 은회색 곱슬 파마머리, 이마에 황동 테 물안경, 하얀 눈썹, 금 고리 귀걸이, 광택 검은 잠수복 + 밧줄, 맨발 |
| 도구 | 갈고리 모양 빗창(밧줄 감은 나무 자루), 등에 그물 감은 주황 테왁 + 초록 망사리(조개 장식), 망사리 속 보라색 말순이(노란 눈, 연보라 빨판) |
| 대표 색 | 검정 + 주황 + 보라 |
| 성격 | 걸걸하고 능청스러움, 정이 깊음. 말순이한테만 다정 |
| 스킬 「숨비소리」 | "호오이~" 휘파람 → 거대해진 말순이가 솟아 촉수로 **적 전체 피해 + 기절** (★3 ×1.3, ★5 ×1.6) |
| 마을 스킬 「물질 대장」 | 부두 생선 생산 **+50%~** (별마다 상승, 출전 안 해도 적용). `vpMine()`처럼 새 함수 필요(예: `vpFish()`) |

# 전설 요리사 「덕배」 기획 기록

작성일: 2026-10-21 · 상태: **기획·그림 완료, 게임 등록은 보류** (대표님 지시: 기록만)

## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 덕배 / `deokbae` |
| 직업 / 등급 | 요리사(한식 장인) / 전설 |
| 콘셉트 | 마족이 왕도를 빼앗기 전 왕의 수라상을 차리던 수라간 최고 숙수. 쫓겨나 시골에서 국밥집 운영 |
| 관계 | **마고의 스승**. "네가 왕이 되면 수라상을 다시 차려주마" 하며 카엘에게 합류 (게임 목표 「왕이 되는 날」과 연결) |
| 생김새 | 70대 할아버지, 작고 다부짐, 흰 상투 + 검은 망건(가운데 그물무늬, 양옆 금색 관자), 가슴까지 늘어진 풍성한 흰 수염, 숱 많은 흰 눈썹, 깐깐하지만 인자한 눈 |
| 옷 | 흰 한복식 조리복(저고리·바지, 소매 걷음), 쪽빛 앞치마(앞 매듭), 쪽빛 대님, 흰 버선 + 짚신 |
| 도구 | 손에 큰 놋쇠 국자, 등에 밧줄로 묶은 둥근 놋 소반 |
| 대표 색 | 흰색 + 쪽빛 + 놋쇠 금색 |
| 성격 | 깐깐하고 고집 센 장인, 음식 남기면 호통. 속정 깊음 |
| 스킬 「보양 수라상」 | 왕에게 올리던 보양 한 상 → **아군 전체 불굴**(일정 시간 동안 쓰러질 피해를 받아도 한 번 버팀) — 동료 중 첫 효과 (★3 ×1.3, ★5 ×1.6: 지속 시간 증가) |
| 마을 스킬 「수라간의 손맛」 | 요리 버프 시간 **+50%~** (별마다 상승, 출전 안 해도 적용). 새 함수 필요(예: `vpCook()`) |

## 차별점
- 마고(회복+공격↑), 루카(회복·공속)와 달리 **회복 없는 생존(불굴)형**.
- 하랄(늙은 어부)과 겹치지 않게 상투·망건·흰 수염·놋 소반 실루엣.

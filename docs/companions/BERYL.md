## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 베릴 / `beryl` (판타지 이름, 보석 「녹주석」에서 따옴) |
| 직업 / 등급 | 광부(보석 감정사) / 희귀 |
| 콘셉트 | 깐깐한 보석 감정사. 브론이 캐 온 광석마다 흠을 잡아 값을 깎음 |
| 관계 | 브론과는 값 흥정으로 늘 티격태격, 브리다는 "내 대장간 물건 값을 제대로 매기는 유일한 녀석"이라고 인정 (합류 대사 웃음 포인트) |
| 생김새 | 그림에서 기획보다 어리게 나옴 → **10대 후반 소년 느낌**으로 확정. 부스스한 짙은 회색 머리, 보라빛 눈, 깐깐하게 찌푸린 눈매. 이마에 황동 테 렌즈 두 개(큰 것·작은 것, 보라빛 렌즈)가 달린 가죽 확대경 머리띠 |
| 옷 | 소매 걷은 흰 셔츠, 은 장식이 달린 자수정빛 보라 조끼, 손가락 없는 가죽 장갑 + 팔토시, 원석이 꽂힌 주머니가 여러 개 달린 갈색 가죽 세공 앞치마, 검은 통바지, 갈색 구두 |
| 도구 | 한 손에 은빛 세공 망치(기획보다 조금 큼), 앞치마 주머니에 보라색 원석들 |
| 대표 색 | 자수정 보라 + 갈색 가죽 + 황동 |
| 성격 | 깐깐하고 꼼꼼함, 흠을 찾으면 신나서 눈이 반짝임 |
| 스킬 「약점 감정」 | 적들의 금 간 곳을 찾아 표시 → 일정 시간 동안 **적이 받는 피해 증가(취약)** — 동료 중 첫 취약 디버프 (희귀 최대 ★4 → ★3 ×1.3만 적용) |

## 차별점
- 브론(피해 50%↓)·고든(기절+반격)·브리다(방어·반사)·페피(전체 폭발)와 달리 **디버프형**.
- 실루엣: 작은 체구 + 확대경 머리띠 + 세공 앞치마 + 망치. 드워프(브론·브리다)·석공(고든)과 겹치지 않음.
- 주의: 페피도 이마에 황동 고글을 씀 → 페피는 붉은 머리·빨간 화약통, 베릴은 회색 머리·보라 조끼·보라 렌즈로 구분됨.

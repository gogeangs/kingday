## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 살로 / `salo` (판타지 이름, 소금 「sal」에서) |
| 직업 / 등급 | 어부(소금 장수) / 일반 |
| 콘셉트 | 바닷물을 말려 소금을 만들어 파는 소금 장수. "짠맛이 있어야 세상이 돌아가지!" |
| 관계 | 마고 식당에 소금을 대는 단골. 하랄에게 "생선보다 소금이 더 귀하다"고 큰소리쳐 늘 티격태격 (합류 대사 웃음 포인트) |
| 생김새 (참고 시트 기준) | 40대 듬직하고 통통한 아저씨, 볕에 탄 피부, 짧은 턱수염, 굵은 눈썹, 시원하게 웃는 큰 입, 이마에 흰 수건 머리띠(뒤로 매듭) |
| 옷 (참고 시트 기준) | 여밈이 있는 푸른 조끼, 목에 건 흰 수건, 무릎까지 걷은 회색 바지, 허리에 굵은 밧줄 + 작은 호리병 두 개, 짚신, 팔에 소금 가루 |
| 도구 | T자 나무 소금 고무래(긴 자루 + 아래 끝의 넓적한 판, 자루에 밧줄 감김), 등에 멘 불룩한 삼베 소금 자루 |
| 대표 색 | 하늘색 + 흰색(소금) + 갈색 |
| 성격 | 호탕하고 말이 많음, 소금 자랑이 끝이 없음 |
| 스킬 「상처에 소금」 | 소금을 한 움큼 뿌려 **적 하나에게 지속 피해** — 일반 동료 중 첫 지속 피해 (일반 최대 ★3 → ★3 ×1.3) |

## 차별점
- 하랄(작살)·넬라(그물)·막례(빗창)·토비(노)·모라(생선)·크랩(집게)과 겹치지 않게 **T자 소금 고무래 + 등의 소금 자루** 실루엣.
- 일반 동료 효과: 단일 피해·공속 저하·피해+감속·관통·보호·회복과 달리 **단일 지속 피해**.

| 그림 | 상태 | 메모 |
|---|---|---|

| ① 동작 시트 | 받음 | 4줄 4/6/4/2, 오른쪽 측면, 투명 배경, 효과 없음, 고무래 한 자루·자루를 쥠, 소금 자루 계속 등에. 대기=고무래 세워 짚음, 걷기=어깨에 멤, 공격=젖힘→치켜듦→앞쪽 바닥 내리침→다시 세움 |
| ② 초상화 2종 | 받음 | 왼쪽 윙크하며 엄지 척 + 소금 한 움큼 / 오른쪽 머리 뒤에 손 얹고 껄껄 + 소금 한 움큼 |

| ④ 스킬 효과 시트 | 받음 | 가로 4프레임: 소금이 쏟아져 내림 → 하얀 결정 폭발 → 붉은 따끔 번쩍임 → 결정·번쩍임만 남음 |

- 등록 시 확인:
  - 걷기·공격 1·2프레임은 **고무래 판이 머리 뒤 위쪽으로 높이 올라가** 프레임 폭이 넓음 → 몸(발) 기준으로 중심 맞출 것. 공격 3프레임은 판이 앞으로 길게 뻗음.
  - 소금 자루가 몸 뒤로 크게 나옴.
  - 초상화 원본은 두 그림이 아래쪽에서 붙어 있어 알파가 가장 적은 곡선 경로로 잘라 나눔.
  - 효과 시트는 하늘색 빛 번짐이 넓음 → 어두운 배경에서 확인. 지속 피해라 3~4프레임 반복 재생 가능.

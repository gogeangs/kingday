| 옷 | 흰 반팔 티, 빨간 목 두건, 올리브색 작업 멜빵바지(무릎 덧댐), 허리에 묶은 소매, 가죽 장갑, 갈색 작업 부츠 |
| 도구 | 등에 밧줄 감은 빨간 화약통(도화선), 허리에 둥근 검은 폭탄들, 대기·걷기 때 어깨에 곡괭이 |
| 대표 색 | 빨강 + 올리브(카키) |
| 성격 | 덜렁대고 겁 없음, 터지는 걸 좋아함, 사고 쳐도 "헤헤" |
| 스킬 「발파」 | 화약통을 던져 **적 전체 큰 폭발 피해** — 광부 자리 첫 공격형 (★3 ×1.3, ★5 ×1.6) |

## 차별점
- 브론(피해 50%↓)·고든(기절+반격)·브리다(방어·반사) 모두 방어형 → **광부 자리 첫 공격형**.

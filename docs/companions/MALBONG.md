## 확정 설정
| 항목 | 내용 |
|---|---|
| 이름 / id | 말봉 / `malbong` |
| 직업 / 등급 | 양봉가 / 전설 |
| 콘셉트 | 「말벌아저씨」 — 보호복 없이 맨손으로 말벌을 잡는 무뚝뚝한 양봉가 (실존 인물 닮지 않게, 분위기만) |
| 관계 | 희귀 양봉가 **데이지의 아빠**. 무서워 보이지만 딸 앞에선 팔불출. 데이지가 "우리 아빠 진짜 착해요!" 하고 소개. (데이지·말봉 이름 차이도 합류 대사 웃음 포인트 후보: "엄마가 이름은 지었어요!") |
| 생김새 | 40대 후반, 떡 벌어진 어깨·두꺼운 근육질 팔, 탄 피부, 희끗한 짧은 검은 머리, 덥수룩한 턱수염(끝이 희끗), 짙은 눈썹·미간 주름, 맨팔에 반창고(X자 포함) |
| 옷 | 챙 넓은 흰 양봉 모자(노랑·검정 사선 줄무늬 띠, 망사 없음), 흰 민소매 러닝셔츠, 노란 멜빵(은색 고리), 갈색 벨트, 갈색 카고 작업 바지, 노란 테두리 검은 장화, 맨손 |
| 도구 | 등에 노란 테 곤충 채집망(밧줄 감김), 허리춤 구멍 뚫린 황동 훈연기(연기 살짝) |
| 대표 색 | 노랑 + 검정 줄무늬, 흰색 |
| 스킬 「맨손 잡기」 | 가장 강한 적(보스 우선)을 맨손으로 움켜잡아 **단일 큰 피해 + 잠깐 기절** — 동료 중 첫 보스 저격형 (★3 ×1.3, ★5 ×1.6) |
| 마을 스킬 「말벌 퇴치반」 | 양봉장 꿀 생산 **+50%~** (별마다 상승, 출전 안 해도 적용). 새 함수 필요(예: `vpHoney()`) |

## 차별점
- 리엘(벌통 엎기: 지속 피해·감속), 데이지(꽃가루 폭풍: 광역 중독)와 달리 **단일 일격형**.
- 실루엣: 듬직한 체격 + 채집망. 요정(리엘)·소녀(데이지)와 겹치지 않음.

# 게임 기획 요약

전체 기획서 원본: [왕이 되는 그날까지 기획서](https://claude.ai/code/artifact/dec5f4fa-a9e0-4e3c-8d55-e424311d287f)

## 세계관

300년 전 봉인됐던 마계의 문이 다시 열려, 마왕군이 하룻밤 만에 에르단 왕국을 무너뜨렸다. 대륙은 마왕 아래 다섯 군단장이 나눠 다스린다. 군단마다 영지 10곳, 영지마다 스테이지 10개.

## 전체 줄거리

- 프롤로그: 농부 카엘이 밭에 박힌 녹슨 쇠막대를 뽑는다. 300년 동안 주인을 기다린 성검 루미나르였다.
- 1부 「잃어버린 왕국」: 다섯 군단을 몰아내고 왕도를 되찾는다. 마왕의 정체는 300년 전의 왕이자 성검의 첫 주인 발타사르. 그는 왕관을 들고 마계로 사라진다.
- 2부 「흩어진 동맹」: 엘프 왕국, 사막 제국, 북방 부족을 해방하고 연합군의 맹주가 된다.
- 3부 「마계 원정」: 일곱 마왕을 쓰러뜨리고, 발타사르가 내민 왕관을 부순다. 백성들이 카엘을 왕이라 부른다. 마지막 장면은 왕궁 뒤뜰에서 밭을 가는 카엘.
- 엔딩 이후: 300년마다 봉인이 약해져 새 회차가 시작된다.

## 주인공 콤비

- 카엘: 은퇴만 꿈꾸는 농부. 입버릇은 "이번 영지만 되찾고 은퇴할 거야."
- 성검 루미나르: 카엘을 왕으로 만들고 싶어 안달인 자존심 센 성검. 괭이 취급을 받으면 비명을 지른다.

## 시스템

- 영지 탈환 지도, 칭호(농부 → 마을 지킴이 → 기사 → 영주 → 백작 → 공작 → 왕)
- 밭과 요리 버프, 생활 건물의 방치 생산
- 은퇴하기(환생): 처음으로 돌아가며 영구 보너스 "은퇴의 추억"을 얻는다
- 방치 보상: 되찾은 영지의 세금

# 유료화 제거 · 광고 중심 전환 계획

작성일: 2026-11-16 · 상태: **1단계(황금 이삭 측정) 완료 — 대표님 확인 기다림**
관련: `docs/HANDOFF_NATIVE.md` §5-1 · `docs/RELEASE_NATIVE.md` §5 · `docs/content/SHOP.md` · `docs/companions/KAEL_CHIEF.md` · `docs/companions/TTUKTTAK.md`

## 왜
대표님이 앱을 보고 "수익성이 떨어진다"고 느낌 → 결제를 모두 없애고 수익은 보상형 광고(AdMob)만 남긴다.

## 결정 사항 (대표님 확정, 2026-11-16)

### 1. 결제 완전 제거 (코드까지)
- 없애는 상품: 황금 이삭 꾸러미 6종(`kd_gem_60`~`kd_gem_6480`), 첫 거래 특가(`kd_starter`), 정기 배송(`kd_sub_monthly`), 원정 일지 유료 줄(`kd_pass`), 영주의 첫걸음(`kd_growth`), 카엘 촌장 맞이하기(`kd_chief`), 뚝딱이 맞이하기(`kd_ttukttak`)
- 숨기기가 아니라 코드까지 지운다: 웹 `pay()`/`TEST_PAY`, 앱 `IapStore`·인앱결제 패키지, 상점 「구매 복원」 칸, 서버 `kd-iap` 함수와 결제 관련 SQL
- 지우기 직전 커밋에 태그 `iap-last`
- 실제 결제자 없음(테스트 계정뿐) → 환불·보상 처리 없음
- 유지: 랭킹 시즌 유니크 카드 보상, 원정 일지 시즌 기록

### 2. 유니크 등급 = 「오래 한 사람이 얻는 최고 등급」
- 뚝딱이: 영지 50 처음 탈환(`S.best` 기준) 때 합류. 이미 넘긴 세이브는 접속할 때 확인해서 합류. 합류 장면은 기존 것
- 카엘 촌장: 은퇴 10회(지금 그대로). 500원 상품만 제거
- 별 올리기 유니크 카드: ★2 10 · ★3 15 · ★4 30 · ★5 45 (합계 100, 지금 290). 이미 쓴 카드가 새 기준을 넘는 세이브는 별을 맞춰 올리고 남는 카드는 그대로 둠
- 유니크 카드 얻는 곳: 랭킹 시즌 보상(그대로) + 원정 일지 무료 줄(시즌마다 5장) + 시련의 탑 10층마다 처음 돌파 때 2장 + 출석 7일마다 1장
- 목표 속도: 보통 유저 약 반년~1년에 ★5

### 3. 원정 일지는 무료 줄 한 줄만
- 기존 무료 보상은 그대로 두고 더함: 짝수 단계마다 이삭 15(합계 150) / 1·5·9·13·17단계 동료 카드 3장 / 10단계 상자 10연속 무료권 + 유니크 카드 2장 / 20단계 시즌 한정 테두리 + 유니크 카드 3장
- 제거: 유료 줄, 「₩3,300 원정 일지 열기」 버튼, 자물쇠, 마감 3일 전 구매 경고. 「모두 받기」는 유지
- 점수 얻는 법·하루 한도는 그대로

### 4. 황금 이삭: 먼저 재고 보고 → **결과는 아래 「1단계 측정 결과」**
- 상점 이삭 가격은 바꾸지 않는다. 모자라면 출석·업적·탑·광고 보상에 이삭을 더 얹는 안을 제안

### 5. 보상형 광고 자리 4개 추가 (강제 광고 없음 원칙 유지)
| 자리 | 보상 | 하루 한도 |
|---|---|---|
| 보스에게 졌을 때 「광고 보고 다시 도전」 | 그 도전 동안 원정대 공격력 +30% | 5회 |
| 상점 「광고 보고 이삭 받기」 | 이삭 10 | 3회 |
| 전투 화면 「자동사냥 속도 2배」 | 30분 동안 2배, 남은 시간 표시 | 4회 |
| 원정 일지 「광고 보고 점수 받기」 | 점수 10 | 3회 |
- 웹은 가짜 광고 `watchAd`, 앱은 AdMob 보상형 광고. 보상은 보상 지급 콜백에서만
- 수치는 제안값 — 시뮬레이터로 확인. 미디에이션(AppLovin·Unity)은 이번에 하지 않음

### 6. 유저 행동 기록 (Supabase)
- 계정 id로만 묶고 개인을 알아볼 정보는 넣지 않음
- 기록: 하루 접속(재방문 계산), 광고 자리별 시청 횟수, 마지막 도달 영지·은퇴 횟수, 이삭 얻은 양·쓴 곳
- 개인정보처리방침에 「서비스 이용 기록」 항목 확인, 없으면 추가 문구 제안

### 판단
- **결정대로 바꾸면 하루 약 130 > 쓰고 싶은 양 약 120 → 이삭을 더 얹지 않아도 됨(권장).** 처음 한 달은 한 번뿐인 보상(약 1,900) 덕분에 넉넉함.

### 같이 확인한 것 (다음 단계 전에 대표님 확인 필요)
1. **상점 이삭 광고가 이미 있음**: 「피트의 선물 · 황금 이삭 +5」 하루 3번(`ADS.gem`). 새 자리 「광고 보고 이삭 받기 10 × 3」을 **이 칸을 10으로 올리는 것**으로 할지(권장, 하루 광고 이삭 30), **따로 한 칸 더**(하루 45)인지
2. **결제로만 얻는 유니크가 2명 더 있음**: 루시안(`kd_lucian`)·골디(`kd_goldie`), 둘 다 ₩5,500. 목록에 없었지만 결제를 다 없애면 얻을 길이 없어짐. 제안: 루시안 = 시련의 탑 100층 처음 돌파, 골디 = 누적 출석 60일 (둘 다 합류 장면은 기존 것)
3. **뚝딱이 합류가 빠름**: 시뮬레이터에서 보통 유저가 **5일째** 영지 50을 되찾음 → 뚝딱이는 「오래 한 사람」보다 「1부를 깬 사람」 보상에 가까움. 이대로 둘지, 왕도(영지 51~60) 정복 같은 더 먼 조건으로 할지
4. **유니크 카드 속도**: 2주마다 랭킹 상위 50% 2 + 원정 일지 5 + 출석 2 = 9장, 첫 달은 탑 10층마다 2장이 더해져 약 10장 → **약 5달에 ★5 (100장)**. 목표(반년~1년)의 빠른 쪽. 유니크가 4명이라 모두 ★5는 400장(약 1년 반)

# 왕이 되는 그날까지 — 아트 작업 인계 (2026-10-19)

## 범위와 상태
이 문서는 ChatGPT에서 제작한 **콘셉트 시안의 디자인 사양**을 Claude 개발 작업에 인계합니다. **이미지 PNG 파일 자체는 이 커밋에 포함되지 않았습니다.** 따라서 아래 경로는 납품 완료 파일이 아닌 목표 경로입니다. 본 문서만으로 게임의 그래픽이 변경되지는 않습니다.

## 기준
- 모바일 세로형 웹게임, 기준 폭 400px / 최대 480px, 화면 시안 9:16
- 오리지널 SD 2~2.5등신, 굵고 깔끔한 윤곽선, 부드러운 셀 셰이딩
- 세계는 진지하고 살짝 어두운 정통 판타지, 동료는 귀엽고 소박한 평민
- 전투: 아군 왼쪽에서 오른쪽을 향함 / 적 오른쪽에서 왼쪽을 향함
- UI: 배경 #141a29, 패널 #1f2740, 금색 #ffc94a, 긍정 #7be08f, 부정 #ff6b7d
- 현재 코드(Canvas 임시 렌더링)와 게임 시스템은 변경하지 않음

## 캐릭터 비주얼 잠금
- Kael: 붉은 띠 밀짚모자, 파란 멜빵바지, 흰 셔츠, 붉은 스카프, 푸른 성검, 나른한 얼굴
- Luminar: 금색 가드, 푸른 보석의 말하는 성검
- Bron: 노란 광산 헬멧/램프, 풍성한 주황 수염, 곡괭이
- Haral: **백발 노인, 노란 우비와 모자, 작살**. 일반 궁수/활로 바꾸면 안 됨
- Riel: 양봉 모자/망사, 초록 원피스, 꿀벌
- Mago: 요리사 모자, 빨간 옷, 흰 앞치마, 국자
- 마을 NPC: 마르타 할머니, 행상인 피트, 꼬마 토비
- 몬스터 전원에 작은 마족 뿔. 군단장 5명: Morbas, Seril, Gromak, Aldor, Ignis

## 목표 파일 구조
- `assets/characters/`: 각 캐릭터별 idle/walk/attack/hit 투명 PNG
- `assets/monsters/`: 지역별 일반 마물/군단장
- `assets/bg/`: Erdan Plains, Dusk Forest, Dwarf Canyon, Frost Tomb, Ash Abyss 각각 sky/far/mid/ground 레이어
- `assets/village/`: ruins/rebuilt/expanded × day/night 및 개별 시설
- `assets/ui/`: 로고, 탭 5종, 장비부위 6종, 등급 프레임 6종, 성유물 상자, 재료 아이콘

## 우선 구현 검수 기준
1. 캐릭터 동작별 256×256px **프레임 단위**, 행별 가로 배열: idle 4, walk 6, attack 4, hit 2. 카엘 예: `kael_idle.png` 1024×256, `kael_walk.png` 1536×256, `kael_attack.png` 1024×256, `kael_hit.png` 512×256.
2. PNG RGBA 실제 투명 알파, 캐릭터 발 기준선과 중심점 통일, 좌우 잘림 없음.
3. 배경은 독립된 패럴랙스 레이어로 제공하고 좌우 반복(seam) 검증. 콘셉트 시트 이미지를 레이어라고 오인하지 말 것.
4. UI 아이콘은 개별 투명 PNG로 추출/제작해 크기 및 한국어 라벨 재검수.
5. 기존 `index.html` Canvas 코드의 렌더링 기능은 이미지가 준비된 뒤 교체, 자동사냥/저장/밸런스 로직 불변.

## 주의: 아직 해결되지 않은 항목
- 본 대화에서 생성된 이미지는 **콘셉트 및 UI 목업**이며, 규격 검증된 생산용 스프라이트/배경/아이콘 아틀라스가 아님.
- UI 단독 시안에 추가 잠금 탭이나 원정대 인물 오표현이 있었음; 실제 메뉴는 장비·원정대·단련·마을·지도 **5개**.
- 전투 파티는 카엘+브론+하랄+리엘+마고 = 5인.
- 게임 배경 Erdan Plains는 밝은 전원보다는 점령/황폐함이 느껴지도록 조절.

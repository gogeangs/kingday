# 개인정보처리방침 (초안)

> **정식 공개본은 `privacy.html`** (https://gogeangs.github.io/kingday/privacy.html, 2026-10-25 앱 결제·애플 로그인·보호책임자 반영). 스토어 「개인정보처리방침 URL」에 이 주소를 넣음. 이 문서는 초안 기록용. 법률 검토 권장.

**주식회사 프로젝트서티즈**(이하 "회사")는 모바일 게임 「왕이 되는 그날까지」(이하 "게임")를 운영하며, 이용자의 개인정보를 소중히 다룹니다.

## 1. 수집하는 정보
| 항목 | 언제 | 목적 |
|---|---|---|
| 게스트 계정 식별자(무작위 ID) | 게임을 처음 켤 때 자동 | 랭킹·우편·클라우드 저장 |
| 닉네임 | 이용자가 정할 때 | 랭킹 표시 |
| 게임 기록(진행 상황, 전투력, 랭킹 기록) | 플레이 중 | 랭킹·클라우드 저장·부정행위 방지 |
| 이메일 주소(구글·애플 계정 연결 시) | 이용자가 계정을 연결할 때 | 계정 확인·기록 복구 |
| 결제 영수증 정보(주문 번호 등) | 유료 구매 시 | 결제 확인·중복 지급 방지·환불 처리 |
| 광고 식별자 | 광고를 볼 때 (Google AdMob) | 보상형 광고 제공 |

회사는 이름, 전화번호, 주소, 결제 카드 정보를 직접 수집하지 않습니다. 결제는 Google Play와 Apple이 처리합니다.

## 2. 보관 기간
- 계정이 있는 동안 보관하며, 이용자가 삭제를 요청하면 지체 없이 삭제합니다.
- 결제 기록은 전자상거래법에 따라 5년간 보관합니다.

## 3. 제3자 제공·처리 위탁
| 받는 곳 | 내용 |
|---|---|
| Supabase Inc. (서버, 서울 리전) | 계정·게임 기록·우편 저장 |
| Google LLC (AdMob, Google Play, Google 로그인) | 광고 제공, 결제, 로그인 |
| Apple Inc. (App Store, Apple로 로그인) | 결제, 로그인 |

## 4. 이용자의 권리
- 게임 안 설정 → 카엘의 수첩에서 게임 기록을 초기화할 수 있습니다.
- 계정·서버 기록 삭제는 아래 문의처로 요청해 주세요.

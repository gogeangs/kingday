# 왕이 되는 그날까지

은퇴만 꿈꾸는 농부 카엘이 밭에서 성검을 뽑는 바람에, 마족에게 빼앗긴 세계를 한 칸씩 되찾다가 결국 왕이 되는 자동사냥 방치형 웹게임입니다.

## 실행하기

설치할 것이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

```bash
# 로컬 서버로 열고 싶다면
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

저장은 브라우저의 localStorage(`acorn-idle-v1` 키)에 됩니다. 처음부터 다시 하려면 개발자 도구에서 이 키를 지우세요.

| 다른 지역 몬스터, 군단장, 배경 | 코드 그림 (전투 배경은 2.5D 구도로 개선) |

이미지가 없거나 불러오지 못하면 게임은 자동으로 코드 그림을 씁니다. 그래서 에셋을 하나씩 추가해도 게임이 깨지지 않아요.

### 새 캐릭터 스프라이트 추가하기

1. 동작 시트를 `art/source/<id>_motion_concept.png`에 넣습니다. 진짜 투명 배경이어야 하고, 1줄 대기 4 / 2줄 걷기 6 / 3줄 공격 4 / 4줄 피격 2, 오른쪽을 보는 측면이어야 합니다.
2. `python3 tools/extract_sprites.py art/source/<id>_motion_concept.png <id>` 를 실행합니다. (`pip install pillow numpy scipy` 필요)
몬스터는 끝에 `--monster`를 붙입니다 (1줄 이동 4 / 2줄 공격 4 / 3줄 피격 2, 왼쪽을 봄). 그리고 `index.html`의 `MON_SPRITES`에 지역 번호와 시트 이름을 추가합니다.
3. `index.html`의 `SPRITES`에 `<id>:{idle:4,walk:6,attack:4,hit:2,h:키}` 한 줄을 추가합니다.

## 화면 구성

- 타이틀 화면 → 전투 화면(기본 화면)
- 하단 탭(장비·원정대·단련·마을·지도)을 누르면 그 화면이 전체로 열리고, 같은 탭이나 ✕를 누르면 전투로 돌아옵니다. 전투는 다른 화면을 보는 동안에도 계속됩니다.
- 전투 화면: 상단 바(카엘·칭호·전투력·골드), 영지 진행 표시, 원정대 초상화 줄, 성유물 상자 바로 열기, 전투 속도 x1/x2

## 지금 들어 있는 것 (프로토타입 v7)

- 원정대 최대 5명 자동 전투 (카엘 + 평민 동료 4명)
- 성유물 상자 장비 뽑기 (6부위, 6등급)
- 동료 레벨업, 카엘 단련
- 마을: 밭 재배, 요리 버프, 여관·식당·낚시터·양봉장·광산 재건
- 영지 50곳 탈환 지도, 칭호 승급
- 은퇴하기(환생), 방치 보상

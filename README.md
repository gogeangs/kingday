# 왕이 되는 그날까지

은퇴만 꿈꾸는 농부 카엘이 밭에서 성검을 뽑는 바람에, 마족에게 빼앗긴 세계를 한 칸씩 되찾다가 결국 왕이 되는 자동사냥 방치형 웹게임입니다.

## 실행하기

설치할 것이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

```bash
# 로컬 서버로 열고 싶다면
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

저장은 브라우저의 localStorage(`acorn-idle-v1` 키)에 됩니다. 처음부터 다시 하려면 개발자 도구에서 이 키를 지우세요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 게임 전체(HTML, CSS, JavaScript 한 파일). 그래픽은 모두 Canvas 코드로 그립니다 |
| `docs/DESIGN_BRIEF.md` | 디자인 작업 의뢰서. 캐릭터, 몬스터, 배경, UI 디자인 요청 사항 |
| `docs/GAME_DESIGN.md` | 세계관, 줄거리, 인물, 시스템 기획 요약 |

## 지금 들어 있는 것 (프로토타입 v5)

- 원정대 최대 5명 자동 전투 (카엘 + 평민 동료 4명)
- 성유물 상자 장비 뽑기 (6부위, 6등급)
- 동료 레벨업, 카엘 단련
- 마을: 밭 재배, 요리 버프, 여관·식당·낚시터·양봉장·광산 재건
- 영지 50곳 탈환 지도, 칭호 승급
- 은퇴하기(환생), 방치 보상

## 코드 지도 (index.html)

| 구역 주석 | 내용 |
| --- | --- |
| `/* ---------- 데이터 ---------- */` | 지역, 동료, 건물, 작물, 이벤트 대사 등 모든 콘텐츠 데이터 |
| `/* ---------- 능력치 ---------- */` | 전투력, 몬스터 체력, 보상 공식 |
| `/* ---------- 전투 ---------- */` | 자동 전투 로직 |
| `/* ---------- 그리기 ---------- */` | 캐릭터(`drawKael`, `drawBron` 등), 몬스터(`drawMon`), 배경(`drawBg`) |
| `/* ---------- 마을 풍경 ---------- */` | 마을 화면 그리기 |
| `/* ---------- 영지 지도 ---------- */` | 탈환 지도 그리기 |
